# 文字组件索引

> 中文字体族不在此决定(见 `fonts/README.md` 两级筛查);这里只管**层级、字距、行高、数字排版**。

| 组件 ID | 用途 | 加载条件 |
| :--- | :--- | :--- |
| `typography.hero-cjk-title` | 超大中文标题,字重对比 + 紧行高 | 标题要"占 30% 画面以上"、要有冲击力时 |
| `typography.bilingual-stack` | 中英双语三层级(英文 kicker / 中文主标 / 英文副行) | 版面有英文、品牌名、英文 slogan、双语标题时 |
| `typography.number-display` | 数字主视觉(价格/百分比/日期/统计) | 版面出现需要被一眼读到的数字时 |
