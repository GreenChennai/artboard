# Shantell Sans

| 属性 | 值 |
|---|---|
| 字体文件 | ShantellSans-Bouncy-Regular.otf |
| 字重/变体 | Bouncy Regular(多变体可加) |
| 分类 | 英文点缀·手写圆润 |
| 气质关键词 | 手写,圆润,bouncy,轻松 |
| 协议/来源 | OFL 1.1 · arrowtype/shantell-sans |

## 气质描述
轻松手写圆润,与中文可爱体/手账风最搭。

## 适用
手账小红书的英文点缀、对话气泡、涂鸦标签。

## 慎用
正式商务;与衬线中文同屏。

## 示例句
「海内存知己,天涯若比邻 0123456789」
