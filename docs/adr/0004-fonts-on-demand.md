# ADR 0004:字体库按需下载,仓库只随附代表款

日期:2026-09-06 · 状态:已采纳

## 背景

字体库扩到 21 款后体积可观(乌龙宋单文件 76MB),全部入库拖慢克隆。

## 决策

fonts/.gitignore 忽略全部字体二进制,仅保留每类一款代表(6 款);
其余登记进 `fonts/download.json`(直链/zip 提取/官网手动三形态),
`scripts/fetch_font.py` 按需取回。AI 工作流:预检报缺失 → fetch_font 补齐。

## 后果

仓库 <100MB;首次用小众字体需联网一次;download.json 同时充当"可信来源清单"。
