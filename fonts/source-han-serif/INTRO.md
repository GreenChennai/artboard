# 思源宋体(Source Han Serif / Noto Serif SC)

| 属性 | 值 |
|---|---|
| 字体文件 | NotoSerifSC-VF.ttf(可变字体) |
| 字重/变体 | 可变字重 200–900(ExtraLight→Black) |
| 分类 | 文艺人文 · 杂志标题 |
| 气质关键词 | 人文、书卷、高级、克制、编辑部 |
| 协议/来源 | SIL OFL 1.1 · googlefonts/noto-cjk(与思源宋体同源) |

## 气质描述
中文衬线的正统。大字号宋体自带"杂志刊头"气场,Black 字重可做极具张力的编辑风
大标;细字重则安静克制。

## 适用
- 杂志编辑风、文艺海报的大标题(700–900)
- 引文、金句、诗歌类文案(400–500)
- 高端品牌、出版、茶酒类目

## 慎用
- 小字号正文(屏幕上笔画易糊,长文换思源黑体)
- 促销打折、大字报场景(压不住价签的躁)

## 示例句
「山川是不卷收的文章,日月为你掌灯伴读 0123456789」
