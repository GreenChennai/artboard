# ADR 0002:参考资料按需读取(渐进披露),不做批量预读

日期:2026-09-06 · 状态:已采纳

## 背景

references/ 已有 15+ 份分册(合计数万 token)。Agent 每次任务全读会大量浪费上下文。

## 决策

SKILL.md 的资源索引改为**路由表**:每份分册标注「何时才读」;
Agent 只读当前任务命中的文件(风格分册/品类规范一次只读命中的一份),
其余不读不解析。SKILL.md 本体保持自足(流水线/铁律/尺寸表/脚本)。

## 后果

上下文消耗大幅下降;代价是"全局视野"变小——用路由表 + guardrails 常读兜底。
