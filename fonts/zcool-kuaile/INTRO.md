# 站酷快乐体(ZCOOL KuaiLe)

| 属性 | 值 |
|---|---|
| 字体文件 | ZCOOLKuaiLe-Regular.ttf(Regular 单字重) |
| 字重/变体 | Regular |
| 分类 | 标题冲击 · 可爱手账 |
| 气质关键词 | 俏皮、圆润、蹦跳、零食感、童趣 |
| 协议/来源 | 免费商用 · 站酷 / Google Fonts(OFL) |

## 气质描述
笔画像跳跳糖,自带表情包体质。适合"可爱有品质"的手账系封面——注意配暖底
和贴纸元素,别让它孤零零站着。

## 适用
- 小红书手账/萌系封面大字
- 零食、玩具、宠物、儿童类目
- 气泡对话框内的短句

## 慎用
- 长句正文(识别率崩)
- 高端、商务、科技调性
- 深色科技底(气质互斥)

## 示例句
「快乐是充电宝,蹦蹦跳跳满格 0123456789」
