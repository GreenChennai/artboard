# artboard 伪3D与空间感分册(统一光源 · 六类手法 · 剪切蒙版 · 景深)

> **本册与既有资源的关系(防多真相源)**:
> - 本册只讲「纵深 / 厚度 / 前后关系」这一维度的**跨元素系统规则**:统一光源、六类伪3D手法、标题伪3D配方、剪切蒙版造空间、景深、Kiln 支持边界与体积预算;
> - 单个可抄特效配方(长投影 `fx-longshadow`、浮雕 `fx-emboss`、贴纸 `fx-sticker`、错版 `fx-misprint` 等 43 式)→ `effects.md`,本册不重复,只在组合时引用;
> - 标题描边 / `paint-order` / 透明填充字硬条 → `title-fx.md`,本册只引用不重写;
> - 矢量交付五条禁令 → `vector-export.md §4`;特效计数与层级铁律 → `guardrails.md` 铁律 3;
> - 景深位图虚化工序 → `imageops.py blur-bg`(用法见 `imaging.md`),本册只定"哪层虚多少"。

## 0. 第一原则:伪3D 是"造的",不是"真的"

**伪3D(Pseudo-3D)**:用 2D 手段(`text-shadow` 挤出、伪元素分层、`clip-path` 遮挡、透视变换)制造"厚度、纵深、前后关系"的**错觉**,不是真 3D 建模。它只服务两件事:

1. **实体感**——元素有厚度,不再"飘"在纸面;
2. **空间感**——画面有前后层,读者知道谁在前、谁在后。

**判断标准**:拿掉这层伪3D,画面信息有没有损失?没有 → 它是装饰,**该删**(同 guardrails 反堆砌原则)。伪3D 是画面里最容易被滥用的维度——"廉价 3D 字"比"平面字"更掉价,所以本册所有手法都受 §七 一致性纪律约束。

## 一、统一光源模型(所有伪3D的前提)

没有统一光源,多个伪3D元素 = 光源打架 = 一眼业余。**统一光源(Light Model)**:全图所有阴影 / 高光共享同一方向与软硬程度,定一次,全图遵守:

```css
:root{
  --light-deg: 135deg;        /* 光源方向:左上 → 阴影朝右下(默认,符合阅读方向) */
  --light-soft: .35;          /* 阴影不透明度上限 */
  --light-blur: 24px;         /* 主投影模糊半径(全图统一) */
  --extrude: 8px;             /* 厚度带宽度(标题按字号定,正文不用) */
}
```

**四级高程(Elevation)**:在光源 tokens 之上,把"元素离纸面多高"分四级,阴影参数全部从 `--light-*` 派生,不另设体系:

| 级 | 用途 | 写法(方向随 `--light-deg`,默认右下) |
|---|---|---|
| **E0 平贴** | 底色、纹理层、贴纸 | 无阴影 |
| **E1 微浮** | 信息卡、条目条 | `0 2px 6px rgba(0,0,0,.10)` |
| **E2 悬浮** | 焦点卡、按钮、弹出面板 | `0 8px var(--light-blur) rgba(0,0,0,var(--light-soft))` |
| **E3 高悬** | 伪3D 主视觉 | `0 18px calc(var(--light-blur)*1.5) rgba(0,0,0,.30)` + 厚度带(手法 1–5) |

- **一图高程 ≤3 级**(E0 不计)。理由:四级全上 = 每个元素都在"漂",相对高度读不出,还挤爆铁律 3"层级 ≤3 层";
- **相邻两级差必须肉眼可辨**(模糊半径或透明度差 ≥1 档)。理由:分不出的两级是假分级,只增加阴影噪音。

**三条光源纪律**(违反任何一条 = 重做):

1. **方向唯一**:所有投影朝向同一侧(默认阴影在右下 = 光在左上)。理由:两个元素投影方向相反时,观众潜意识读到"两个光源",画面立刻假;
2. **软硬分级**:近处元素阴影**硬**(blur 小)、远处**软**(blur 大)——这是"空间深"的物理暗示,全部同软硬 = 没有距离感;
3. **高光与阴影同侧**:挤出体的受光面永远朝光源方向。理由:受光面背光 = 凹凸读反,浮雕变"脏"。

## 二、六类手法(每类可抄)

### 手法 1 · 长阴影堆叠(硬挤出带)

最安全的伪3D——纯 `text-shadow`。多层 1px 锐利位移拼出**厚度带(Extrusion Band)**:长阴影 / 克隆层在字形侧下方拼出的"实体侧壁"。

```css
/* 厚度带:blur 固定 0;颜色逐层同色或明暗交替做"反光条纹" */
.fx-extrude{
  color:#fff;
  text-shadow:
    1px 1px 0 var(--c-ink),  2px 2px 0 var(--c-ink),  3px 3px 0 var(--c-ink),
    4px 4px 0 var(--c-ink),  5px 5px 0 var(--c-ink),  6px 6px 0 var(--c-ink),
    0 14px 24px rgba(0,0,0,.35);          /* 最后一条:落地投影,把字"压"进空间 */
}
```

- **厚度带宽度 = 层数 × 步长**;标题取字号 5%–10%(88px 字 → 6–8px 厚);
- **落地投影必须有**:只有挤出、没有落地投影 = 字"飘着",厚度带反而暴露悬浮;
- 步长可用 0.5px 步进做细腻条纹;逐层生成量大时让脚本生成,导出前写成静态 CSS;
- 相关既有配方:`fx-longshadow`(纯长投影,无落地)。

### 手法 2 · 分层克隆偏移(轻量,深度可控)

复制一/两层同内容元素沿固定方向偏移,中间色分隔——比长阴影更可控:

```css
.fx-clone{ position:relative; color:var(--c-bg); z-index:2; }
.fx-clone::before{ content:attr(data-text); position:absolute; left:0; top:0;
  z-index:-1; color:var(--c-accent); transform:translate(4px,4px); }   /* 后层(厚度) */
```

- **层数 ≤2**(一前一亮);层数多了糊。理由:每层都在复制字形,3 层以上边缘互相干扰,小字号直接糊死;
- 与渐变字配合:前层用渐变(`title-fx.md §二`)→ 金属挤出;
- **真 3D 版**(preserve-3d + translateZ)见 §六 矩阵:仅浏览器道成立。

### 手法 3 · 透视变换(真实景深)

父容器给 `perspective`,子元素 `rotateX/Y` 朝向观察者——文字"斜进去":

```css
.stage{ perspective:600px; perspective-origin:50% 40%; }
.tilt{ transform: rotateX(12deg) rotateY(-8deg); }
```

- **角度克制**:单轴 ≤15°。理由:超过 20° 中文笔画透视变形严重,可读性崩;
- 静态海报适合"招牌斜俯视";**导出前必读 §六 矩阵**(仅浏览器道成立)。

### 手法 4 · 等距 / 等轴测(几何/科技风首选)

用严格等比的偏移束伪造等轴测挤出,明暗交替像"瓦楞墙":

```css
.fx-iso{
  text-shadow:
    1px 1px 0 #c9a054, 2px 2px 0 #8a6a24,
    3px 3px 0 #c9a054, 4px 4px 0 #8a6a24,
    5px 5px 0 #c9a054, 6px 6px 0 #8a6a24;
}
```

- 与科技 KV / 赛博 / 机甲最搭;
- 等距立方体用纯 CSS 三面拼(`rotateX(60deg) rotateZ(45deg)` + 三个面)或 SVG。

### 手法 5 · 块状挤出(厚实体感)

连续 1px 锐利步进(厚)+ 远端大模糊投影(落地)+ 描边分割(把字与挤出体分开):

```css
.fx-block{
  color:#fff;
  -webkit-text-stroke:3px var(--c-ink);      /* 先描边:文字与挤出体的分割线 */
  paint-order:stroke fill;                   /* 描边垫底(中文细体必加,title-fx.md 既有硬条) */
  text-shadow:
    1px 1px 0 var(--c-ink), 2px 2px 0 var(--c-ink), 3px 3px 0 var(--c-ink),
    4px 4px 0 var(--c-ink), 5px 5px 0 var(--c-ink), 6px 6px 0 var(--c-ink),
    7px 7px 0 var(--c-ink), 8px 8px 0 var(--c-ink),
    0 18px 30px rgba(0,0,0,.40);             /* 落地投影 */
}
```

- 与新野兽派(粗黑边硬阴影)天生一对;描边不垫底会吃笔画(理由同 `title-fx.md §一`)。

### 手法 6 · 内凹 / 浮雕(压印/高级感)

双光源反向位移,一点亮一点暗:亮点朝光源 → **凸**;反序 → **凹**:

```css
.fx-emboss{ color:var(--c-bg);                  /* 凸:字与底同色系,靠光影成形 */
  text-shadow: -1px -1px 0 rgba(255,255,255,.65), 1px 1px 0 rgba(0,0,0,.45); }
.fx-deboss{                                     /* 凹(压印,letterpress) */
  color:var(--c-bg);
  text-shadow: 1px 1px 0 rgba(255,255,255,.55), -1px -1px 0 rgba(0,0,0,.40); }
.fx-emboss-box{                                 /* 元素级浮雕 */
  background:#eae4da; color:#b8823a;
  box-shadow: inset 1px 1px 2px rgba(0,0,0,.45), inset -1px -1px 2px rgba(255,255,255,.55); }
```

- 浮雕/压印是"低对比的高级",适合黑金/大理石/奢品;依赖"字与底同色系",底色必须非纯白纯黑(纯底上光影 Read 不出);
- 本册补齐 effects.md `fx-emboss` 简版的凹凸方向与元素级写法,方向定义以本册为准。

### 手法速查表

| 手法 | 一行关键属性 | 位图导出(默认) | 适用风格 |
|---|---|---|---|
| 长阴影堆叠 | `text-shadow:1px 1px 0 c,…` | ✅ | 通用/复古/波普 |
| 分层克隆 | `::before{transform:translate(4px,4px)}` | ✅ | 通用/金属 |
| 透视变换 | `perspective + rotateX/Y` | ⚠️ 仅浏览器道(§六) | 科技/招牌 |
| 等距 | 严格等比 `text-shadow` 束 | ✅ | 科技/机甲/几何 |
| 块状挤出 | 1px 步进 + `-webkit-text-stroke` | ✅ | 新野兽派/漫画 |
| 内凹浮雕 | 双反向 `text-shadow` / `inset box-shadow` | ✅(元素级 inset 矢量需核) | 奢品/黑金/大理石 |

> 表中 ✅ 指**浏览器道位图导出**(Kiln auto 默认道)。所有 text-shadow / stroke / mask 类在 Kiln 自研道与矢量输出下会**静默丢失**——交付前必读 §六 矩阵。

## 三、标题伪3D 三套配方(按力气从轻到重)

**A · 轻(编辑/文艺)——只有落地投影 + 极薄厚度**

```css
.title-a{ text-shadow: 2px 2px 0 rgba(0,0,0,.12), 0 10px 26px rgba(0,0,0,.28); }
```

**B · 中(海报主标)——硬挤出 + 落地投影**(手法 1 参数化)

```css
.title-b{ color:#fff;
  text-shadow: 1px 1px 0 var(--c-primary), 2px 2px 0 var(--c-primary),
               3px 3px 0 var(--c-primary), 4px 4px 0 var(--c-primary),
               5px 5px 0 var(--c-primary), 6px 6px 0 var(--c-primary),
               0 16px 28px rgba(0,0,0,.35); }
```

**C · 重(促销/综艺)——块状挤出 + 描边 + 落地**(手法 5)

> **标题伪3D 四条纪律**:
> 1. **厚度随字号**:88px 主标厚度 6–10px;160px 大标 12–18px;正文**不做伪3D**。理由:正文笔画细,厚度带会糊掉字腔,可读性崩;
> 2. **只做标题一处**:其它文字保持平贴——全图都立体 = 没有重点(承接铁律 3 一图一焦点);
> 3. **厚度方向 = 光源方向**(默认右下),与全图阴影一致(§一);
> 4. **中文细体先 `paint-order: stroke fill`**,否则描边吃笔画(`title-fx.md §一` 既有硬条);**透明填充字禁 text-shadow**(阴影从字底透出毁掉渐变,`title-fx.md §二` 既有硬条)——要"渐变字 + 挤出"用手法 2 分层克隆把厚度垫在 `z-index:-1` 层。

## 四、剪切蒙版造空间

**核心思路**:用 `clip-path` / `mask` 制造"元素被另一个元素遮挡"或"从某形状穿出"的关系 → 观众读到"谁在前、谁在后"。四种写法(≥3 即达标,全给):

### 写法 A · 前后遮挡(主体从色块穿出)——最省力的空间叙事

```html
<div class="poster">
  <h1 class="hero">城市之声</h1>              <!-- 后层:标题 -->
  <div class="plate"></div>                    <!-- 前层:色块,盖住标题下半 -->
</div>
```

```css
.hero{ position:absolute; left:8%; bottom:26%; z-index:1;
  font:400 150px/1 'SmileySans'; color:var(--c-ink); }
.plate{ position:absolute; left:0; right:0; bottom:0; height:34%;
        background:var(--c-primary); z-index:2; }   /* 前层盖住标题下半 */
```

→ 标题"半没入"色块,立刻有前后空间感,一个 `z-index` 就够,不需要任何裁切。

### 写法 B · 画中画(框中框 + 裁切)

```css
.viewport{ width:46%; aspect-ratio:3/4; overflow:hidden;      /* 内框裁切 */
           clip-path: polygon(0 0, 100% 0, 100% 88%, 0 100%); }  /* 斜切下缘 */
```

配合 `composition.md` 框中框骨架:内框里放次级画面/照片,与外框形成"层中层"。

### 写法 C · 穿透/切片(mask 渐变)

```css
.slices{ -webkit-mask-image: repeating-linear-gradient(
   0deg, #000 0 12px, transparent 12px 20px); }     /* 横向切片,像"错位" */
```

切片是"层级拆解"暗示:主体被切成条带仍有先后,适合科技/故障风。

### 写法 D · 撕纸/斜切边

```css
.torn{ clip-path: polygon(0 2%, 12% 0, 100% 4%, 100% 100%, 0 100%); }
```

撕纸/斜切给"手工拼贴"的前后关系:被撕的那层永远读作"上层"。

> **蒙版五条纪律**:
> 1. **前景遮挡块必须是不透明实体**,被遮主体留 30%–40% 露出量最有戏。理由:全遮 = 主体消失,露太多 = 没有遮挡感;
> 2. **不要遮脸 / 遮关键信息**(产品主体的品牌标识不能被盖)。理由:遮挡服务空间叙事,不能牺牲信息;
> 3. `clip-path` 与铁律 1 的 `overflow:hidden` 共用无冲突(一个管内层裁切、一个管外层画布);
> 4. **导出安全见 §六**:`inset` 双道安全;`circle/ellipse/polygon` 与 `mask` 仅浏览器道,自研道 / 矢量输出会静默失效——失效形态是"色块变完整矩形/实心块",比崩溃更危险,因为不容易被发现;
> 5. **只做一层遮挡关系**,不要三层套娃。理由:每层遮挡都要求观众做一次前后判断,超过一层读起来累,违反"层级 ≤3"。

## 五、景深(Depth of Field)

制造"近实远虚"的空间感,四层分工:

| 层次 | 处理 | 说明 |
|---|---|---|
| **前景**(可选) | 轻微 blur(1–2px)+ 降饱和 | 制造"镜头很近"感 |
| **主体** | **最锐、最高对比** | 焦点层,永不 blur |
| **背景** | blur 6–14px 或预虚化图 | 用 `imageops.py blur-bg` 或预模糊图 |
| **空气中层** | 半透明白/暖雾(α .05–.15) | 拉开层间距,像"空气透视" |

- 工具:位图虚化走 `imageops.py`(入口与档位见 `imaging.md`);压字垫层数值见 `color-contrast.md`;
- **禁主体上做 blur**。理由:焦点层糊了画面就没了"看哪里";**禁全图统一 blur**。理由:全糊 = 没有景深,只有没对上焦。

## 六、导出安全与 Kiln 支持矩阵(2026-09-21 实测)

> artboard 渲染走 Kiln **双车道**:`--engine auto`(默认)浏览器在位走**系统 Edge/Chrome 高保真道**;缺席时回退 **Kiln 自研道**(`--engine native`,自研布局引擎)。两道能力差距极大,伪3D 原语**多数只在浏览器道成立**,且自研道的失效是**静默的**(不报错、不告警)。

**实测方法**:`scaffold.py` 冒烟项目 + 7 个单能力样例,`export.py`(浏览器道)与 Kiln CLI `--engine native`(自研道)各导一次;真 3D 两项另配"无 3D 属性"对照图做像素差与色块 bbox 比对;矢量用 `ai_export.py --svg --pdf` 并解析 SVG 源码。

| # | 能力 | 浏览器道(auto 默认) | Kiln 自研道(native) | SVG/PDF 矢量 | 判定 |
|---|---|---|---|---|---|
| 1 | `text-shadow` 多层挤出 | ✅ 厚度带 6 层完整 + 落地投影 | ❌ 整体丢失(白字平贴底色) | ❌ 只剩纯色 `<text>` | 位图默认道可用;自研道/矢量禁用 |
| 2 | `-webkit-text-stroke` + `paint-order` | ✅ 描边垫底不吃笔画(对照组无 paint-order 笔画被吃) | ❌ 描边丢失 | ❌ 无 stroke 属性 | 同上 |
| 3 | `clip-path: inset` | ✅ | ✅(与浏览器道逐像素一致) | ❌ 退回完整矩形 | **双道安全的唯一裁切值** |
| 3b | `clip-path: circle/ellipse/polygon` | ✅ 四形全对 | ❌ 色块整体裁没(蓝像素=0,只剩文字) | ❌ 退回完整矩形 | 仅浏览器道 |
| 4 | `mask-image` 渐变切片 | ✅ 切片/渐隐正确 | ❌ 被忽略 → 实心色块 | ❌ 变实心块 | 仅浏览器道 |
| 5 | `perspective` + `rotateX/Y` | ✅ 真透视(卡片成梯形,bbox 外扩) | ❌ 静默平贴(与无 3D 对照 bbox 全等) | ❌ | 真3D:浏览器道**可用**,自研道**禁用** |
| 6 | `preserve-3d` + `translateZ` | ✅ 前层放大 / 后层缩小被盖 | ❌ 静默平贴(bbox 全等) | ❌ | 同上 |

**真 3D 结论**(判据 5/6):浏览器道真 3D 成立,可用于位图交付;Kiln 自研道**不支持且静默忽略**;按铁律 10"未验证不默认"的同一逻辑,真 3D 仅在确认走浏览器道交付时使用。

**降级方案**:

```css
/* 真想做纵深层,又怕回退自研道:用分层克隆(手法 2)代替 preserve-3d,
   效果近似;真 3D 属性包在 @supports 里,自研道不认时自动走伪元素方案 */
.layer{ position:relative; }
.layer::before{ content:attr(data-text); position:absolute; left:6px; top:6px; z-index:-1; }
@supports (transform-style: preserve-3d){
  .layer{ transform-style: preserve-3d; transform:translateZ(12px); }
}
```

**默认姿势与纪律**:

1. 能用 `text-shadow` / 伪元素分层实现的,**绝不用真 3D**——不是因为好看,是因为自研道回退时损失最小;
2. **用了伪3D 的图,导出后必须 Read 成品图确认**(Step 6.1 既有动作,此处为强制点):自研道回退时白字挤出会变"浅底白字"几乎不可见,只有看图能发现;
3. 矢量交付(SVG/PDF/EPS/AI)时:伪3D 层一律先栅格化(位图层进矢量稿)或放弃;`clip-path` 只留 `inset`;`vector-export.md §4` 五条禁令继续适用;
4. 浏览器缺席(自研道)环境做伪3D任务 = 白做,开工前 `preflight.py` 先确认导出道。

---

## 七、一致性纪律(与铁律对齐)

1. **纵深计入特效计数**:伪3D + 其他特效 ≤3 种(铁律 3)。理由:伪3D 自带"阴影 + 高光 + 分层"三重视觉噪音,再叠光效/噪点必成垃圾;
2. **一图一处纵深焦点**:标题或主视觉,二选一。理由:两处都在"向前凸" = 互相抢焦点;
3. **光源统一**:全图阴影同向同软硬(§一);
4. **透视消失点统一**:一张图只用一种透视。理由:两种透视并存时透视消失线相交,空间关系自相矛盾;
5. **装饰配合**:伪3D 元素的落地投影要**更长更软**,暗示"它比其他元素更高"——这是纵深元素之间唯一允许的差异化;
6. **不越硬规则**:中文细体描边必配 `paint-order`;透明填充字禁 `text-shadow`(`title-fx.md` 既有硬条,本册手法 5 已内建)。

## 八、部署形态与体积预算(2026-09-21 实测)

**三条实现路线与体积**:

| 路线 | 实现 | 新增依赖 | 体积增量(实测) | 默认 |
|---|---|---|---|---|
| **① CSS 配方** | `text-shadow` 挤出 / 伪元素分层 / `clip-path` / `box-shadow` | 无 | **≈0**(本册分册 + 案例 + scaffold 注释合计约 20KB 文本) | ✅ 默认 |
| **② 内联 SVG** | 等距块 / 立方 / 路径挤出 | 无 | **≈0**(markup 内联,几 KB) | ✅ 默认 |
| **③ 真 3D** | `perspective`+`transform`(纯 CSS) | 无 | **0**(就是几行 CSS) | ⚠️ 仅浏览器道 |
| ③' | WebGL 引擎(three.js 等 vendored) | 可选 | `three.min.js` ≈ 0.6–1.2MB(未引入) | ⛔ 仅按需 |

**体积红线**:

| 项 | 值 |
|---|---|
| 目标增量 | **≤10MB**;硬上限 **≤200MB**(用户口径 2026-09-21) |
| 本轮实测增量 | 分册 + 案例 + scaffold 注释 ≈ 20KB,**达标** |
| 现状基线 | `assets/vendor/` 仅 `echarts.min.js`(1.03MB)+ `gsap.min.js`(72KB)≈ 1.1MB;**无 three.js** |
| 位图深度图/法线贴图 | 每张 1080×1440 8-bit PNG ≈ 1–3MB;仅"位图级浮雕"任务才需要,交付时**不进 skill 仓库** |
| 引入三方 3D 库 | **默认不引**;确需时先报体积、经同意再加(`guardrails.md` 离线优先纪律) |

> 一句话:伪3D **几乎不占空间**——它是几 KB 的 CSS,不是 200MB 的引擎;真正会变重的只有"位图深度图批量化"这一种非常规用法。

> **X1 边界提示(此能力不做)**:真 3D 引擎(WebGL/three.js 场景)**不在 artboard 范围**——定位是 HTML/CSS 平面设计,Kiln 自研道与矢量道均不支持,越界且不可交付;确需真 3D 产物走专门 3D 工具链,本技能只按上表③的纯 CSS transform 提供浏览器道轻量方案。
