# 电商大促(ecommerce-promo)

> 一句话定位:大促主图/推广横幅,价格与紧迫感优先,声音要"炸"。

## 画布与安全边距
- 尺寸:square(1080×1080)主图 / banner(1920×600)横幅 / vertical(1080×1920)详情头图。
- 安全边距 6%;爆炸贴、出血色块可破格。

## 色彩角色表
| 角色 | 值 | 用法 |
|---|---|---|
| 底 bg | `#fff5f0` / 深底版 `#2a0a0a` | 浅底日常促,深底双 11 感 |
| 近黑文字 ink | `#2a0a0a` | 标题与正文 |
| 主色 primary | `#e0231c` | 大促红:底纹条带、价格 |
| 强调 accent | `#ffc300` | 金色:只给价格数字或「省」字 |
| 辅助 muted | `#a07068` | 条款、活动时间 |

## 字体栈
| 角色 | 字体 | 字重 | 字距 |
|---|---|---|---|
| 主标/促销词 | [得意黑](../../fonts/smiley-sans/INTRO.md) | — | 0(可负 -0.01em) |
| 价格数字 | [得意黑](../../fonts/smiley-sans/INTRO.md) | — | 0 |
| 说明/条款 | [思源黑体](../../fonts/source-han-sans/INTRO.md) | 400/500 | 0.02em |

## 字号阶(1080 宽基准)
促销大字 160–220 / 价格 ¥ 后数字 120–160 / 副标 44 / 条款 20(最小可 18)。

## 网格与间距
8px 间距系;三段式分区:顶部品牌条(高 10%)→ 中部促销主张(50%)→ 底部卖点/CTA(40%)。

## 布局原型
| 场景 | 原型 | 结构 |
|---|---|---|
| 单卖点爆款 | sparse 大字报 | 超级促销词(2–4 字)铺满宽,价格贴右下 |
| 多卖点聚合 | balanced | 主价区 + 3 个横条卖点(图标 + 一句) |
| 横幅 | banner 三段 | 左促销词 / 中价格锚 / 右 CTA 按钮 |

## 组件语言
1. **爆炸贴**(fx-starburst + 圆底):「立减」「赠」类短词,旋转 -6°。
2. **价格锚组件**:¥ 小 + 数字超大 + 删除线原价(muted 色)。
3. **优惠券条**(fx-ticket + 虚线):「满 300 减 50」句式,可点击感按钮化。
4. **时间紧迫条**(思源黑体 500):「仅剩 2 天」+ 倒计时数字(得意黑)。
5. **描边大字**(fx-outline-stroke):次级促销词压在底纹上,不抢价格。

## 调性禁则
1. 字体 ≤2 款(得意黑 + 思源黑体),混入第三款 = 杂牌感。
2. 红金是主角,**禁**再引入蓝/紫/绿第三色系。
3. 禁条款字号 < 18px 或对比度 < 4.5:1(合规底线)。
4. 禁促销词换行超过 2 行——大字报的力量来自一口气读完。
5. 删除线原价必须完整可读,禁糊化处理(广告法)。
6. 爆炸贴 ≤2 个/图,叠 3 个就成地摊。
7. **必须有真实素材**():纯文字+图形的促销图一律不合格——产品照(用户提供或 `版权风险-` 演示图)抠图加投影做主体,或实拍氛围图做底;photo 区至少占画面 30%。

## 素材版式
- 产品抠图件(soft 投影)放在价格锚同侧,「图-价-券」三点一线。
- 实拍底图压暗 + 噪点后再上金字(fx-foil 需要深底才有金属感)。
- 氛围图选图关键词(英文命中率高):`coffee cup dark`, `product photography dark background`, `food photography moody`。
