# 数据组件索引

> 数据必须逐字来自用户/真实来源(铁律 4);这里只管**怎么摆**,不管"数字从哪来"。

| 组件 ID | 用途 | 加载条件 |
| :--- | :--- | :--- |
| `data-display.stat-block` | 统计块:一个主数字 + 标签 + 来源 | 要有 1–4 个核心指标、且数字是画面论据时 |
| `data-display.metric-row` | 指标行:一行并列 2–4 个紧凑数字 | 版面横向有余量、指标之间是"并列关系"时 |
| `data-display.label-group` | 标签组:键值对清单(参数/规格/日期) | 名片、易拉宝、产品参数、活动信息需要成组罗列时 |
