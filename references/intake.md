# artboard 需求追问(开工前必过,防盲做)

> 原则(2026-09-06 用户确立):**不能用户甩一段文案/一张图就闷头开做**——先搞清楚"用在哪、多大、什么风格、什么配色、素材从哪来",再动手。追问学 grill-me:一次打包问完、每问给推荐项、最多追问一轮。

---

## 触发规则

| 输入模式 | 追问强度 |
|---|---|
| A 文案直出 | **五问全问**(除非用户已给全五要素,或明说「直接做 / 全按推荐」) |
| B 图片复刻 | 只问 Q1 用途 + Q2 尺寸(视觉基准已在图里;风格配色跟随原图) |
| C 换风格 | 只问 Q1 用途 + Q2 尺寸(风格配色是任务本身) |
| 同会话连做同需求多张 | 五问只问一次,后续沿用 |

## 五问(打包一次发出,每问带推荐)

**Q1 · 用在哪?(决定品类 + 呈现骨架)** — 最重要,必问
- 线上内容(小红书/公众号/朋友圈)→ xhs/square 竖版骨架,Z 动线、首屏即全部
- 电商(主图/横幅/promo)→ square/banner,价格与卖点优先
- 线下印刷(易拉宝/海报/名片/三折页)→ 对应品类,按印刷字号阶与安全边距
- 发布会/品牌 → kv/vertical,深色克制骨架
➡️ 影响的不只是尺寸:骨架(单列/分栏/三段)、字号阶、留白策略全由用途反推。

**Q2 · 尺寸?** — 给默认防遗忘
➡️ 按用途给默认(如"小红书默认 1080×1440,2x 导出")并请确认;有特殊要求直接报 px/mm/inch,agent 换算进尺寸预设。**用户不改就用默认,但不许不问。**

**Q3 · 视觉风格?**
➡️ 从风格清单推荐一个 + 一句话理由;用户描述气质("想要高级感")时由 agent 匹配最近风格并说明。

**Q4 · 配色?**
➡️ 有品牌色给 hex;没有 → 风格默认 tokens 或 style-system 八组色板选一组推荐。

**Q5 · 素材从哪来?**
➡️ 有产品图/吉祥物/食品照 → 走抠图管线(首选);没有 → ①图库(Pexels/Pixabay 干净授权)②爬虫(自动标 `版权风险-`)③纯 CSS 图形。食品/人物类海报必须真实素材(见 materials.md)。

**Q5.5 · 有没有明确「不想要」的?(反参照,可选)**
➡️ 一句话即可:"不要蓝紫渐变""不要出现人物""别太促销腔"。反参照直接写进分册禁则优先级最高位,
是消除 AI 默认味成本最低的手段(方法源自 stylekit 的 antiReferences)。

## 追问纪律

1. **一次打包问完**五问(或触发规则要求的子集),禁止挤牙膏式一问一答。
2. 每问带推荐项;用户可整句回「全按推荐」。
3. 用户只答部分 → 空缺用推荐值,**开工前复述全部假设**("按这些做:用途小红书封面、尺寸 1080×1440、风格①、暖纸色板、图库素材,不对喊停")。
4. 最多追问一轮;第二轮仍无有效回答 → 按推荐做,交付时列出所有假设。
5. 复刻/换风格任务的追问同样复述确认后再动工。
