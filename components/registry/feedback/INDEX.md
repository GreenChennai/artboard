# 状态与反馈组件索引

> 海报里的"反馈件"不是交互态,而是**语义标记**:它说明这条信息的状态(新/限时/售罄/提示)。

| 组件 ID | 用途 | 加载条件 |
| :--- | :--- | :--- |
| `feedback.badge` | 徽章 / 角标:"NEW""限时""第 3 期""售罄" | 需要在角落挂一个状态标记,且不想让它抢主标时 |
| `feedback.tag` | 关键词标签胶囊:话题/品类/人群 | 需要罗列 2–6 个短词让画面"可扫读"时 |
| `feedback.alert-strip` | 提示条 / 公告条:一行注意事项 | 有"必须说但不能抢戏"的补充信息(改期/免责/入口)时 |
