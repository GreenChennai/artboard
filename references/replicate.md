# 图片复刻协议(1:1 复刻 / 参考风格)

> 目标:用户丢来一张参考图,产出**布局、配色、字体气质、文案逐字还原**的 HTML 海报,
> 并通过「原图 vs 复刻图」并排比对自检。视觉识别优先级见 materials.md(Agent 视觉优先)。

---

## Step R1 · 读图拆解(参考图只读一次,输出结构化拆解)

用自身视觉能力(或 vision_mode=local 时的本地 VQA/OCR)按顺序拆解,写成拆解笔记:

1. **画布**:宽高比(量像素比例)→ 匹配尺寸预设(xhs/kv/…)。
2. **版式骨架**:画几个分区?每区的位置与占比(用百分比写,如"标题区:上 0–18%,左右满宽")。
3. **逐字文案**:所有可见文字**逐字抄录**(这是 OCR 环节;不确定的字标注 ▲待确认)。
4. **色彩**:采样 5 个 hex(底/主文/主色/强调/辅助),标注采样位置。
5. **字体气质**:标题衬线还是黑体?字重?有无斜体/描边/渐变?→ 到字体库匹配最接近款(≤2 候选)。
6. **装饰语言**:贴纸/线框/编号徽章/照片处理方式/噪点纹理…
7. **视觉动线**:第一眼看哪、第二眼看哪(决定元素权重)。

## Step R2 · 文案与素材核对

- 复刻模式的文案**来自参考图本身**(逐字);用户补充/替换的文案按用户为准。
- 参考图中的照片:无法 1:1 还原原图照片 → 按**同主题同构图**从素材库取(风格复刻),
  或请用户提供原图素材(内容复刻)。intake 时说明选择了哪种。
- 参考图中的品牌 logo:占位框 + 备注,不伪造。

## Step R3 · 构建

- `scaffold.py` 建项目(尺寸按 R1 匹配的预设)。
- 按拆解笔记写 HTML:分区结构 → tokens(采样色)→ 字体 → 逐字文案 → 装饰。
- 特效从 effects/title-fx 取配方;参考图有噪声/纸纹等质感别漏。

## Step R4 · 并排比对自检(复刻模式专属)

```bash
python scripts/compare.py <参考图> <复刻导出图> -o compare.png
```

- Read 并排图,逐项核对:分区位置/占比、文案逐字、色彩气质、字体气质、装饰件、动线。
- 偏差处理:布局偏差 >5% 或文案有误 → 必修;气质偏差 → 修一轮;细节纹理 → 列为已知差异。
- 比对上限 2 轮(同自检闭环);交付时附 compare.png 给用户自查。

## 忠实度约定

- **默认高保真复刻**(本文档全部规则即为此设计)。
- 用户明说「可以改良/参考风格就行」→ 结构与层级跟随参考,配色字体可按用户品牌替换。
- 参考图分辨率太低导致文字不可辨:逐字抄录改为「按上下文推断」并在交付时列出推断清单。
