# artboard 通用设计护栏(所有风格叠加遵守的硬规则)

> 这里是底线,不是风格。每个风格分册在此基础上叠加自己的 tokens、字体栈与禁则。

---

## 1. 画布纪律(违反 = 导出必翻车)

- `body { margin: 0 }`;唯一顶层容器 `.poster` 使用**固定像素尺寸**(按尺寸预设),`overflow: hidden`。
- **禁止**依赖滚动:没有"往下看"这回事,首屏即全部。
- **交互式海报不做**(X2 边界):点击/悬停/滚动叙事超出"固定画布即全部"的定位(上一条的推论),渲染导出语境下也不存在交互;需要交互形态走 H5 制作工具,artboard 只出静态图与动图。
- **禁止** `position: fixed` / `100vh` / `100vw`——导出语境下语义错误,用画布尺寸代替。
- 内容安全边距:画布四周至少留 6% 宽度的内边距(小红书类被圆角裁切的场景留 8%)。
- 装饰元素允许贴边出血,但**文字和 logo 永远在安全边距内**。

## 2. 编辑纪律 + CRAP 四原则

- **密度目标 4/10**:每个元素都要挣得自己的位置;最高质量的动作通常是删减(系统化执行见 `references/revision-protocol.md` §3 减法阶梯)。
- **强调色纪律**:强调色只给读者最先看的 1–2 个元素。到处强调 = 没有强调。
- 一张图**只有一个视觉焦点**;层级最多 3 层(主标 / 辅文 / 标签)。
- 无阴影的廉价堆叠、无意义的通用圆角卡片阵列——每处阴影和圆角都要有理由。
- 文字即界面:文案逐字来自用户或经用户确认,**不编造数据、不虚构促销条款**。
- **不猜着开工**:输入缺项就问(intake.md Brief Gate 检查单),缺失 ≥1 强制补齐一轮;
  仅「直接做」可跳闸且须假设清单请确认(铁律 8)——编内容以外的"编前提"同样是编造。
- **CRAP 自检口诀:「靠不齐、不重复、差不多」——出现任何一个,画面就废了**:
  - **C 对比**:不一样就要明显不一样(标题 ≥ 正文 1.5–2 倍);"差一点点"比"没差别"更糟;
  - **R 重复**:同一字体组合、同一色板、同一圆角、同一图标风格贯穿全图;
  - **A 对齐**:没有元素可以随便放;整图只用一种主对齐;
  - **P 亲密**:相关的靠在一起,组内间距 < 组间距。

## 3. 排版规则(吸收 Müller-Brockmann 网格系统 + W3C clreq)

- 字号阶(以画布宽 1080 为基准,其他宽度等比换算):主标 88–160,副标 40–56,正文 26–32,标签 20–24,页脚 18–20。长图(2400 宽)整体 ×1.6 起步。
- **字号阶梯用比例生成,不要随手敲**:r=1.25(通用)或 r=1.414(海报展示型)。基准 16px 时:16→20→25→31→39→49。
- 行高:标题 1.1–1.3;正文 1.6–1.8(中文黄金组合:16px + 1.75 行高 + 每行 30–35 字)。
- 中文字距:大标题 0.02–0.06em(松弛大气);锐利促销风可 0 或负字距。**正文禁止负字距**。
- 每行正文 ≤ 22 字;段落宽度 ≤ 画布宽 70%。
- 字体配额:整图 ≤ 3 款(标题/正文/数字各司其职),从字体库选,两级筛查见 `fonts/README.md`。

### 3.1 网格搭建流程(顺序不能反)

**先定正文字号 → 再定栏宽与行距**(反过来做必出"字排不进去")。版心页边距经典比
内:上:外:下 = 2:3:4:6,版心位置比几何中心**高约 1/10**(完全居中会"往下掉")。
元素全部吸附栏与基线;检查是否有元素"没有归属"。

### 3.2 中文排版三条底线(clreq)

1. **行首行尾禁则**:句读点(。,、;:?!)与收尾引号/括号**不得出现在行首**;
2. **中西文混排**:中文与西文/数字之间加 1/4 空格(`共计 24 帧`);
3. **中文三不**:不拉长压扁汉字、不用假粗体/假斜体(用真字重)、长文不排斜体。
   对齐:长文左对齐首选;居中只用于标题/短句;两端对齐需 `text-justify: inter-ideograph`。

## 4. 色彩规则(Itten 色彩对比 + 60/30/10)

- 全部颜色走 `:root` tokens(`--c-ink/--c-bg/--c-primary/--c-accent/--c-muted`),禁止散落裸 hex。
- 主色 60 / 辅助 30 / 强调 10;强调色即"强调色纪律"里的 1–2 个元素。
- **Itten 面积比**:亮色小面积、暗色大面积(黄:紫面积 = 1:3,橙:蓝 = 1:2);
- **高级感公式**:低饱和底 + 一点高饱和(饱和度对比);
- 文字禁纯黑(从 `#111` 起步),底色慎用纯白(从 `#faf7f2` 起步);正文对比度 ≥ 4.5:1(大字 3:1)。
- 禁「蓝紫渐变 + 发光」组合(最大众脸的 AI 味);风格分册另有禁则叠加。

## 5. 去 AI 味约束

- **"不像 AI 生成的设计"是最高优先级审美约束**。自检问句:这张图截到社交平台,会不会被说"一眼 AI"?
- 禁 emoji 当图标——用 `assets/icons/` 的 Tabler SVG 内联。
- 禁 HTML 默认样式裸奔:默认列表符号、默认链接蓝、默认滚动条、浏览器默认按钮。
- 装饰必须服务层级或叙事,禁止随机堆砌;贴纸/胶带/手写批注要"像人贴上去的"(轻微旋转 -3°~3°)。
- 网格可以打破,但要打破得**故意**(明显的错位、出血、裁切),不是不小心。

### 5.1 AI 味七宗罪(【机检】`check_slop.py` 阻断)

> 来源:open-design `craft/anti-ai-slop.md` + `apps/daemon/src/lint-artifact.ts`(Apache-2.0)。
> **每条硬规则都必须能指出"谁来查"** —— 规则文件与机检脚本谁管什么,对 Agent 诚实
> (上游的契约写法:标 `auto-enforced by the linter` 还是 `guidance, not auto-checked`)。
> 【机检】= `scripts/check_slop.py` 会拦;【目检】= 只能人/Agent 看图判断。

| # | 罪状 | 判据 | 谁查 | 修法 |
|---|---|---|---|---|
| 1 | **默认 LLM 强调色** | 出现 `#6366f1 #4f46e5 #4338ca #3730a3 #8b5cf6 #7c3aed #a855f7` 之一 | 【机检】`ai-default-indigo` | 换成项目 `--c-accent`;确要 indigo 就写进 `:root` token(那就成了设计决策) |
| 2 | **紫蓝 / 蓝青「信任渐变」** | `linear-gradient(...)` 里含紫/violet/indigo,或同时含蓝与青停靠点 | 【机检】`purple-gradient` / `trust-gradient` | 换平面底或单一强调色;层次靠留白与字号,不靠渐变 |
| 3 | **emoji 当图标** | ✨🚀🎯⚡🔥💡 等出现在 `<h*>`/`<button>`/`<li>`/`*icon*` 元素内 | 【机检】`emoji-icon`(正文散文里的 emoji 不算) | 换 `assets/icons/` 的 Tabler SVG(1.5–1.75px 描边、`currentColor`)或删掉 |
| 4 | **标题回落到系统无衬线** | `h1/h2/h3` 或 `.h-hero/.h-xl/.h-lg/.h-md` 规则里硬编码 Inter/Roboto/Arial/system-ui | 【机检】`sans-display` | 标题走 `var(--font-display)`(字体库的性格款);只有"科技实用/现代极简"方向才允许系统无衬线且要写进风格分册 |
| 5 | **圆角 + 左彩边卡** | `.x{...border-left:Npx solid...;...border-radius:≥1...}` | 【机检】`left-accent-card`(P1;引用卡/要点卡是合法用法) | 二选一:去圆角,或去左彩边改四周细描边 |
| 6 | **编造指标** | "10× faster""99.9% uptime""效率提升 N 倍""零故障"等营销空话句式 | 【机检】`invented-metric` | 删掉,或换占位等用户给真数(**铁律 4**:文案逐字来自用户) |
| 7 | **填充文案** | `lorem ipsum` / `feature one/two/three` / `placeholder text` / "待补充·占位文本" | 【机检】`filler-copy` | 换真实文案;没文案就删这一块,用构图填版面 |

**软信号(P1,机检给提示不阻断)**:Hero→Features→Pricing→FAQ 千篇一律【目检】;
外链占位图 CDN【机检 `external-ref`,本技能按铁律 2 直接升 P0】;
`:root` 外裸 hex > 12【机检 `raw-hex`】;accent 滥用(正文引用 > 6 次)【机检 `accent-overuse`】;
大写无字距【机检 `all-caps-no-tracking`】;中文标题行高 <1.3【机检 `cjk-leading`】;
中文标题负字距【机检 `cjk-negative-tracking`】。

**怎么加灵魂而不犯规**:目标是 **~80% 成熟手法 + ~20% 独特决定**。那 20% 该花在:
一个大胆的视觉动作(一个字体决定 / 一个比例 / 一次出血)、有语气的小文案
("开始记录"胜过"立即使用")、一个用户会记住的微交互、一个只有真用过产品的人才会放的细节。
判据:**截一张图给不相干的人看,他能说出这是哪个品牌/哪件事 —— 才有灵魂;说不出,就是模板。**

**例外怎么留**:确要保留某条(如促销风的中文负字距),在 HTML 里写
`<!-- slop-ignore: cjk-negative-tracking -->`,并在交付报告里说明理由 ——
豁免是**显式且要交代**的,不是静默放过。

### 5.2 其他【机检】铁律项(不属七宗罪但同属机器可查)

| 规则 | 判据 | 谁查 |
|---|---|---|
| 离线渲染(铁律 2) | `src/href="http(s)://"` 的资源引用、`@import url(http…)`、CSS `url(http…)` | 【机检】`external-ref`(P0) |
| 固定画布(铁律 1) | `position:fixed` / `100vh` / `100vw`(模式 H 的 H5 页自动降 P1) | 【机检】`canvas-discipline` |

### 反 AI 味自检 12 条(交付前逐条过)

1. 没有「紫→蓝」渐变(大众脸第一名)。**【机检 `purple-gradient`/`trust-gradient`】**
2. 没有 AI 高发字体当主标:Inter/Roboto/思源默认字重直出——主标必须用字体库的"性格款"。**【机检 `sans-display`;字体是否真加载见 §9.4】**
3. 没有渐变文字滥用(烫金/铬金等 fx 类除外,且一图 ≤1 处)。**【目检】**
4. 没有等权重标题阵列——层级必须拉开 ≥1.5 倍字号差。**【目检】**
5. 没有嵌套卡片(卡片里套卡片)。**【目检】**
6. 没有默认居中构图当唯一构图——居中要有理由(仪式感/对称主体)。**【目检】**
7. 强调色 ≤2 处,且给了最先该看的东西。**【机检 `accent-overuse` 粗筛(正文引用 ≤6 次)+ 目检确认可见处数】**
8. 没有装饰性英文小字(如无意义的 "DESIGN / ART / 2026" 眉题堆砌)。**【目检】**(边界注:禁的是装饰性无意义小字;有信息量的双语——译文/品牌名/专名/可读副题——见 `references/bilingual-typography.md` §七)
9. 正文行宽 ≤ 22 个汉字,行高 1.6–1.8(中文)。**【目检】**——行高下限的另一半(标题 ≥1.3)是 **【机检 `cjk-leading`】**
10. 没有均质圆角卡片铺满画面(所谓"卡片阵列墙")。**【目检】**——其中"圆角+左彩边"这一形是 **【机检 `left-accent-card`】**
11. 留白 ≥ 25%,且留白位置有意图(呼吸位在焦点旁,不是四边均匀镶边)。**【目检】**
12. 删掉任何一个元素都会更差吗?——如果删掉没影响,删掉它。**【目检】**

> 上表凡标【机检】的,都对应 `scripts/check_slop.py` 的一条规则(规则表见该脚本
> `--list-rules` 或文件头);标题里出现 `【目检】` 的,机器查不了,**必须看图**。

## 6. 素材与资源

- 用户图片放 `src/img/`,`object-fit: cover`;多图色调不统一时加统一滤镜(duotone/低饱和)。
- 图表用 `src/vendor/echarts.min.js`(数据长图风格);图标内联 SVG(引用 `assets/icons/<name>.svg` 内容)。
- **离线优先**:HTML 不引任何 CDN;需要第三方资源时复制进项目 `src/vendor/`。
- 动图已启用(M2):规范见 `references/animation.md`;静态海报仍不依赖动画中间帧。

## 7. 文字溢出修复优先级(自检发现溢出时按序执行)

**先分清两种溢出,处置完全不同**:

| 类型 | 现象 | 处置 |
|---|---|---|
| **出卡片框** | 文字画到卡片背景/边框之外 | 走下面 **0 → 5**(先修结构) |
| 出画布 | 内容被 `.poster{overflow:hidden}` 裁掉 | 走 **1 → 5** |

0. **让框跟随内容(结构修复,首选)**:`height` → `min-height`;去掉 `top`+`bottom` 双锁;
   长文案加 `line-clamp`。完整写法与对照表见 **`card-layout.md`**。
   ⚠️ **不要**用 `overflow:hidden` 去"兜住"文字——那会把字裁掉一半,比出框更难看。
1. 减小正文字号(下限:知识卡 16px / 常规 26px,不许再低);
2. 减小行高(下限 1.4);
3. 减小卡片内边距;
4. 换更紧凑布局(双栏替单栏);
5. 精简文案——**必须先征得用户同意**。

> **预防优先于补救**:按 `card-layout.md §三` 的卡高公式**先估后写**,并给同组卡片
> 统一 `min-height` 到最大估高。出框后再缩字号是下策(会破坏层级一致性)。

## 8. HTML 语义规范

- 标题用 `<h1>`–`<h3>`,列表用 `<ul>/<ol>`,卡片用 `<section>`,装饰用空 `<div>`+CSS;
- `.stage` 上开 `-webkit-font-smoothing:antialiased; text-rendering:optimizeLegibility`;
- 修改交付过的项目时只动相关部分,重跑自检,旧版本留 `index_v2.html` 备份。

## 9. 出图前自检清单(每轮必过,见流水线 Step 6;量化打分见 design-review-rubric.md)

1. 主标 3 米外可读?信息层级清晰?
2. 文字无溢出、无截断、无换行孤字?
3. **两条机检都跑过且 `ok:true`?** —— 分工不同,都要:
   - `scripts/check_overflow.py <proj>/src`(几何)—— 唯一能看见"文字出卡片但没出画布"的手段
     (`min-height` 用对了吗?有无定高文字容器?越界的是不是只有带 `data-allow-overflow` 的装饰?)
     视频卡/会被叠字幕的动图追加 `--safe-area auto` 查内容有没有进字幕带
     (要降档时先看 `video-safe-area.md §二` 的代价)
   - `scripts/check_slop.py <proj>/src`(气质/铁律,静态 3–5s 零 token)—— 默认 indigo / 紫蓝渐变 /
     emoji 图标 / 编造指标 / 填充文案 / 标题落系统字体 / 引用 http 资源(铁律 2)/
     固定画布 100vh·fixed(铁律 1)/ 中文标题行高 <1.3。P1 是建议(大写字距、裸 hex、
     中文负字距…),加 `--strict` 才算阻断
4. 字体确实加载(不是系统回退)?数字用对了字体?
5. 对比度达标?强调色只出现在 1–2 处?
6. 装饰是否抢了主体?删掉一个元素画面会更好吗?
7. 画布尺寸/倍率正确?导出 PNG 尺寸 = 画布 × scale?
8. 动图/视频卡:内容全部落在安全区内?(`video-safe-area.md`,**含左右 184px**)
9. "一眼 AI"测试通过?
