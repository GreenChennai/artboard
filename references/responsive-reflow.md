# artboard 一稿多尺寸重排(reflow)

> **何时读**:同一设计要出多个尺寸时(3:4 + 1:1 + 9:16;或 KV 16:9 + 社媒竖版)。
> 把「不许拿 3:4 硬裁」这条禁令变成**怎么重排**。
> 画布 px 与导出倍率查 `sizes-common.md` / `scaffold.py` SIZES,不在本册。

---

## 〇、先判断:这是「同一版式」还是「同一套设计」

| 情况 | 做法 |
|---|---|
| **同一版式,不同尺寸**(信息完全一样,只换画布) | 走本册 reflow |
| **同一套设计,不同用途**(信息要增删,如封面 vs 内页) | **新建文件**,不是 reflow;`xhs-cover.md` 的组图工作流另算 |
| **只改导出倍率**(1080→2160) | 不需要 reflow,改 `--scale` 即可 |

判据:**改完尺寸后,是否需要增删任何一条文案?**需要 → 不是 reflow,是新版式。

---

## 一、四类元素:哪些能缩,哪些必须动

| 类别 | 元素 | 跨尺寸处理 |
|---|---|---|
| **A 可等比缩放** | 背景纹理、装饰图形、渐变、噪点、边框 | 直接按比例缩放,零思考 |
| **B 需重新定位** | 主标、副标、CTA、二维码、logo | 位置按新画布的三分线/栏线重算;字号按 §二 换算 |
| **C 需重新排布** | 多条目列表、网格卡片、分栏正文 | 栏数可能要变(见 §三),条目可能要拆/合 |
| **D 需重新裁切** | 照片、插画、人物 | 见 §四 |

**记忆**:装饰随便缩(A),文字重新摆(B),内容重新排(C),图片重新裁(D)。

---

## 二、字号阶换算:按「栏宽」不按「画布宽」

> `guardrails.md:30` 说「其他宽度等比换算」,`data-longform.md:25` 说「2400 宽 = 1080 ×1.8」,而 2400/1080 = 2.22 —— **两个系数都不对**。
> 根因:字号该跟**阅读距离和栏宽**走,不是画布宽。2400 宽的长图是**近距离**看,字号不该 ×2.22。

**换算公式**(ADR-0014):
```
新字号 = 母阶字号 × √(新画布宽 / 1080)      约到 2px 整数
```

| 目标画布宽 | 系数 | 母阶正文 28px → | 母阶主标 128px → |
|---|---|---|---|
| 800 | 0.86 | 24px | 110px |
| 1080 | 1.00 | 28px | 128px |
| 1240(A4) | 1.07 | 30px | 137px |
| 1440 | 1.15 | 32px | 147px |
| 1754(三折页) | **按栏宽算**(见下) | — | — |
| 1920(KV) | 1.33 | 37px | 170px |
| 2400(长图) | 1.49 | 42px | 191px |

**例外**:多栏版式(三折页 1754 宽三栏、杂志网格)按**栏宽**代替代画布宽:
```
三折页栏宽 ≈ (1754 − 2×40) ÷ 3 = 558
系数 = √(558 / 1080) = 0.72   → 正文 20px
```
这与 `formats/trifold.md:27` 给的「主标 110–150」是吻合的(而不是按画布宽算出 1754/1080 → 主标 208)。

**冲突处理**:品类分册(`formats/`)与风格分册(`styles/`)已给出的字号数值**优先**,本公式只在**分册没写**时用。

## 三、栏数:画布比例决定

| 画布比例 | 建议栏数 | 说明 |
|---|---|---|
| 1:1(方图) | 4–6 | 方图信息量最少,栏多会碎 |
| 3:4(小红书) | 6 | 默认 |
| 9:16(竖屏/故事) | 4 | 竖向长,栏一多就变面条 |
| 16:9(KV/横幅) | 12 | 横向空间大,12 栏才有排布自由 |
| 长图 2400×auto | 12 | 每栏 ≤200px 宽 |

**跨比例重排的栏数动作**:
- 3:4 → 1:1:栏数 6 → 4;把 2 栏宽的卡片改成整宽
- 3:4 → 9:16:栏数 6 → 4;**条目从横排改竖排**,或条目数 >6 时拆成两张
- 16:9 → 9:16:栏数 12 → 4;**左右分栏必须改上下堆叠**(横屏的左右结构在竖屏里不成立)

## 四、图片:三种策略,按主体重要性选

| 策略 | 做法 | 适用 |
|---|---|---|
| **裁切**(默认) | `object-fit: cover` + 调 `object-position` | 主体居中、背景可牺牲 |
| **留白**(主体不可裁时) | `object-fit: contain` + 补同色底 | 产品图、logo、带文字的图 |
| **换图**(比例差太大时) | 换一张更适合新比例的 | 3:4 → 16:9 横幅,竖构图硬裁必废 |

### 4.1 `object-position` 速查(沿用 `xhs-cover.md:101-102`)

| 主体位置 | 值 |
|---|---|
| 顶部主体(人脸在上) | `center 30%` |
| 半身人像 | `center 55%` |
| 全身人像 | `center 65%` |
| 前景静物/美食俯拍 | `center 70%` |
| 居中产品 | `center center` |

### 4.2 硬红线

- **产品本体不许裁变形**:只能裁背景,不能压扁/拉长(违反 `guardrails.md` §3.2「不拉长压扁汉字」的精神,产品同理)
- **人脸不许裁到眼/口**:这是最常见的翻车点
- **含文字的图片不许裁字**:宁可留白
- 3:4 → 16:9 这类**跨度极大**的比例,优先**换图**而不是裁

## 五、安全区与出血:换画布必须重算

| 项 | 规则 |
|---|---|
| 安全边距 | 四周 ≥ 画布宽 **6%**;被圆角/UI 裁切的场景(小红书封面、故事)≥ **8%**(`guardrails.md:12`) |
| 视频安全区 | 9:16 顶 230px / 底 576px / 左右 118px(`animation.md:291`) |
| 印刷出血 | 满版底色外延 **3mm**;关键文字距裁切线 ≥5mm(`print-cmyk.md:21`) |
| 折页补偿 | 三折页内板收窄 **1–2mm**(`sizes-common.md:31`) |

**重排时最容易漏的**:安全边距是**百分比**,画布从 1080 换成 1920 时,6% = 65px 变成 115px —— 直接改画布宽而不重算 padding,元素就会贴边。

```css
:root { --safe: 8%; }        /* 用百分比,不要写死 px */
.poster { padding: var(--safe); }
```

## 六、母版 + 变体工作流

```
<slug>-master.html     ← 母版:信息结构 + 文案(唯一真相源)
<slug>-34.html         ← 1080×1440
<slug>-11.html         ← 1080×1080
<slug>-916.html        ← 1080×1920
project.json           ← 每个变体的宽高/scale 单独登记
```

**规则**:
1. **母版只存信息结构**,不存画布样式。变体文件里写各自 `:root` 的画布尺寸与字号阶。
2. **文案改动只改母版**,然后同步到变体 —— 不许在变体里改文案(必然不同步)。
3. 变体之间**允许骨架不同**(3:4 用三分,9:16 用中轴),但**必须同一套 tokens、同一套字体、同一套装饰语言**(CRAP 的 R 重复)。
4. 每个变体独立过 `design-review-rubric.md`,**不能只审母版**。

## 七、跨比例检查清单(出图前)

| 比例对 | 必查 |
|---|---|
| 3:4 → 1:1 | 条目是否从"竖排 6 条"变成"塞不下"?需要减到 4 条或拆图 |
| 3:4 → 9:16 | 底部是否有大片空?(9:16 比 3:4 高 33%,要么加内容要么加大留白,不能硬撑) |
| 16:9 → 9:16 | 左右分栏是否改成了上下堆叠? |
| 任意 → 1:1 | 主标是否过长?(方图纵向空间小,主标 >12 字要考虑断行或压缩) |
| 任意 → 印刷 | 是否转成 300dpi?RGB 极值色是否替换?(见 `print-cmyk.md`) |

**通用三条**:
1. 每个变体的安全边距都重算过(是百分比,不是 px 写死)?
2. 图片在每个变体里都重新看过 `object-position`,主体没被切?
3. 每个变体的字号都按 §二 换算过,不是把 1080 的字号直接搬过去?

## 八、正反例

### ✗ 反例:改画布了事

> 小红书 3:4 封面做好后,把 `.poster` 的 `width/height` 改成 1080×1080 直接导出。

后果:底部 CTA 被裁、主标贴顶(安全边距是写死的 86px,1:1 下仍是 86px 但画布窄了)、列表第 5–6 条溢出被 `overflow:hidden` 吃掉。

### ✓ 正例:正确 reflow

> 3:4 → 1:1:
> ① 栏数 6 → 4,条目 6 条压到 4 条(第 5、6 条并入"更多")
> ② 主标 128px → 128px(画布宽没变,只变高,字号不动)
> ③ 安全边距 8% 重算(=86px,画布宽未变,值不变,但**高度方向**的 padding 从 8%×1440 变成 8%×1080)
> ④ 底部 CTA 从 (68%, 88%) 移到 (68%, 84%)
> ⑤ 照片 `object-position` 从 `center 55%` 调为 `center 45%`(方图顶部空间少了)
