# artboard 数据可视化规范

> **何时读**:版面出现图表 / 数据卡 / 排行榜 / 漏斗 / 时间轴数据时。
> 长图品类仍以 `data-longform.md` 为准,本册是它的超集。
> 数字本身怎么写(千分位/小数位/单位空格)见 `numeric-typography.md`。

---

## 一、图表选型:由「论点形态」决定,不是由数据类型决定

| 你想说的论点 | 选它 | 别选 |
|---|---|---|
| **随时间变化 / 趋势** | 折线、面积图 | 柱状(时间点多时看不清趋势) |
| **构成占比**(部分-整体,≤5 项) | 堆叠柱、**环形** | 饼图(见 §7) |
| **多方对比**(谁大谁小) | **分组柱 / 条形**(横向) | 折线(类别无顺序) |
| **排序 / 排名** | 横向条形(降序) | 纵向柱(标签太长会转 90°) |
| **转化 / 流失** | 漏斗 | 折线 |
| **分布 / 相关** | 散点、直方图 | 饼图 |
| **要素拆解 / 归因** | 鱼骨、树图 | 柱图 |
| **单一巨数** | **大数字卡**(不是图表) | 任何图表 |
| **两个变量的关系** | 散点、气泡 | 双 Y 轴折线(见 §7) |

> 判断口诀:**比大小 → 柱;看变化 → 线;看占比 → 环;看流程 → 斗**。
> 一句话能说完的数据,**不要用图表**——用大数字卡(见 §6)。

## 二、坐标轴:事故高发区

### 2.1 刻度

| 项 | 规范 |
|---|---|
| 刻度数量 | 4–6 条(Y 轴),不要 10 条 |
| 刻度值 | 取**整齐数**:`0 / 50 / 100 / 150`,不要 `0 / 37 / 74 / 111` |
| 刻度文字 | 与数据同形态 `tabular-nums`;字号 = 轴注字号(`data-longform.md:43`:2400 宽长图轴注 30px) |
| 刻度线 | 与网格线**二选一**:有网格线就不画刻度线(重复) |
| 单位 | 写在**轴标题或首个刻度上**(`万元`),不要每个刻度都带 |

### 2.2 零基线(柱状图硬规则)

- **柱状图 / 条形图 / 面积图:Y 轴必须从 0 开始**。截断会放大差异,是数据误导。
- 折线图**可以**不从 0 开始(它表达变化率不是绝对值),但必须:
  - 在轴旁标注「Y 轴起点非 0」或改用面积图
  - 或把折线改柱图(老实从 0 起)

### 2.3 截断轴(确需时)

数值集中在高位(如 92–98)且用柱图必须截断时:
```
Y 轴:92 ─┐
        ╱ ← 断点符号(双斜线 / 波浪),位置在 0 与 92 之间
      0 ─┘
```
- 断点必须**可见**(双斜线或波浪线),不许静默截断
- 断掉的区间 ≥ 轴总长的 1/8,否则看不出是断的

### 2.4 网格线

```css
grid: { lineStyle: { color: 'rgba(16,26,46,.08)', width: 1 } }
```
- 只画**横向**网格线(辅助读 Y 值);纵向网格线只在时间序列且刻度稀疏时才加
- 透明度 `.06–.12`,**不许实线深色**(抢数据)
- 零基线可以加深一档(`rgba(...,.18)`)

## 三、图例:能删就删

| 情况 | 做法 |
|---|---|
| 只有 1 个系列 | **删掉图例**,标题里写清楚 |
| 系列 ≤3 且空间够 | **直接标注在图形旁**(引线标签),比图例好得多 |
| 系列 4–6 且不好直接标 | 保留图例,放**顶部或右上**,不放底部(视线要来回跑) |
| 系列 >6 | **重新分组/拆图**,不要堆图例 |

图例视觉:色块 + 文字,**色块与文字间距 = 文字字号的 0.5 倍**;图例项之间间距 = 文字字号的 1.2 倍。

## 四、系列色:≤4,色盲友好

```js
// ECharts 主题色(与 color-contrast.md §5.3 一致)
color: ['oklch(58% 0.17 40)', 'oklch(72% 0.15 85)',
        'oklch(62% 0.13 220)', 'oklch(48% 0.10 300)']
```
```css
:root{                                   /* 纯 CSS 图表 / SVG 用 */
  --s1: #d55e00; --s2: #f0b429;
  --s3: #3a8fd0; --s4: #7b4ea8;
}
```

| 规则 | 说明 |
|---|---|
| 系列 ≤4 | 超过 → 重新分组或拆图(`data-longform.md:57` 同规) |
| 相邻色 OKLCH L 差 ≥0.12 | 去色后仍可分辨(`color-contrast.md` §5.2) |
| **单系列强调** | 一个系列用主色,其余用中性灰(`--c-muted`)——比给 4 个颜色更有重点 |
| 语义色固定 | 涨/跌、好/坏用**约定色**(红涨绿跌 or 反向,全图统一),不随风格变 |
| 图表线 ≥3:1 | 与背景的对比度(`color-contrast.md` §1 图形类) |

## 五、标注与标签

### 5.1 数据标签:只标关键三项

`data-longform.md:43` 规则:**只标最大 / 最小 / 最新**,其余靠轴读。

- 柱顶标签字号 = 轴注字号 的 **0.9 倍**,不要比轴注大
- 标签与柱顶间距 = 柱宽 的 **1/4**
- 标签遮挡图形时,**放到柱内**(白色文字)而不是硬塞在外面

### 5.2 标题:写结论,不写指标名

```
✅ 「新客反超老客,首次出现在 Q3」      ← 结论
❌ 「新客数与老客数对比」               ← 指标名
❌ 「柱状图」                          ← 图表类型
```
- 图表标题 = 一句完整主张,带主谓宾
- 副标题(可选)= 口径说明:「统计口径:2026 年 1–8 月,去重后」

### 5.3 来源注

- 字号 ≥ 该风格正文最小字号的 0.85 倍,**不可省略**(`data-longform.md:59`)
- 位置:图表正下方,与图表间距 = 基线单位的 0.5 倍
- 内容:`数据来源:XX 研究院(2026.08)`,有口径就写口径

## 六、大数字卡:不是图表,但最常用

```html
<div class="stat">
  <div class="stat-num">1.28<span class="unit">亿</span></div>
  <div class="stat-label">全年活跃用户</div>
  <div class="stat-delta">同比 +43%</div>
</div>
```
```css
.stat-num { font-size: 200px; font-weight: 900; line-height: 1;
            font-variant-numeric: lining-nums; letter-spacing: -0.01em; }
.stat-num .unit { font-size: .34em; font-weight: 500; margin-inline-start: .12em; }
.stat-label { font-size: 32px; opacity: .72; margin-top: 24px; }
.stat-delta { font-size: 28px; color: var(--c-accent); margin-top: 12px; }
```

| 规则 | 数值 |
|---|---|
| 数量级 | 中文用万/亿(`numeric-typography.md` §2.2) |
| 单位字号 | 数字的 **30–40%** |
| 数字字距 | **0 或 −0.01em**(大数字零字距,见 `data-longform.md:23`) |
| 标签 | 数字字号的 **15–20%**,放数字下方 |
| 一屏大数字卡 | ≤3 个;超过就改图表 |

## 七、禁则

| 禁 | 原因 | 替代 |
|---|---|---|
| **3D 图表** | 透视让后排水柱看起来更矮,读数错误 | 2D + 分组 |
| **双 Y 轴** | 两条线的交点位置由轴刻度随意决定,可造出任意结论 | 拆成两张图,或归一化成指数 |
| **饼图 >4 扇区** | 小扇区角度分不出 | 横向条形(降序) |
| **甜甜圈图 >2 环** | 环与环无法比较 | 堆叠柱 |
| **面积图叠加 >3 层** | 互相遮挡,基线不可读 | 分组柱或小倍数图 |
| **图表用渐变填充** | 渐变区域无法准确读值 | 纯色填充 |
| **数据标签全标** | 视觉噪声 | 只标最大/最小/最新 |
| **Y 轴不从 0 的柱图**(无断点标记) | 数据误导 | 从 0 起 / 加断点 / 改折线 |
| **图表转矢量时用了 `mix-blend-mode`** | 色偏(`vector-export.md` 五条禁令) | 纯色叠加 |

## 八、图表与版面

| 项 | 规范 |
|---|---|
| 图表与标题间距 | 基线单位 × 0.5 |
| 图表与来源注间距 | 基线单位 × 0.5 |
| 图表与**相邻板块**间距 | 基线单位 × 2(板块间距 = 组内间距 2–4 倍,`typography-rules.md:65-68`) |
| 图表宽 | 不超过内容栏宽;长图列宽 ≤2000px(`data-longform.md`) |
| 图表高 | 宽高比 **16:9 ~ 4:3**;横条形图可纵向延展 |
| 留白 | 图表内部留白 ≥ 图表面积 25%,不要撑满 |

**配色一致性**:图表色必须走 `:root` tokens,**禁止裸 hex 散落**(铁律 + `guardrails.md:52`)。

## 九、ECharts 落地(数据长图/看板)

```js
const theme = {
  textStyle: { fontFamily: '"Source Han Sans SC", system-ui', fontSize: 30 },
  color: ['#d55e00','#f0b429','#3a8fd0','#7b4ea8'],
  grid:   { left: 120, right: 80, top: 100, bottom: 120, containLabel: true },
  xAxis:  { axisLine: { lineStyle: { color: 'rgba(16,26,46,.25)' } },
            axisLabel: { fontSize: 30, color: 'rgba(16,26,46,.62)' },
            axisTick: { show: false } },
  yAxis:  { splitLine: { lineStyle: { color: 'rgba(16,26,46,.08)', width: 1 } },
            axisLabel: { fontSize: 30, color: 'rgba(16,26,46,.62)' } },
  legend: { top: 0, itemGap: 32, textStyle: { fontSize: 30 } },
  tooltip:{ trigger: 'axis' },
};
```
- 用 `containLabel: true`,否则轴标签会被裁切(导出图不可交互,裁了就是没了)
- 导出前必须确认图表**已 settle**:`export.py` 的 `--max-wait` 参数要够(见 `references/export.md`)
- 纯 CSS 图表(小红书/电商风格)优先手写,不引 ECharts(体积 + 风格可控)

## 十、图表自检(8 条)

1. 图表类型匹配论点形态?(§一)
2. 柱图 Y 轴从 0 起?截断有可见断点?
3. 刻度 4–6 条、取整齐数、单位只写一次?
4. 系列 ≤4,相邻色 OKLCH L 差 ≥0.12,去色后可辨?
5. 数据标签只标最大/最小/最新?
6. 标题是**结论**不是指标名?
7. 来源注存在且字号达标?
8. 无 3D、无双 Y 轴、无渐变填充?

> 打分走 `design-review-rubric.md`(并入「B 排版质量」25% + 「C 色彩与对比」20%;数据误导类问题直接判 B 维度 ≤2)。

> **图表动效**(片头/概括里逐系列构建):语法与导出边界见 `video-motion.md §三`「图表构建」——
> ECharts 逐系列淡入或 SVG 描边画出;矢量交付时内联 SVG 会栅格化(`vector-drawing.md §4.5`)。
