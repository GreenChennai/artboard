# MiSans

| 属性 | 值 |
|---|---|
| 字体文件 | MiSans-Bold.ttf, MiSans-Regular.ttf, MiSans-Semibold.ttf |
| 字重/变体 | Regular/Semibold/Bold(另 12 字重可加) |
| 分类 | 正文可读·标题 |
| 气质关键词 | 现代,圆润,中性,屏幕优化,小米生态 |
| 协议/来源 | 免费商用(小米字体许可)· hyperos.mi.com/font |

## 气质描述
比思源黑更「屏幕原生」的现代黑体:笔画末端微收,灰度均匀,中英混排舒服。
Semibold 是标题甜点字重——比 Bold 清爽,比 Regular 有力。

## 适用
商业海报全能:Regular 正文 / Semibold 标题 / Bold 强调;科技、生活方式、电商类目。

## 慎用
书卷气场合(换思源宋/霞鹜文楷);超大促销字力度不如得意黑。

## 示例句
「海内存知己,天涯若比邻 0123456789」
