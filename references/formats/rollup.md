# 品类规范 · 易拉宝(rollup)

> 介质品类:80×200cm 标准展架(85/120cm 宽按比例换算)。可视距离 1–2m,字号往大了做。

## 画布与导出
- 画布 **2362×5906**(设计稿 50%),**导出 `--scale 2`** → 4724×11811 = 150dpi 印刷标准。
- 导出耗时明显偏长(≈56MP),属正常;WPI 会自动分块拼接。
- 安全边距:左右 12cm(≈560px);**顶部 25cm 与底部 30cm 是视觉弱化区/卷轴盲区**——重要信息放在高度 25%–85% 带内。

## 字号阶(2362 宽画布)
| 元素 | 字号 |
|---|---|
| 主标语 | 340–520px |
| 副标 | 130–180px |
| 正文要点 | 90–120px(小于 90px 观众看不见) |
| 联系方式/二维码区 | 二维码 ≥ 420×420px |
| logo 高 | 200–320px |

## 布局原型(竖版单列,自上而下)
logo → 主标语(1–8 字,占位最大)→ 副标 → 3 个要点(图标+短句,每条 ≤12 字)→ 底部联系方式/二维码。
人流量大的场景:主标语和二维码是仅有的两个"必读项",其余全是辅助。

### 二维码
设计稿放「二维码占位」框即可;终稿前 `python scripts/qr.py generate --data "…" --out src/img/qr.png`(支持品牌色/内嵌 logo,H 级纠错)替换,重导。码宽 ≥ 版面宽 8%,四周留白 ≥1 模块;解析用 `qr.py decode <图>`(本地 zxing,离线),公网图片可走草料 API `read-qr-code`。

## 调性禁则
1. 禁段落文字——易拉宝是海报的极端形态,全部短语化。
2. 要点 ≤3 条;禁贴边、禁进盲区(顶部 25cm/底部 30cm)。
3. 一图一个焦点:主标语字号必须 ≥ 副标 2 倍。
4. 底色与展架画面衔接:背景色铺满画布,禁止留白边(卷轴处露白=废品)。
