# artboard 材质语言分册(纸 · 金属 · 玻璃 · 布 · 木 · 塑料)

> **单一真相源声明(防多真相源)**:
> - 本册管「**什么材质感选什么配方**」:六类常见材质 → 配方对照总表 + 材质使用纪律,是材质层的唯一入口;
> - 单个特效配方的 CSS 全文 → `effects.md`(43 式),本册**只引用不复制**;
> - `fx-` 配方族唯一真相源是 `effects.md`,本册**不新增 fx- 编号**;§二的 `ml-*` 是本册原生的材质写法(material-language),仅当总表无对应既有配方时使用,写法自包含;
> - 厚度/纵深(挤出、浮雕的立体面)→ `depth-3d.md`;位图照片的介质处理(颗粒/半调/扫描线)→ `image-language.md §三`;实体印刷工艺(烫金/UV/击凸/模切)→ `print-production.md`——本册全部配方是**屏幕模拟**,不替代实体工艺。

---

## 0. 第一原则:材质是"角色",不是"滤镜"

先问"这个元素**是什么做的**"(它是一张纸上的海报?一块玻璃后面有光?),再选配方。两个推论:

1. **材质必须自洽**:玻璃拟态卡背后没有色块 = 隐身(`effects.md` 导出注意第 1 条);金属字贴在浅底上 = "漂"。材质感来自**它与环境的光学关系**,不是配方本身;
2. **一图主材质 ≤2 种**。理由:每种介质都在要求观众重新理解"这张图的物理世界",纸+玻璃+木+金属同框 = 世界观打架(点缀级小面积第三种允许,如一枚金箔徽章)。

## 一、材质 → 配方对照总表

> 用法:定下材质 → 查行 → 按列出的既有配方去 `effects.md` 抄 CSS;无对应配方的走 §二 原生写法。

| 材质 | 观感关键词 | 配方(真相源) | 适用题材 | 关键纪律 |
|---|---|---|---|---|
| **纸** | 暖、哑、纤维感 | `fx-paper`(暖纸底)+ `fx-noise`(细噪,multiply);报纸变体 `fx-newsprint` | 手账/文艺/餐饮/出版/邀请函 | 纸感 = 低饱和暖底 + 细噪,**禁配霓虹/铬金**(两种介质打架);白卡纸用 `fx-frosted` 浅底版 |
| **金属** | 冷、亮、硬、反光带 | 铬金字 `fx-chrome`;烫金字 `fx-foil`;要厚度 → `depth-3d.md` 手法 2(分层克隆 + 渐变字 = 金属挤出) | 高端/科技/年终庆/白酒/奖牌 | 金属字只做标题一处(一焦点);**底必须深或重色**,浅底上金属字读不出反光带 |
| **玻璃** | 透、冷、浮 | 深底 `fx-glass`;浅底磨砂 `fx-frosted` | 科技 KV 信息卡、发布会、数码 | **背后必须有实际色块/图**;`backdrop-filter` 导出安全性随 `depth-3d.md §六` 矩阵,导出后必看图确认没隐身 |
| **布/绒** | 软、哑、吸光 | 丝绒 `fx-velvet`;织纹 `ml-weave`(§二) | 奢品/服饰/家居/节日 | 布感靠"暗部吃光"(`inset` 阴影),禁高光硬边;织纹透明度 ≤.08,叠最上层 |
| **木** | 温、糙、条纹 | `ml-wood`(§二)+ 复用 `fx-noise` | 餐饮/家具/自然/手作 | 条纹方向唯一、间距**不等距**(等距 = 印刷品假木纹);木上文字用深棕不用纯黑 |
| **塑料/亚克力** | 光、滑、亮边 | `ml-glossy`(§二);透明感叠 `fx-glass` | 数码/母婴/玩具/促销 | 高光条只 1 条、方向随统一光源(`depth-3d.md §一`);两处高光反向 = "两个太阳" |

## 二、本册原生写法(`ml-*`;总表无既有配方时用)

```css
/* ml-weave 织纹:经纬两组细线交叉模拟布面 —— 叠加层,不承载内容 */
.ml-weave { position:absolute; inset:0; opacity:.07; pointer-events:none; background:
  repeating-linear-gradient(0deg,  rgba(0,0,0,.55) 0 1px, transparent 1px 4px),
  repeating-linear-gradient(90deg, rgba(0,0,0,.55) 0 1px, transparent 1px 4px); }

/* ml-wood 木纹:不等距竖条纹 + 一处节疤色斑;细噪层复用 fx-noise,不重复给 */
.ml-wood { background:
  radial-gradient(16% 26% at 72% 20%, rgba(74,46,20,.28), transparent 70%),
  repeating-linear-gradient(90deg,
    #a97b4b 0 46px, #96683c 46px 58px, #b0834f 58px 118px,
    #8f6136 118px 126px, #a97b4b 126px 178px); }

/* ml-glossy 塑料/亚克力:顶侧一条高光 + 内亮边,光源默认左上(与 --light-deg 同步) */
.ml-glossy { background:
  linear-gradient(160deg, rgba(255,255,255,.30) 0%, rgba(255,255,255,0) 36%),
  var(--c-primary);
  box-shadow: inset 0 1px 0 rgba(255,255,255,.55), inset -1px -1px 0 rgba(0,0,0,.18);
  border-radius: var(--radius, 14px); }
```

## 三、材质使用纪律(带理由)

1. **主材质 ≤2 种/图**(§0,点缀级第三种须 ≤5% 面积)。理由:材质一多,观众的"物理世界"判断互相覆盖,画面立刻杂;
2. **材质计入特效计数**:纹理类材质与特效同算,合计 ≤3(铁律 3)。纸底+噪+烫金字 = 3,已满;
3. **光源一致**:一切高光/反光/厚度方向随 `depth-3d.md §一` 统一光源 tokens;反光带方向矛盾 = 金属变塑料;
4. **导出后必看图**:玻璃/金属/高光都依赖渐变与 `backdrop-filter`,Kiln 自研道回退时**静默劣化**(同 `depth-3d.md §六` 风险),只有看成品图能发现;
5. **屏幕模拟 ≠ 实体工艺**:用户要印刷+烫金/UV/击凸时,交付 `print-production.md` 的工艺参数并告知"屏显金色 ≠ 烫金实物",不许拿 CSS 渐变冒充工艺报价。
