# artboard 数字 · 单位 · 日期排版

> **何时读**:版面出现价格 / 百分比 / 统计数字 / 日期 / 时间 / 序号 / 单位符号时。
> 默认中文海报口径;英文/国际版见 §7。

---

## 一、数字字体:三种形态,别选错

| 形态 | CSS | 用在哪 |
|---|---|---|
| **等宽数字** | `font-variant-numeric: tabular-nums` | 表格、清单、价格列、时间轴 —— **凡是上下要对齐的** |
| **比例数字** | `font-variant-numeric: proportional-nums` | 正文、标题里的零散数字(视觉更匀) |
| **等高数字** | `font-variant-numeric: lining-nums` | 大数字卡、数据看板(与大写字母等高,气势足) |

```css
.num   { font-variant-numeric: tabular-nums lining-nums; }   /* 数据列 */
.big   { font-variant-numeric: lining-nums; letter-spacing: 0; }  /* 大数字,零字距 */
.body  { font-variant-numeric: proportional-nums; }          /* 正文 */
```

**规则**:
1. 同一列/同一组数字必须**同一种形态**,混用一眼看出不齐。
2. 大数字(主标级)用 `lining-nums` + `letter-spacing: 0`(`data-longform.md:23` 同规),字距会让它松垮。
3. 中文字体的西文数字多数不好看——**数字量大的图,数字单独用一款西文字体**(字体配额 ≤3 款,铁律 3)。

## 二、千分位与数量级

### 2.1 千分位

| 场景 | 写法 | 例 |
|---|---|---|
| 4 位以上整数 | 加千分位 | `12,800`、`1,024` |
| 4 位整千 | 可省(中文习惯) | `2026 年` 不加,`12,800 元` 加 |
| 年份、编号、电话、邮编 | **不加** | `2026`、`第 1024 号`、`13800138000` |
| 表格数据列 | 全列统一加 | — |

### 2.2 数量级缩写:中文用万/亿,不用 K/M/B

| 中文 | 数值 | 英文对应 |
|---|---|---|
| 万 | 10⁴ | 10K |
| 亿 | 10⁸ | 100M |

```
✅ 中文海报:3.2 万、1.5 亿、8,600
❌ 中文海报:32K、150M            ← 中英混血,读者要换算两次
✅ 英文海报:32K、150M
❌ 英文海报:3.2 万
```

**规则**:一套海报里**只用一个计数体系**。中文 ≠ 万/亿,英文 ≠ K/M/B,不要混。

### 2.3 精度

- 缩写后保留 **1 位小数**(`3.2 万`),整数则不带小数(`8 万`)
- 同一组数据**小数位必须一致**:`12.5% / 8.0% / 43.2%`,不能 `12.5% / 8% / 43.25%`
- 大数不做假精确:`营收 12.8 亿`,不写 `12.83 亿`

## 三、货币 · 百分比 · 单位

### 3.1 货币符号

**中文**:符号在前,**数字与符号之间不留空格**。
```
✅ ¥1,280    ✅ ¥ 1,280(带 1/4 em 细空间也可,但同一版面必须统一)
❌ 1,280 元 在价格卡上(占位长、弱冲击)——正文里写「1,280 元」没问题
```

**价格卡三段式**(`ecommerce-promo.md:40` 的价格锚):
```html
<div class="price">
  <span class="cur">¥</span><span class="int">1,280</span>
  <s class="was">¥1,899</s>
</div>
```
```css
.price .cur { font-size: .42em; vertical-align: .18em; }   /* 符号 = 数字的 42% */
.price .int { font-size: 1em; font-weight: 900; letter-spacing: -.01em;
              font-variant-numeric: lining-nums; }
.price .was { font-size: .30em; opacity: .55; text-decoration-thickness: 2px; }
```
- 货币符号 = 数字字号的 **40–45%**,基线略上提
- 原价删除线 `text-decoration-thickness: 2px`(默认 1px 在导出图上几乎看不见)
- 现价与原价**字号差 ≥2.5 倍**,不能只靠颜色区分

### 3.2 百分比

```
✅ 增长 43%、占比 68.2%、折扣 7 折
❌ 增长 43 %、占比 68.2 percent
```
- `%` 与数字**之间不留空格**(与中文习惯一致)
- 中文折扣优先用「折」:`7 折` 比 `70%` 更像人话;`7.5 折` 比 `75% OFF` 地道
- 同组百分比小数位统一(见 §2.3)

### 3.3 单位符号

| 类型 | 空格 | 例 |
|---|---|---|
| 数字符号(%、℃、°、¥、$) | **不留** | `38.2℃`、`25°`、`¥99` |
| 字母单位(kg、km、ml、px、dpi) | 留 **1/4 em** | `5 kg`、`300 dpi`、`1080 px` |
| 中文单位(元、页、人、天) | 留 **1/4 em** | `1,280 元`、`30 天` |
| 中文与数字之间 | 留 **1/4 em** | `共计 24 帧`(`guardrails.md:46`) |

```css
.q { margin-inline: .06em; }    /* 1/4 em 细空间的近似;精确用 &thinsp; 或 word-spacing */
```

## 四、负号 · 范围 · 约数

| 符号 | 正确 | 错误 | 说明 |
|---|---|---|---|
| 负号 | `−12.5%`(U+2212 MINUS SIGN) | `-12.5%`(hyphen) | hyphen 太短,排版里像破折号残段 |
| 范围 | `9–13 日`(U+2013 EN DASH) | `9-13 日` | 中文范围用一字线 `—` 或半字线 `–`,**不用 hyphen** |
| 约数 | `约 1,200` | `~1,200`、`1200左右` | 中文用「约/近/超」,不用 `~` |
| 倍数 | `×1.6` | `x1.6`、`X1.6` | 用乘号 U+00D7 |

**不换行**:数字与其紧邻符号之间禁止断行。
```css
.nobr { white-space: nowrap; }
```
```html
<span class="nobr">38.2℃</span> <span class="nobr">9–13 日</span>
```

## 五、日期与时间

| 场景 | 推荐 | 备选 | 禁用 |
|---|---|---|---|
| 中文海报(正式) | `2026 年 9 月 13 日` | `2026.09.13` | `2026/9/13`(斜杠是西式) |
| 中文海报(紧凑/活动) | `9.13–9.20` | `9 月 13 日 – 20 日` | `09/13-09/20` |
| 时间 | `19:30`(24 小时制) | `19:30–21:00` | `7:30 PM`(中文场景) |
| 带星期 | `9 月 13 日(周日)` | — | `9月13日 周日` |
| 同年省略 | `9 月 13 日` | — | 上下文已明确年份时可省 |

**规则**:
1. **24 小时制**,中文场景不用 AM/PM
2. 年份四位数**不加千分位**(`2026`,不是 `2,026`)
3. 月日补零看风格:`9.13`(中文)vs `09.13`(科技/数据风),**同一版面统一**
4. 中英文混排海报:日期体系跟随主要语言,不混

## 六、序号与列表

| 层级 | 中文正式 | 中文轻松 | 数据/清单 |
|---|---|---|---|
| 一级 | `一、` `二、` | `01` `02` | `1.` `2.` |
| 二级 | `1.` `2.` | `①` `②` | `1.1` `1.2` |
| 三级 | `(1)` `(2)` | `·` | `a.` `b.` |

**规则**:
1. **序号与正文之间留 1/4 em**,但序号数字用**等宽**(`tabular-nums`),否则 8、9、10 会歪。
2. 编号文字与序号**左对齐基线一致**,不要序号居中、文字顶格。
3. 序号本身可以是强调元素(得意黑/大字号),但它**不计入**「强调 ≤2 处」的额度(它是结构,不是强调)。

```html
<ol class="steps">
  <li><span class="idx">01</span><span class="txt">先定正文字号</span></li>
</ol>
```
```css
.steps .idx { font-variant-numeric: tabular-nums lining-nums;
              font-weight: 900; margin-inline-end: .35em; }
```

## 七、英文 / 国际版差异

| 项 | 中文 | 英文 |
|---|---|---|
| 千分位 | `,` | `,` |
| 小数点 | `.` | `.` |
| 数量级 | 万 / 亿 | K / M / B |
| 货币 | `¥1,280`(符号在前) | `$1,280`、`€1.280,00`(欧陆式点逗互换) |
| 日期 | `2026.09.13` / `9 月 13 日` | `Sep 13, 2026` / `13 Sep 2026` |
| 时间 | 24h `19:30` | 12h `7:30 PM` |
| 百分号空格 | 不留 | 不留(`43%`) |
| 破折号范围 | `9–13` | `9–13`(en dash 相同) |

## 八、正反例

### ✗ 反例

> 「本次活动销售额 12800 元,同比增长 43.25%,参与人数约 1200 人,活动时间 2026/9/13 7:30PM」

问题清单:
1. `12800` 缺千分位 → `12,800`
2. `43.25%` 与同行其它数据小数位不一致(若其它是整数) → 统一
3. `约 1200 人` 缺千分位 → `约 1,200 人`
4. `2026/9/13` 斜杠 → `2026.09.13`
5. `7:30PM` 中文场景用 PM + 缺空格 → `19:30`
6. 数字未用 `tabular-nums`,列内不齐

### ✓ 正例

> 「销售额 ¥12,800 · 同比 +43% · 约 1,200 人参与 · 9 月 13 日 19:30」

- 货币符号前置不留空;`+43%` 用真负正号;千分位齐全;中文日期 + 24h 时间。

## 九、数字排版自检(6 条)

1. 上下要对齐的数字列,用了 `tabular-nums`?
2. 4 位以上整数加了千分位?年份/编号没加?
3. 中文场景用万/亿(不是 K/M/B)?
4. 同组数据小数位一致?
5. 数字与紧邻符号(`%`、`℃`、`¥`)没留空格,且与中文之间留了 1/4 em?
6. 负号用 U+2212、范围用 en dash、约数用「约」?

> 打分走 `design-review-rubric.md`(并入「B 排版质量」维度,占 25%;数字问题按该维度扣 0.5–1 分)。
> 图表内的数字另有规范(轴刻度、单位、小数位),见 `dataviz.md`。
