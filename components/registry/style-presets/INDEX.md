# 风格预设索引

> 预设 = 一组 `--ab-*` token 覆盖 + 3–5 条落地规则。**不是**一整套 CSS,更不是组件复制。
> 加载协议:先读本页选定预设 → 读该预设文件拿 token 块 → 再按需取具体组件。

| 组件 ID | 用途 | 加载条件 |
| :--- | :--- | :--- |
| `style-preset.new-chinese` | 新中式:宣纸底 / 墨色 / 朱砂 / 大量留白 | Brief 出现"东方/国风/水墨/文人/非遗/茶"时 |
| `style-preset.cyber` | 赛博科技:近黑底 / 霓虹描边 / 扫描线 / 等宽标签 | "科技/未来/赛博/发布会/电竞/数据大屏"时 |
| `style-preset.glass` | 玻璃拟态:深色渐变底 / 半透明面板 / 高光边 | "高级感/通透/科技产品/深色 KV/毛玻璃"时 |
| `style-preset.minimal` | 极简:白底 / 墨字 / 一根线 / 无圆角 | "极简/高级灰/日式/性冷淡/大量留白/画廊"时 |
