# 繁梅黑体/繁梅明体

| 属性 | 值 |
|---|---|
| 字体文件 | Fanmei-Hei.ttf, Fanmei-Ming.ttf |
| 字重/变体 | Hei/Ming 各单字重 |
| 分类 | 正文可读·繁体专属 |
| 气质关键词 | 繁体,黑体,明体,书卷,0BSD |
| 协议/来源 | 0BSD(近乎公有领域)· github.com/lxgw/Fanmei |

## 气质描述
霞鹜文楷作者出品的繁体字库:黑体端正、明体书卷,专门补繁体场景。

## 适用
繁体字海报、港台风文案;明体做繁体引文。

## 慎用
简体为主的版面(字符集以繁体优先)。

## 示例句
「海内存知己,天涯若比邻 0123456789」
