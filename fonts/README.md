> 两级筛查法:先按「分类」选定大类 → 点进对应 `<目录>/INTRO.md` 细读气质与适用场景 → 定稿 ≤3 款(标题/正文/数字各司其职)。
> 新增字体:建目录放字体文件 + INTRO.md,然后跑 `scripts/add_font.py <目录名> --name 显示名 --category 分类 --tags 关键词`。
