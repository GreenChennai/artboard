# artboard 印前与后工艺

> **何时读**:用户提到「印刷/送印厂/打样/烫金/UV/模切/专色/覆膜/裁切线」,或印刷品类标了 `"print": true`。
> 分工:`print-cmyk.md` 管**色彩空间**,本册管**工艺**。两者都要过。
> 🔧 = 印厂/RIP 才能做(artboard 只能留条件);✍️ = 设计稿阶段就能做。

---

## 一、陷印(Trapping / 补漏白)

**是什么**:印刷四色版不可能 100% 套准,相邻色块之间会露出白边(漏白)。陷印 = 把浅色向深色**扩一点点**,让误差被盖住。

### 1.1 数值

| 工艺 | 陷印量 |
|---|---|
| 胶印(铜版/胶版纸) | **0.25–0.5 pt** = 0.09–0.18 mm |
| 报纸/新闻纸印刷 | 1–2 pt = 0.35–0.70 mm(纸张变形大) |
| 柔性版/丝网 | 1–3 pt |
| 大实地对大实地 | 取上限 |

### 1.2 三条规则

1. **浅色扩向深色**(不是反过来)。深色盖浅色的容错更高。
2. **文字不陷印**除非字号 >24pt 且压在色块上;小字陷印会变粗变糊。
3. **渐变压实地**不做陷印(渐变边缘本身是软过渡,陷印会出硬边)。

### 1.3 artboard 能做什么

🔧 **陷印本身由印厂 RIP 或 Illustrator 的陷印功能完成**,HTML/PDF 阶段做不到。

✍️ **但你可以避免陷印问题**:
- 避免**大面积平色紧邻**且两色 CMYK 成分相差极大(如满版 C100 紧邻满版 Y100)
- 避免**细线/小字压在两色交界处**
- 避免设计成"必须精确套准"的图形(细边框套色块、同心细圆环)

## 二、专色(Spot Color / Pantone)

### 2.1 什么时候用

| 用专色 | 不用专色 |
|---|---|
| 品牌色**必须精确**(logo 的特定红) | 普通四色能调出的颜色 |
| 金属色 / 荧光色 / 珠光(CMYK 调不出) | 成本敏感(专色=多一块版) |
| 大面积平色,要求**绝对均匀**(四色平网会有水纹) | 图片、渐变 |
| 只要 1–2 色的简单印品(双色印刷反而更便宜) | — |

### 2.2 artboard 怎么标

✍️ HTML 阶段用**注释 + 占位色**标注,交付时口头/书面说明:

```css
:root{
  /* 专色 1:PANTONE 186 C(品牌红)—— 交付时需单独出专色版 */
  --c-brand: #c8102e;      /* 屏幕近似值,非印刷值 */
}
```
```html
<!-- SPOT: PANTONE 186 C -- 品牌红,需出专色版 -->
<div class="logo">…</div>
```

**必须写清的三件事**(交付给用户/印厂):
1. 专色**编号**(PANTONE 186 C,不能只说"红色")
2. 专色**覆盖区域**(哪些元素)
3. 是否需要**专色渐变/网点**(专色网点是`tint %`,如 PANTONE 186 C @ 30%)

### 2.3 能力边界

🔧 **artboard 的 PDF 导出走 CMYK,不生成专色通道**。要真专色必须在 Illustrator 里把对应路径改成专色。
→ 走 `scripts/ai_export.py` 出 `.ai`(ADR 0011 的原生构建)后在 AI 里改,或直接在交付说明里写明让印厂处理。

## 三、印前标记(Print Marks)

### 3.1 五种标记

| 标记 | 作用 | 谁加 |
|---|---|---|
| **裁切线** Crop marks | 指示成品裁切位置 | 🔧 印厂 / AI 导出 PDF 时勾选 |
| **出血** Bleed | 满版底色外延 3mm,裁切误差不至于露白边 | ✍️ 设计稿做 |
| **套准线** Registration marks | 四色版对齐基准 | 🔧 RIP |
| **色标** Color bar | 检测墨量密度 | 🔧 RIP |
| **版面信息** Slug | 文件名/日期/色数 | 🔧 RIP |

### 3.2 ✍️ 出血:artboard 必须做的

`print-cmyk.md:21` 已定 3mm。落地:

```css
/* 画布 = 成品尺寸 + 2×出血;内容区 = 成品尺寸 */
:root{
  --bleed-mm: 3;
  --w-mm: 210; --h-mm: 297;          /* A4 成品 */
  /* 300dpi 下:1mm = 11.811px */
  --bleed: 35px;                      /* 3mm × 11.811 ≈ 35px */
}
.poster{
  width: 2560px;  height: 3618px;     /* (210+6) × (297+6) mm @300dpi */
  position: relative; overflow: hidden;
}
.bg{ position:absolute; inset:0; }    /* 满版底色铺到出血边 */
.safe{ position:absolute; inset: var(--bleed); }   /* 内容全部装进安全框 */
```

**换算**:`px = mm ÷ 25.4 × DPI`(`export.md` 同公式)。300dpi 下 1mm = **11.811px**。

| 品类 | 出血 | 成品→含出血画布(300dpi) |
|---|---|---|
| A4 210×297 | 3mm | 2480×3508 → **2551×3579** |
| 名片 90×54 | 3mm | 1063×638 → **1134×709** |
| 三折页 297×210 | 3mm | 3508×2480 → **3579×2551** |
| 易拉宝 80×200cm | **不需要**(喷绘裁切精度低,一般做 5–10mm 白边或卷边) | — |

⚠️ **关键文字距裁切线 ≥5mm**(`print-cmyk.md:21`)—— 出血 3mm,文字还要再往里缩 2mm。

## 四、网线数(LPI)与网点

**是什么**:印刷用网点模拟连续调,网线数 = 每英寸多少行网点。它决定了**图片需要多少 DPI**。

### 4.1 各工艺的网线数

| 工艺 / 纸张 | LPI | 图片所需 DPI(= LPI × 2) |
|---|---|---|
| 铜版纸胶印 | **150–175** | 300–350 |
| 胶版纸胶印 | 133–150 | 266–300 |
| 报纸 | 85–100 | 170–200 |
| 柔性版 | 100–133 | 200–266 |
| 丝网 | 45–65 | 90–130 |
| 喷绘(易拉宝/写真) | **无网点**(连续调) | **96–150 足够** |

### 4.2 对 artboard 的意义

- **`export.md` 的「印刷 ≥300dpi」对应的是铜版纸胶印 150lpi**。报纸/喷绘不需要那么高,按上表降,省体积。
- 易拉宝是**喷绘**,150dpi 是标准(`formats/rollup.md`),不是 300 —— 这是正确且经济的。
- 图片 DPI **超过 LPI×2 没有意义**(只是增大文件)。

### 4.3 网点边界(设计避坑)

| 现象 | 阈值 | 后果 |
|---|---|---|
| 高光绝网 | 网点 <**2–5%** | 印不出来,变成纯白 |
| 暗部并级 | 网点 >**95–98%** | 糊成一块,失去层次 |
| 平网水纹 | 大面积均匀浅色(10–30%) | 出现摩尔纹/水波纹 |
| 渐变阶梯 | 渐变跨度 >50% 且长度短 | 出现明显色阶断层 |

**设计对策**:
- 渐变跨度控制在 **≥30% 的长度**内完成(渐变长度 ÷ 变化量)
- 大面积浅平网改用**细网点纹理**或**纸纹**(见 `effects.md` 的纸感/噪点配方)
- 高光不要低于 **C3 M2 Y2 K0** 这类极小值

## 五、纸张与色彩

### 5.1 纸张影响两件事:网点扩大 与 白度

| 纸张 | 网点扩大(Dot Gain) | 特点 |
|---|---|---|
| 铜版纸(涂布) | **15–20%** | 网点清晰,色彩饱和,适合照片 |
| 胶版纸(非涂布) | **25–30%** | 吸墨,颜色变暗变闷,细节略糊 |
| 新闻纸 | **30–40%** | 大幅变暗,禁用细小文字和反白字 |
| 特种纸/纹理纸 | 不定 | 吸墨不均,大实地易花 |

### 5.2 设计补偿(✍️ 可做)

| 纸张 | 补偿 |
|---|---|
| 胶版/新闻纸 | 整体**提亮 8–12%**;饱和度**降 5–10%**;正文加粗一档;最小字号上调 |
| 铜版纸 | 基本不用补偿 |
| 深色满版 | 用 `C40 M30 Y30 K100` 而非四色黑(`print-cmyk.md:18`) |
| 反白字(深底白字) | 新闻纸上**禁用**;胶版纸上字号 ≥9pt 且字重要够 |

## 六、后工艺与设计要求

| 工艺 | 效果 | 设计稿要求 |
|---|---|---|
| **覆膜**(光膜/哑膜) | 保护 + 提亮/降反光 | 哑膜会让颜色**变暗 5–8%**,提前压一点饱和;满版深色建议过膜防蹭脏 |
| **局部 UV** | 局部高亮、凸起感 | 需**单独出 UV 版**(一张纯黑白稿,黑色=要 UV 的区域);UV 区域线宽 ≥0.3mm |
| **烫金/烫银** | 金属光泽 | 需**单独出烫印版**;图案线宽 ≥0.2mm,**禁止细密网点**(烫不平);文案用粗体 |
| **击凸/压纹** | 立体触感 | 需单独凹凸版;避开细小文字;与印刷图案对位需留 ±0.5mm 容差 |
| **模切** | 异形裁切 | 需**模切刀线**(单独路径层,专色描边标注 `dieline`);成品内容距刀线 ≥3mm |

### artboard 能做的

✍️
- 为 UV / 烫金 / 模切各出**一张单色版图**(黑底白图案,PNG 或 PDF),这是印厂唯一认的东西
- 在交付说明里写明每块版对应的工艺与区域
- 模切刀线用单独的 HTML(`<slug>-dieline.html`),`stroke` 用专色标注

🔧
- 真正的版文件(.ai/.eps with spot color `dieline` / `uv` / `foil`)需在 Illustrator 里完成 → 走 `scripts/ai_export.py` 出 `.ai` 后再加工

## 七、交付清单(印刷任务,逐条过)

**文件**
- [ ] 成品 PDF(含 3mm 出血、裁切线)
- [ ] 转曲 PDF 或已嵌入字体(避免换机走样 —— `glossary.md`「转曲」)
- [ ] 需要工程文件时另出 `.ai`(`ai_export.py`)
- [ ] UV / 烫金 / 模切 的单色版(各一张)

**色彩**
- [ ] 全部色值在 CMYK 安全范围(TAC ≤300%,`print-cmyk.md:19`)
- [ ] 文字 K100 单色黑,无四色黑
- [ ] 无 RGB 极值色(`#0000FF` / `#00FF00` / `#39FF14`)
- [ ] 专色已标注编号与区域

**版式**
- [ ] 出血 3mm 已含,满版底色铺到边
- [ ] 关键文字距裁切线 ≥5mm
- [ ] 图片 DPI ≥ LPI×2(铜版纸 300,喷绘 150)
- [ ] 折页已做内板收窄 1–2mm 补偿

**后工艺**
- [ ] 覆膜/UV/烫金/模切 的版文件与说明齐全
- [ ] 已注明纸张克重与类型(影响网点扩大,印厂要据此调整)

## 八、自检(6 条)

1. 出血 3mm 已做,满版底色铺到画布边?
2. 关键文字距裁切线 ≥5mm?
3. 文字 K100 单色黑,没有四色黑?
4. 图片 DPI 匹配目标 LPI(不是一律 300)?
5. 需要后工艺的,单色版出了吗?
6. 纸张类型已确认,做了网点扩大补偿吗?
