# 思源黑体(Source Han Sans / Noto Sans SC)

| 属性 | 值 |
|---|---|
| 字体文件 | NotoSansSC-VF.ttf(可变字体) |
| 字重/变体 | 可变字重 100–900(Light→Black 全轴可用) |
| 分类 | 正文可读 · 大标题 |
| 气质关键词 | 现代、中性、干净、全能、数据感 |
| 协议/来源 | SIL OFL 1.1 · googlefonts/noto-cjk(与 Adobe 思源黑体同源) |

## 气质描述
现代无衬线的"基础设施"字体:不抢戏、极可靠。Light 细节精致,Black 字重厚实有力,
一套字从正文管到超级大标题。

## 适用
- 正文、说明文字、数据标签(Regular/Medium)
- 科技 KV、品牌主视觉的粗黑大标(Black,配合大字号和大字距)
- 信息图数字(等宽数字观感整齐)

## 慎用
- 文艺、手写、复古调性(会显得冷)
- 长段宋体感排版场景(换思源宋体)

## 示例句
「把复杂留给算法,把简单交给设计 0123456789」
