# 寒蝉拙楷

| 属性 | 值 |
|---|---|
| 字体文件 | ChillZhuoKai_R.ttf |
| 字重/变体 | Regular 单字重 |
| 分类 | 文艺人文·手写 |
| 气质关键词 | 楷体,拙朴,手写,温润,笔记 |
| 协议/来源 | OFL(免费商用)· 100font 帖1812 / github.com/Warren2060/ChillZhuoKai |

## 气质描述
「拙」字当头的楷体:故意写得不太熟练的手写感,笨拙但真诚,人味十足。
比霞鹜文楷更松弛随性,笔记感和温度更强。

## 适用
手账小红书批注、文艺引文、笔记感标题;配霞鹜文楷做正文-批注组合。

## 慎用
正式商务、精密数据版式;超过两行的长文。

## 示例句
「海内存知己,天涯若比邻 0123456789」
