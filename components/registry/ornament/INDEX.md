# 装饰组件索引

> 装饰件的共同约束:只作用于背景/装饰层,不接管文字;同一画面 ≤3 种(铁律 3)。

| 组件 ID | 用途 | 加载条件 |
| :--- | :--- | :--- |
| `ornament.seal-stamp` | 朱红印章 / 落款,新中式画面收尾 | 新中式、东方主题,或要在角落盖一个"作者感"标记时 |
| `ornament.neon-scanline` | 静态霓虹描边 + CRT 扫描线 | 赛博/科技主题,需要"屏幕感"但不需要动画时 |
| `ornament.glass-panel` | 玻璃拟态面板(模糊 + 半透明 + 高光边) | 深色底上要浮起一块信息面板,或科技 KV 特性卡 |
| `ornament.paper-grain` | 纯 CSS 纸张/油墨纹理底 | 新中式、印刷品、要"摸得到"的纸质质感时 |
