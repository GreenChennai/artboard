# artboard 视频动效(模式 V:片头/片尾/概括/章节/转场)

> **本册是"视频动效件"的唯一真相源**;`animation.md` 仍是"海报动图(模式 P)+
> 单张场景卡(模式 S)"的真相源。分工表见 §九。
> 与 CutFlow 的边界(**硬**):artboard **只产卡**——出画面件 + 分镜表 + 卡点表;
> 剪辑 / 配乐 / 变速 / 字幕烧录 / 时间线合成一律 **CutFlow** 的领域(§七)。

---

## 〇、第一原则:视频动效服务"节奏",不是"炫技"

> 观众注意力以**秒**计。片头超过 5 秒 = 直接掉完播率(短视频实操共识)。
> 依据 Apple HIG《Motion》:动效**必须有明确目的**(传达层级 / 提供反馈 / 帮助预判 /
> 等待时分散注意力),不做装饰性动画,不得阻塞内容。

**一句话判据**:拿掉这个动效,观众少理解了什么?答不出来 → 删。
同屏动效 ≤2 组(承铁律 3 的特效上限);片头/片尾**不是必选项**——只有用户要或视频类型需要才做。

## 一、五类画面件 × 时长契约

> **时长全是经验值/工程取值,不是标准**;置信度列就是"打几分",用户与平台实测优先。

| 件 | 作用 | 时长 | 画幅 | 必含元素 | 置信度 |
|---|---|---|---|---|---|
| **片头 Opener** | 建立品牌/主题预期 | **3–5s**(短视频);**5–8s**(教程/短片) | 全画幅(可出血) | Logo 或主标 + 一句话主题 | 经验值(中文短视频实操:严控 3–5s) |
| **片尾 Outro** | 收束 + 引导 | **3–6s** | 全画幅 | 落版 + CTA + 账号信息 | 经验值(结尾留 5–10s 总结引导) |
| **内容概括 Summary** | 预告/回顾要点 | **5–15s**(每条 1.2–2s) | **安全区内** | 3–5 条要点逐个进场 | 工程取值 |
| **章节卡 Chapter** | 分段导航 | **1.5–3s** | **安全区内** | 编号 + 章节名(+一句话副题) | 工程取值 |
| **转场 Transition** | 镜头衔接 | **0.3–0.8s** | 全画幅 | 方向延续(进慢出快) | 工程取值(承 animation.md §九) |

**时长纪律**:片头短视频 ≤5s;转场**比入场短**且方向延续;概括稳定态要"一眼扫完"
(要点 ≤5);全片预算:Σ件时长 ≤ 目标总时长(用户给,或按 §二 类型默认)。

## 二、五类视频 × 动效配方矩阵

| 视频类型 | 节奏特征 | 片头 | 片尾 | 概括 | 章节 | 视觉密度 | 词法(优先) |
|---|---|---|---|---|---|---|---|
| **口播** | 语速主导,画面是补语 | 轻(3s,Logo+主标) | 轻(3s,CTA) | 少用(打断语流) | 可选 | **低** | 信息卡 / 关键词强调 / 下三分 / 逐词高亮 |
| **教程** | 步骤驱动 | 中(4–5s,标题+目录预览) | 中(4s,回顾+引导) | **必用**(开篇目录+结尾回顾) | **必用** | 中 | 图解渐进构建 / 步骤线 / 代码高亮 / 图表构建 |
| **vlog** | 情绪驱动、镜头碎 | 极轻或无 | 轻 | 不用 | 不用 | **低** | 手写批注 / 贴纸 / 转场擦除 / 轻视差 |
| **短片** | 叙事驱动 | 中(5–8s,氛围) | 中(5s,字幕卡) | 不用 | 可选 | 中 | 标题字卡 / 蒙版擦除 / 视差 / 光线流动 |
| **MV** | **音乐驱动** | 重(可 5–8s) | 中 | 不用 | 不用 | **高** | 动力排印 / 逐字节奏 / 形状变形 / 卡点切换 |

**用法**:先按视频类型查本表定"哪些件要做、密度多高",再进 §三 挑语法。
配图需求走 materials.md §0 判定表("视频动效件"=不需要照片,以排版/几何为主)。

## 三、动效语法库(7 式;每式带"导出注意")

> 底层 token/法则/白名单**一律引用不重复**:缓动与时长 token → `animation.md §三`;
> 十二法则 → §二;可动属性白名单 L1/L2/L3 → §十一;五段式 → §八。

| 语法 | 技术 | 适用 | 导出注意(必读) |
|---|---|---|---|
| **动力排印** | 逐字/逐词 `<span>` + stagger + 位移/旋转/缩放 | MV、片头、口号 | 逐字 span 必须过**语义断行**(`typography-rules.md §一`);不跨断行点 |
| **Logo 揭示** | `clip-path` 擦除 / mask 生长 / `stroke-dashoffset` 描边 | 片头、片尾 | 引擎对动画 clip-path 仅支持 **inset/circle/ellipse**;stroke-dashoffset 属 L2 白名单 |
| **数字滚动** | `@property` 注册整数 + counter | 概括、数据卡 | `tabular-nums` 防抖;**终值=文案数值**;时长 ≤1s(`animation.md §十`) |
| **图表构建** | ECharts 逐系列淡入 / SVG 描边画出 | 教程、概括 | **矢量交付时内联 SVG 会栅格化**(`vector-drawing.md §4.5`);位图/MP4 交付不受影响 |
| **蒙版擦除** | `clip-path: inset()` 推进 | 转场、章节 | 同上(仅 inset/circle/ellipse) |
| **视差** | 多层不同速 `translate` | 短片、vlog | 仅 `transform`(L1 白名单) |
| **形状变形** | clip-path polygon 近似 / 多层交叉溶解 | MV、片头 | polygon 动画**未实测** → 先做 5 分钟探针再定;不稳就退交叉溶解 |

## 四、时间轴契约:分镜表(Shot List;模式 V)

```
模式 S(单张卡,animation.md §八):P0静置 → 入场 → 持住 → 出场 → P1静置
模式 V(多镜头件,本册):shot-1 → [转场] → shot-2 → … → shot-N
                          每个 shot 内部仍守五段式;件间用"转场件"衔接
```

**输出物 = 分镜表**(交给 CutFlow 挂轨):

```
shot | 内容      | 时长(s) | 动效语法   | 转场(至下)   | 备注
  1  | 主标+Logo |  3.2    | Logo 揭示  | 蒙版擦除 0.4s | 前置静置 2.0s 被录制吃掉
  2  | 三条卖点   |  6.0    | 图元 stagger| 淡出 0.4s    | 每项 +120ms
  3  | 落版 CTA  |  4.0    | 焦点收缩   | —            | 收尾静置 0.3s
```

**纪律**:
1. 每个 shot **单独一个 HTML**(`shot-01.html`…,便于重导单镜);同项目复用 tokens;
2. `--max-wait` = 五段总和 + 1.5s(承 `animation.md §八`);
3. 导出片长 ≈ 时间轴总长 − 1.8s(前置静置被录制吃掉,既有实测口径);
4. 全 finite 禁 infinite、必须出入场(铁律 6;每个 shot 单独守)。

## 五、节奏接口:BPM → 帧(卡点表)

```
拍间隔(ms) = 60000 / BPM / 拍细分
例:120 BPM、细分 1 → 500ms/拍;25fps → 12.5 帧/拍 → 取整到 12 或 13 帧网格
```

```bash
python scripts/beat_sheet.py --bpm 120 --fps 25 --bars 16 [--subdiv 2]
python scripts/beat_sheet.py --list "0.5,1.0,1.6,2.4" --fps 25   # 短视频无 BPM:秒点直接对齐
```

- 输出单行 JSON `points[{index,t_ms,t_sec,frame}]` + stderr 可读表;
- 卡点表 = 每个 shot 出入点对齐帧网格,导出后**抽帧核对**;
- 只输出"画面在第几秒出现",**不做配乐**(§七)。

## 六、画幅与安全区、字幕带共存

| 画幅 | 场景 | 安全区(标准档) | 置信度 |
|---|---|---|---|
| 9:16 / 16:9 / 3:4 | 已有实测 | `video-safe-area.md §二` | 实测 |
| **1:1** | 朋友圈 / 信息流 | 四边 **8%** | **工程取值(未实测)** |
| **4:5** | IG / 小红书竖版 | 顶 8% / 底 **16%** / 左右 8% | **工程取值(未实测)** |
| **2.35:1** | 短片电影感 | 四边 **5%**;字幕带单独处理 | **工程取值(未实测)** |

- 数值已同步进机检(`check_overflow.py --safe-area 1x1|4x5|2.35x1`,auto 判画幅同支持);
- **复核纪律**:安全区数值每 **6 个月**或平台大改版后复核一次;方法 = 目标平台导出真机
  截图 + 量取按钮列/字幕带宽度,回填 `video-safe-area.md §七` 来源表。

**下三分 / 字幕带(lower third;06-C)**:概括/章节卡要跟烧录字幕共存时——
1. 画面件内容**整体让出底部字幕带**(9:16 标准档底 30% 已含;横屏底 16%);
2. 自带"下三分"信息条(人名条/标题条)时:宽度 ≤ 画布宽 70%,贴字幕带**上沿**之上,
   字号 ≥ 字幕字号(video-safe-area.md §四的 marginV 口径),入出场走擦除不盖字幕;
3. 中英双语字幕排版(断行/字号/行距)按 `bilingual-typography.md`,本册不重复。

## 八、交付前自检(模式 V;逐条过)

1. 每个件都有**明确目的**吗?(§〇 判据:拿掉少理解了什么)
2. 时长符合 §一 契约吗?(片头短视频 ≤5s)
3. 全 finite、有出入场吗?(每个 shot 单独守)
4. 内容全在**对应画幅**安全区内吗?(`check_overflow.py <proj>/src --safe-area auto`)
5. 逐字动画过**语义断行**吗?(无词被劈开)
6. 转场"进慢出快"且方向延续吗?
7. 导出后**效果没丢**吗?(对照 §三"导出注意")
8. 分镜表 + 卡点表齐吗?
9. **无障碍**(06-A):有 ≥3 次/秒的闪动/频闪吗?(光敏性不适,删)台词关键信息只靠动画提示吗?
   (`prefers-reduced-motion` 用户降级为淡入淡出——导出产物不受此设置影响,但**同一 HTML 的网页版**必须带该媒体查询分支)
