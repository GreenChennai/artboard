# artboard 品牌一致性

> **何时读**:用户给了品牌色 / logo / 既有 VI;或一次做**多张同品牌物料**。
> 优先级:用户给的品牌规范 > 本册 > 风格分册默认。

---

## 一、Logo:净空 · 最小尺寸 · 禁则

### 1.1 最小净空(Clear Space)

净空 = logo 四周**不允许任何元素进入**的空白带。

```
净空 X = logo 高度的 25%(横向版式)
净空 X = logo 宽度的 25%(竖向/方形版式)
```

```css
.logo{ padding: calc(var(--logo-h) * .25); }   /* 或用 wrapper 撑开 */
```

**绝对下限**(净空算出来太小时用):

| 场景 | 净空下限 |
|---|---|
| 屏幕(1080 画布) | ≥ 12px |
| 印刷(300dpi) | ≥ 1.5mm ≈ 18px |

**净空区里禁止出现**:文字、其它图形、图片边缘、裁切线。**背景纹理可以进**(它是底不是图形)。

### 1.2 最小尺寸

| 场景 | logo 高度下限 |
|---|---|
| 屏幕(1080 基准画布) | **≥ 40px**(约 3.7% 画布宽) |
| 印刷 | **≥ 5mm**(300dpi 下 ≈ 59px) |
| 名片 | 90–140px(`formats/card.md:18`) |
| 易拉宝 | 200–320px(`formats/rollup.md:17`) |

小于下限 → 笔画并级、字面糊掉。宁可放大,不要为了"精致"缩小。

### 1.3 Logo 位置优先级

```
1. 品类规定的位置(名片左上/居中、易拉宝顶部、折页封面)
2. 动线起点(左上 → Z 动线;顶部居中 → 中轴)
3. 版式末位:右下/底部居中的落款位
```
同一套物料里,logo 的**相对位置**(占比坐标)应保持一致,不要每张换地方。

### 1.4 五条禁则

| 禁 | 反例 |
|---|---|
| **不改色** | 把品牌蓝改成"和背景更搭"的紫。要反白就用官方反白稿,不要自己调 |
| **不拉伸** | 为了填满而横向拉宽;`transform: scaleX()` 或设 `width` 不锁比例 |
| **不加投影/描边/发光** | 给 logo 加 `drop-shadow`(除非 VI 明确允许) |
| **不旋转** | 把 logo 转 −6° "活泼一点" |
| **不压在 busy 背景上** | 压在照片细节区、强纹理上。要压就加垫层(见 `color-contrast.md` §4) |

**复刻任务**:品牌 logo **用占位框 + 备注,不伪造**(`replicate.md:79`)。

```html
<!-- LOGO 占位:用户需替换为官方文件;不要手绘近似 logo -->
<div class="logo-placeholder">[LOGO]</div>
```
```css
.logo-placeholder{
  display:grid; place-items:center;
  border: 2px dashed currentColor; opacity:.55;
  font-size: 24px; letter-spacing:.1em;
}
```

## 二、品牌色阶:从一个品牌色生成 10 阶

### 2.1 生成法(OKLCH)

固定**色相 H** 与**基准彩度 C**,只动明度 L;两端降彩度(浅色发白、深色发灰是印刷与屏幕的共同物理约束)。

```css
:root{
  /* 以品牌红 H=25 C=.16 为例;把 H/C 换成用户给的品牌色即可 */
  --brand-50:  oklch(97% 0.020 25);
  --brand-100: oklch(93% 0.045 25);
  --brand-200: oklch(87% 0.075 25);
  --brand-300: oklch(79% 0.110 25);
  --brand-400: oklch(71% 0.140 25);
  --brand-500: oklch(63% 0.160 25);   /* ← 基准阶 = 用户给的品牌色 */
  --brand-600: oklch(55% 0.150 25);
  --brand-700: oklch(47% 0.130 25);
  --brand-800: oklch(39% 0.100 25);
  --brand-900: oklch(30% 0.075 25);
  --brand-950: oklch(21% 0.050 25);
}
```

**从 hex 反推 H/C**:把用户给的 hex 转 OKLCH(工具或 `color-mix()` 调试),取 H 与 C 填入,再按上表铺 L。

### 2.2 阶位用途

| 阶 | 用在哪 |
|---|---|
| 50–100 | 浅底、卡片背景、高亮底 |
| 200–300 | 边框、分隔线、次要图标 |
| 400–500 | **主色**:主按钮、强调元素、图表主系列 |
| 600–700 | 深底上的可点击色、正文强调 |
| 800–900 | 标题、深底 |
| 950 | 极深底、反白文字的底 |

**对比度校验**:文字用 700–900 阶压 50–100 阶底(ΔL ≥ 0.45 → 4.5:1,见 `color-contrast.md` §三)。**不要用 500 阶做正文色**(常卡在 3:1 附近)。

### 2.3 印刷约束(重要)

`oklch()` 里的高饱和值**可能超出 CMYK 色域**。印刷任务:
1. 按 `print-cmyk.md` 的 12 色对照表核一遍
2. 超出色域的阶位**降 C**(每次 −0.02)直到进入安全范围
3. 品牌主色若本身超色域 → 明确告知用户「这个色四色印不出,需要专色」,走 `print-production.md` §2

## 三、品牌色的版面分配

沿用 `guardrails.md:53` 的 60/30/10,但把角色换成品牌语义:

| 比例 | 角色 | 取哪一阶 |
|---|---|---|
| 60% | **底色 / 大面积** | 中性色(暖纸/米杏/白),不是品牌色 |
| 30% | **辅助** | brand-800/900(深)或 brand-100(浅底) |
| 10% | **强调** | brand-500/600 |

**常见错误**:把品牌色当 60% 铺满。品牌色是**识别符**,不是背景色 —— 铺满就失去了强调力。

**强调纪律不变**:强调色 ≤2 处(铁律 3)。品牌色用得多不等于可以到处强调。

## 四、品牌字体锁定

一套物料内**字体组合必须完全一致**:

```css
:root{
  --f-brand: "Smiley Sans";        /* 标题/品牌名:性格款 */
  --f-text:  "Source Han Sans SC"; /* 正文:可读款 */
  --f-num:   "MiSans";             /* 数字:等宽/数字优美款 */
}
```

| 规则 | 说明 |
|---|---|
| ≤3 款 | 铁律 3。标题/正文/数字各一款,不超 |
| 字重≤3 档 | 同一款字体只用 2–3 个字重(如 400/700/900),不要 5 档 |
| 用户有指定就用指定的 | 用户给的字体 > 本册推荐 |
| 用户没给但有 logo | 从 logo 字形气质推断(圆润→圆体;硬朗→黑体),并在交付时注明「字体为近似匹配」 |

## 五、跨物料一致性(一套多张时)

同一项目下的多个 HTML,以下 **7 项必须逐字一致**:

| 项 | 落地方式 |
|---|---|
| 1. `:root` 色板 | 各文件复制同一段 tokens,不改值 |
| 2. 字号阶 | 同画布宽用同一套;不同画布宽按 `responsive-reflow.md` §二 换算 |
| 3. 字体组合 | 同上 |
| 4. 圆角半径 | 同一 `--radius`,不要 8px/12px/16px 混用 |
| 5. 间距基线 | 同一 `--baseline`(见 `composition.md` §4.2) |
| 6. 图标风格 | 同一套(Tabler,同 `stroke-width`),不混实心/描边 |
| 7. 投影参数 | 同一 `--shadow`,不要一处硬一处软 |

**落地建议**:把 tokens 抽成一个 `<style>` 片段,所有变体文件**复制同一段**(artboard 是离线单文件,`import` 不可用)。改品牌色时**全局替换这段**,不要在单个文件里改值。

> **边界与触发条件(09-O 系列感,不展开)**:本节管**同品牌**多物料一致。「同主题、非同品牌的 N 张系列」(如一组活动联投海报、一套系列插画封面)暂不建册——**触发条件:用户一次要 ≥3 张同主题且无统一 VI 时**,先与用户确认一张"系列 token 契约"(固定 tokens / 字体 / 网格 / 构图母版,即本节 7 项的变体),再按契约分发各张;契约本身复用本节,无需新机制。需求实际反复出现时再扩独立节。

## 六、品牌一致性检查项(交付前)

1. logo 四周净空 ≥ 高度 25%,净空区无其它元素?
2. logo 尺寸 ≥ 下限(屏幕 40px / 印刷 5mm)?
3. logo 没被改色/拉伸/投影/旋转?
4. 品牌色走 tokens,没有裸 hex 散落?
5. 品牌色**没有**当 60% 大面积铺?
6. 文字用的品牌色阶过了 4.5:1?
7. 一套多张时,7 项跨物料一致项逐项对齐?
8. 复刻任务里 logo 是占位而非伪造?
9. 印刷任务的品牌色在 CMYK 安全范围内?

> 打分走 `design-review-rubric.md`(并入「C 色彩与对比」20% + 「E 去 AI 味」10%;品牌色滥用按 C 维度扣分)。
