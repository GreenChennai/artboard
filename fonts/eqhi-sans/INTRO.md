# 嗷呜等高体

| 属性 | 值 |
|---|---|
| 字体文件 | HowlingEqHiSans-VF.ttf |
| 字重/变体 | 可变字体 Regular~Bold |
| 分类 | 正文可读·中英混排 |
| 气质关键词 | 等高,中英混排,可变字体,参数表 |
| 协议/来源 | OFL 1.1 · github.com/howlingFounts/EqHiSans |

## 气质描述
汉字与西文等高的黑体:中英混排不再一高一矮,数字一行像一条线。

## 适用
中英混排海报、参数表、带英文品牌名的版面。

## 慎用
纯中文大标题(等高优势体现不出来)。

## 示例句
「海内存知己,天涯若比邻 0123456789」
