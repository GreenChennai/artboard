# 纳挼崩音黑

| 属性 | 值 |
|---|---|
| 字体文件 | NanoTikBazHei-Bold.ttf |
| 字重/变体 | Bold 单字重 |
| 分类 | 标题冲击 |
| 气质关键词 | 抖音感,硬朗,方正,短视频标题 |
| 协议/来源 | OFL 1.1(抖音美好体字库补全)· github.com/Hansha2011/NanoTikBazHei |

## 气质描述
抖音美好体的开源补全版:笔画硬朗、字腔方正,带短视频的冲劲。

## 适用
短视频封面、促销标题、需要「抖音感」的大字。

## 慎用
文艺、正式公文;小字正文。

## 示例句
「海内存知己,天涯若比邻 0123456789」
