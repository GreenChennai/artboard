# 打印 / CMYK 流程(线下物料必读)

> 用户明确「要打印 / 线下物料」时,**设计阶段就切换 CMYK 色域**,而不是导出后才发现色差。

---

## 1. 为什么必须提前

RGB(屏幕)色域大于 CMYK(印刷)。屏幕上鲜亮的荧光绿、宝蓝、大红,
印刷时**必然发灰发暗**。导出后才转 CMYK = 观看效果与实际打印不符,返工。

## 2. 设计阶段规则

1. **主色/强调色从下方 CMYK 安全色谱中选**,不使用荧光色与纯 RGB 极值:
   - 避免 RGB 纯色:`#0000FF`、`#00FF00`、荧光绿 `#39FF14`、亮粉等(印刷不可达);
   - 饱和度拉满的渐变两端 → 各降 10–15% 饱和再入版。
2. **黑色文字用单色黑 K100**(`#000000` 转印刷即 C0M0Y0K100),
   禁用四色黑(`C60M40Y40K100` 会套准偏移出重影);深色底可用 `C40M30Y30K100`。
3. **总墨量(TAC)≤ 300%**:四色数值相加不超过 300,超出会洇纸不干。
4. 白色 = 不印刷(无 C/M/Y/K),镂空露纸色。
5. 满版底色向出血线外延 3mm;关键文字距裁切线 ≥ 5mm。
6. 灰色用 K 单色(C0M0Y0K20–70),禁四色灰(偏色)。

## 4. 导出与交付

- **导出仍为 RGB PNG**(渲染管线决定),交付前用:
  `python scripts/calc_size.py dpi --px 2480 3508 --mm 210 297` 确认 DPI;
- **CMYK 转换**(Pillow,无损走 TIFF 或 CMYK-PDF):
  ```bash
  python - <<'PY'
  from PIL import Image
  im = Image.open('export/poster.png').convert('CMYK')
  im.save('export/poster-cmyk.pdf', resolution=300)
  im.save('export/poster-cmyk.tif', compression='tiff_lzw')
  PY
  ```
- 交付清单:CMYK PDF + TIFF、出血 3mm 已含、300dpi、字体已嵌入/转曲、
  单色黑文字、总墨量 ≤300%。
- 印刷类批处理(`导出-*.bat`)可配合 `project.json` 的 `"print": true` 标记
  提醒走本流程。

## 5. 触发词

用户提到:打印 / 印刷 / 线下 / 喷绘 / 名片 / 折页 / 画册 / 易拉宝实物 →
**一律按本流程**:设计用 CMYK 安全色 + 导出后转 CMYK 交付。
