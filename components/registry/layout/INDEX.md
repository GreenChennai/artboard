# 版式组件索引

> 用法:先读本页,命中后只读命中的那一个组件文件。用途写任务语言,不写设计术语。

| 组件 ID | 用途 | 加载条件 |
| :--- | :--- | :--- |
| `layout.poster-vertical` | 竖版海报基础画布(3:4 / 9:16),带安全区与出血 | Brief 说"海报/封面/竖版/手机看"时 |
| `layout.editorial-split` | 图文分栏,文字左 / 视觉右,适合信息密度中等 | 有真实配图且要"图文并置"、又不想要大标题压满时 |
| `layout.center-hero` | 居中主视觉 + 底部信息锚,上下留白大 | 主 KV、发布会主视觉、一句话口号海报 |
