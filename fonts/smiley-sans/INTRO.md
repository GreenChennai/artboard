# 得意黑(Smiley Sans)

| 属性 | 值 |
|---|---|
| 字体文件 | SmileySans-Oblique.ttf(仅斜体单字重) |
| 字重/变体 | Oblique(内置倾斜,不可变字重) |
| 分类 | 标题冲击 |
| 气质关键词 | 冲刺、动势、竞技、促销、年轻 |
| 协议/来源 | 免费商用 · atelier-anchor/smiley-sans(OFL) |

## 气质描述
自带前倾 8° 的速度感黑体,笔画利落。天生是"开赛口令"的嗓子——一个词砸下去
就有画面。中文平面设计近年的现象级标题字。

## 适用
- 电商大促主标(「限时 5 折」「疯抢」)
- 运动、竞技、发布倒计时类 KV
- 数字大字(斜体数字张力极强)

## 慎用
- 正文(几乎不可读性优先的场景)
- 需要端正、权威、严肃的场合
- 与其他斜体元素混排(斜上加斜)

## 示例句
「即刻开抢 48 小时 0123456789」
