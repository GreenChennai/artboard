# Roboto Flex

| 属性 | 值 |
|---|---|
| 字体文件 | RobotoFlex-VF.ttf |
| 字重/变体 | 可变字体(多轴) |
| 分类 | 英文点缀·现代无衬线 |
| 气质关键词 | VF,现代,万能,数字,眉题 |
| 协议/来源 | OFL 1.1 · googlefonts/roboto-flex |

## 气质描述
Roboto 的可变版:数字与英文眉题的万金油,宽窄粗细一键可调。

## 适用
英文眉题(kicker)、参数标签、数据页英文。

## 慎用
装饰性大标题(个性平淡)。

## 示例句
「海内存知己,天涯若比邻 0123456789」
