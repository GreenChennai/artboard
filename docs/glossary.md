| 联接(junction) | NTFS 目录重解析点;相对引用经 OS 穿透到 Skill 库,http/file 双通 |

| pack | `scripts/pack.py`:穿透联接收集依赖 → 自包含 zip,HTML 引用自动改写 |
| 五问 | 开工前追问协议:用途/尺寸/风格/配色/素材(intake.md) |
| 设计简报 | 五问汇总的"生图式提示词",先给用户看再动工(design-prompt.txt) |

| 证据链 | 复刻纪律:每个颜色/度量追溯到测量;token 必须带采样证据,裸眼估的不进 CSS(replicate.md) |
| 分区普查 | inspect_ref.py census 按区采样:flat fills=真填充/all pixels=小块/ink core=文字墨色(R1b) |
| 复刻比对 | compare.py 生成原图 vs 复刻图并排图(--region 局部放大+ΔRGB 数字),逐分区核对(replicate.md Step R4) |
| 风格分册 | 某视觉风格的规则集:色彩角色表+字体栈+字号阶+组件+禁则+案例(styles/) |
| 品类规范 | 某输出介质的规范:尺寸/字号下限/折线/盲区(formats/) |
| 原子混搭 | 分册章节按单关注点组织,可跨风格借用单个原子(如"瑞士版式+Y2K 配色") |
| 版权风险- | 爬虫来源素材的强制文件名前缀,交付时必须提醒更换(materials.md) |

| WPI | 渲染导出引擎:Playwright 驱动系统 Edge/Chrome,输出 PNG/GIF/MP4/PDF |
| settle | WPI 导出前的稳定化:等字体/图片、滚动触发 reveal、动画收敛到终态 |
| 孤字 | 段落末行仅 1 个汉字——排版硬禁(typography-rules.md) |
| tabular-nums | 等宽数字;数据列必须使用以垂直对齐 |
| 反 AI 味自检 | 12 条交付前清单(guardrails.md §5) |
| 矢量枢纽 | HTML 先打印成 Chromium 单页矢量 PDF,再衍生 SVG/EPS/转曲 PDF(ADR 0006) |
| 转曲(outline) | 文字变字形轮廓路径;矢量交付产物一律转曲,防换机换字体走样(ADR 0007) |
| -print.pdf | Chromium 原生打印 PDF:文字内嵌可编辑,AI 打开可改字(需装同款字体) |
| -outline.pdf | ghostscript 转曲 PDF:任何机器视觉一致,文字不可选 |
| AI 兼容 PDF | Illustrator 可直接打开编辑的 PDF;真 .ai = 在 AI 里打开它另存一次(ADR 0008) |
| SSIM 验收 | 转换产物栅格化后与基准截图算结构相似度,≥0.95 合格 ≥0.99 优秀(vector-export.md) |
| 矢量安全清单 | 16 种 CSS 原语转换实测表;**五条禁令**:硬切透明渐变 / mix-blend-mode / 渐变字 / conic-gradient / 渐变 alpha-stop 压圆角(vector-export.md §5) |
| WebHtml2VectorEdit | 自写正向转换核心:HTML→分层 AI 可编辑 PDF/SVG/EPS,不依赖 WPI |

| 面板底色克隆 | 分层手术:有底色又含内容的元素,底色剥离进图形层,本体转结构 |
| 模式 P(海报循环) | 动效分册的循环模式:无缝循环 2–6s,首帧=末帧,终态=合格静态海报(animation.md §〇) |
| 模式 S(场景卡) | 动效分册的视频模式:插进口播之间的信息卡/图解卡,五段式一次性时间轴,全 finite,必须有出场 |
| 五段式 | 模式 S 时间轴契约:前置静置→入场→持住→出场→收尾静置(ADR-0012) |
| 前置静置 | 五段式第一段:空卡 ≥2.0s,吸收 WPI 录制起点偏移(实测 1.7–1.9s),片头呈现为"空卡一拍" |
| 录制偏移 | WPI 录制起点比 CSS 时间轴 0s 晚(1080×1920 实测 1.7–1.9s)的现象;对策是前置静置 ≥2.0s(ADR-0012) |
| 出场三原则 | 比入场短(0.4–0.6s)、方向延续(入向=出向)、stagger 反序(后进先出) |
| 语义断行 | 中文标题断点手动给:两行=两个 `.tl` span;断点选语法边界,禁止词中间劈开(typography-rules.md §一) |
| 逐行三合一 | 视频卡标题逐行 span:断行、换色、入场 stagger 三者共用同一 span 边界 |
| 生动性词汇表 | 科普/教程动效手法:图解渐进构建/逐词强调/数字计数/前后对比/聚光灯/Ken Burns/次要动作(animation.md §十) |
| 母阶 | 字号阶的单一回退基准:画布宽 1080,r=1.25/1.414 比例生成;分册缺项时才用(ADR-0014) |
| 栏宽换算 | 字号按**内容栏宽**而非画布宽换算:系数 = √(栏宽/1080);多栏版式(折页/杂志)必用(ADR-0014) |
| 动线 | 视线在画面上的移动路径:S 中轴 / Z / F / 放射 / 环;构图的第一决策(composition.md §一) |
| 骨架 | 主体在画布上的落位法:三分 / 黄金 1:1.618 / 中轴对称 / 对角 15–30° / 框中框 / 满版出血(composition.md §三) |
| 视觉重量 | 焦点评判的六个加权量:面积 40 / 对比 25 / 位置 15 / 孤立 10 / 方向 5 / 纹理 5(composition.md §二) |
| 基线单位 | 纵向节奏的最小单位 = round(正文字号 × 行高 ÷ 4) × 4;所有纵向间距取其 0.5/1/2/3 倍(composition.md §4.2) |
| 栏沟 | 相邻栏之间的间隙:画布 ≤800 用 16px、801–1440 用 24px、1441–2400 用 32px、>2400 用 48px(composition.md §4.1) |
| Rubric | 设计评审打分表:五维度 × 0–5 分 + 权重(A30/B25/C20/D15/E10),及格线 ≥3.5 且无单项 ≤1(ADR-0013) |
| 硬伤 | rubric 中直接计 0 的项:主标被盖不可读 / 字体回退 / 文字溢出 / 对比度 <2:1 / 元素毫无对齐(design-review-rubric.md §一) |
| 大字 | WCAG 2.2 定义:≥18pt(24px)常规 或 ≥14pt(18.66px)粗体 → 对比度阈值 3:1;其余算常规文字需 4.5:1(color-contrast.md §一) |
| 相对亮度 | Y = 0.2126R + 0.7152G + 0.0722B(通道先线性化);对比比 = (L1+.05)/(L2+.05)(color-contrast.md §二) |
| ΔL 速判 | 用 OKLCH 明度差估对比度:≥0.33 → 3:1、≥0.45 → 4.5:1、≥0.54 → 7:1;中性色精确,高饱和为近似(color-contrast.md §三) |
| 垫层 scrim | 文字压图时的可读性兜底层:全幅渐变 α ≤.75 / 局部色块 α .55–.70 / 二者叠加 + 文字收边投影 α ≤.50(color-contrast.md §四) |
| 色盲友好 | 约 8% 男性红绿色盲:颜色不得作唯一编码(加文字/形状);系列色相邻 OKLCH L 差 ≥0.12(color-contrast.md §五) |
| 大数字卡 | 单一巨数的呈现形态(不算图表):数字字距 0 或 −0.01em、单位字号 = 数字 30–40%、一屏 ≤3 个(dataviz.md §六) |
| LPI | 网线数:每英寸网点行数。铜版 150–175 / 胶版 133–150 / 报纸 85–100 / 喷绘无网点;图片 DPI = LPI×2(print-production.md §四) |
| 陷印 trapping | 补漏白:浅色向深色扩 0.25–0.5pt(胶印)以吸收套准误差;由印厂 RIP 完成,设计侧只能避免"必须精确套准"的构图(print-production.md §一) |
| 网点扩大 | 纸张吸墨导致网点变大的现象:铜版 15–20% / 胶版 25–30% / 新闻纸 30–40%;需提前提亮降饱和补偿(print-production.md §五) |
| 净空 clear space | logo 四周禁止进入的空白带 = logo 高(横版)或宽(竖版)的 25%;屏幕下限 12px、印刷下限 1.5mm(brand-system.md §1.1) |
| 品牌色阶 | 从一个品牌色生成的 10 阶:固定 H/C、按 OKLCH L 从 97% 铺到 21%,两端降 C(brand-system.md §二) |
| Reflow | 一稿多尺寸重排:装饰可等比缩放 / 文字重新定位 / 内容重新排布 / 图片重新裁切(responsive-reflow.md §一) |
| 母版+变体 | 多尺寸工作流:`<slug>-master.html` 存信息结构(文案唯一真相源),`-34`/`-11`/`-916` 存各自画布与字号(responsive-reflow.md §六) |
| 容器越框 | 文字画出其背景/边框容器的边界(但可能仍在画布内);与"出画布"是两类,处置不同(card-layout.md / ADR-0015) |
| painted 盒(绘制的盒) | 有非透明背景色或可见边框的元素。溢出的判据参照系:**只对 painted 盒**判"内容越界"——无绘制的纯文字元素内容略大于自身盒是行盒现象,不是缺陷 |
| 卡高公式 | 按最长条目反推容器高度:`padding×2 + Σ(行数×字号×行高) + 间距`,其中行数 = ceil(字数 ÷ 每行字数)(card-layout.md §三) |
| 收口 | 让容器在被撑破前截住内容的三种手段:`line-clamp`(行数)、`text-overflow:ellipsis`(单行)、`overflow:hidden`(兜底)。**不用于兜文字**——会裁掉半个字 |
| 安全区 | 视频里避开**字幕带 + 平台 UI 遮挡带**后剩下的可用区;9:16 = 左右 184 / 顶 230 / 底 576(video-safe-area.md) |
| 字幕带 | 成片叠加字幕所占的底部区域(9:16 ≈ 底部 30%、16:9 ≈ 16%、3:4 ≈ 18%);卡上内容不得进入 |
| UI 遮挡带 | 平台界面自身占用的区域:顶部状态栏/关注栏、底部文案与音乐栏、**右侧按钮列(9:16 宽 180px)** |
| 保守交集 | 多平台发布时取各平台安全区的最严值;9:16 = 左右 184 / 顶 230 / 底 576,用以一版通吃 |
| 豁免标记 | `data-allow-overflow` 属性:声明该子树是**装饰**(可越界);内容标记它等于承认"这块不是内容"(card-layout.md §六) |

## 术语消歧

> 以下 4 组术语在全库被混用,是大量"数字打架"的语义根因。遇到时按本表取义。

| 混用组 | 成员 | 消歧 | 真相源 |
|---|---|---|---|
| **尺寸类** | **预设** / **物料** / **品类** | **预设** = 画布参数(宽/高/scale),18 个键;**物料** = 真实投放物(社媒/电商/印刷/办公/广告,47 种);**品类** = 输出介质族,有独立规范分册(名片/A4/三折页/易拉宝/PPT,5 类) | 预设:`scripts/scaffold.py:29-50` SIZES;物料:`material-catalog.md`;品类:`formats/` |
| **风格类** | **风格** / **风格方向** | **风格** = 已建分册,含可执行规则集(色板/字体栈/字号阶/组件/禁则),现 4 册;**风格方向** = `styles-catalog.md` 的 123 个气质词,只供选型,**不可执行** | `styles/` vs `styles-catalog.md` |
| **字号类** | **大字** / **主标** | **大字** = WCAG 的对比度豁免类别(≥24px 常规 / ≥18.66px 粗体),是**阈值概念**;**主标** = 字号阶第一级,是**层级概念**。1080 基准下只有主标和副标够"大字",正文/标签/页脚都不算 | `color-contrast.md` §一 |
| **换算类** | **等比换算** / **栏宽换算** | **等比**(按画布宽线性)已废,三折页/长图均失效;**栏宽换算**(系数 = √(栏宽/1080),多栏用栏宽)为唯一口径 | ADR-0014 + `responsive-reflow.md` §二 |
| **安全类** | **安全边距** / **安全区** | **安全边距** = 画布四周的通用内边距(6%/8%),防裁切与贴边,静态图也用;**安全区** = 视频专有,躲开字幕带与平台 UI 后的可用区(9:16 左右 184/顶 230/底 576)。前者是"离边多远",后者是"哪块能用" | `guardrails.md §1` vs `video-safe-area.md` |
| **溢出类** | **出画布** / **出容器** | **出画布** = 内容被 `.poster{overflow:hidden}` 裁掉,自检一直在查;**出容器** = 文字画出卡片背景/边框但仍未出画布,此前无任何判据(ADR-0015)。后者更常见也更隐蔽 | `card-layout.md` + `check_overflow.py` |
