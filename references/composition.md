# artboard 构图与版式骨架

> **何时读**:选完风格之后、写 HTML 之前;或自检发现「看着散 / 没重点 / 像模板」。
> **生成层(概念/主导动作)见 `design-thinking.md`;本册从骨架起**——先用它定"说什么",再回这里定"怎么排"。
> 与 `style-system.md` 六原型分工:那个按**信息量**选型,本册按**视觉动线**选型——先定骨架再装信息量。
> 数值冲突时:品类/风格分册优先,本册只补它们没写的。

---

## 〇、三次决策,顺序不能反

```
① 动线  →  眼睛怎么走(S 中轴 / Z / F / 放射 / 环)
② 骨架  →  主体放哪(三分 / 黄金 / 对称 / 对角 / 框中框 / 满版出血)
③ 网格  →  元素怎么吸附(栏数 / 栏沟 / 基线单位)
```

反过来做(先摆元素再找动线)= 元素各说各话,画面必散。

**完成判据**:能用一句话说出「眼睛从 __ 出发,经过 __,停在 __」,且这句里三个位置都能在画布上指出坐标。

## 一、动线:五种,按信息密度选

| 动线 | 结构 | 适用 | 画布上怎么落 |
|---|---|---|---|
| **S / 中轴** | 视线沿垂直中轴上下摆 | 1–2 点信息、仪式感、对称主体 | 主标居中偏上(版心比几何中心**高 1/10**),落款居中偏下 |
| **Z** | 左上 → 右上 → 左下 → 右下 | 3–4 点、横版、有明确 CTA | 起点左上 logo/眉题,终点右下 CTA/二维码 |
| **F** | 顶部横扫 → 左侧竖扫 → 再横扫 | 5+ 点、清单/长图/报告 | 靠**左对齐的标题带**制造横栅,每 3 行一个断点 |
| **放射** | 从一点向四周扩散 | 单主体、促销爆炸、数据发散 | 中心点偏离几何中心 **1/6–1/4**(正中心=呆),放射线 ≤24 根 |
| **环** | 沿闭合路径绕行 | 流程、时间线、步骤图 | 3–6 节点,环直径 ≤ 画布短边 70% |

**判定**:眯眼看图 3 秒,目光落点应**唯一**。若出现两个同等强度的落点,说明动线断了——降低其中一个的视觉重量(见 §二)。

## 二、视觉重量:让焦点唯一的量化手段

视觉重量不是"大小",是六个可加权的量:

| 权重项 | 权重 | 加重的手段 | 数值上限 |
|---|---|---|---|
| **面积** | 40% | 放大元素 | 主元素占版面 15–40%;>50% 变成压迫 |
| **对比** | 25% | 与背景拉开明度/饱和度差 | 见 `color-contrast.md`;强调色 ≤2 处 |
| **位置** | 15% | 放到动线起点或交叉点 | 中轴上、三分线上 |
| **孤立** | 10% | 周围留白 | 焦点周围留白 ≥ 该元素自身面积的 30% |
| **方向** | 5% | 用线条/视线/箭头指向它 | 指向性元素 ≤3 个 |
| **纹理** | 5% | 加质感/描边/投影 | 一图 ≤3 种特效(`guardrails.md` 铁律 3) |

**焦点唯一性检查(必过)**:
1. 把图缩到 15% 宽看(或眯眼),第一落点唯一?
2. 第二落点比第一落点弱 ≥1 档(面积比 ≤60% 或对比度差 ≥2 级)?
3. 视线从第一落点到第二落点的移动路径,是否就是 §一 声明的动线?

三条全过 = 焦点成立。任一条不过 → 调**第二落点**,不是加强第一落点。

**缩略图可读性(信息流场景必过)**:把图缩到 15% 宽(≈小红书/朋友圈/电商列表的缩略图尺寸)再看一眼——**主信息仍可辨**才算过:缩略状态下能读出主标大意、能数出层级。理由:信息流里图的 90% 曝光发生在缩略尺寸,缩放后主标糊成一团色 = 等于没做;不过就**加大主标或减信息**,不是给主标加描边(描边缩放后只剩脏边)。评审打分时本项并入 rubric A 维「第一落点唯一」一起看(`design-review-rubric.md §A`)。

## 三、骨架:六种,给 CSS

> 所有坐标以 `.poster` 固定画布为基准。装饰可出血,**文字与 logo 永远在安全边距内**(`guardrails.md` §1:四周 ≥6%,被圆角裁切的场景 ≥8%)。

### 1 · 三分法(默认,最稳)

横竖各两条三分线,四个交点是最强落点。

```css
.poster { position: relative; overflow: hidden; }
.hero {                       /* 主体压在右三分线 × 上三分线的交点 */
  position: absolute;
  left: 66.67%;  top: 33.33%;
  transform: translate(-50%, -50%);
  width: 46%;                 /* 主体宽 ≈ 画布宽 40–50% */
}
.title { position: absolute; left: 8%; top: 12%; }   /* 标题走左上三分区 */
```

选点原则:
- **左上交点**:最自然的第一落点(阅读起点)
- **右下交点**:CTA、二维码、价格
- **右上交点**:次要信息,权重天然低于左上
- 正中心:**只在对称骨架里用**,否则显呆

### 2 · 黄金分割(1:1.618,文艺/高级感)

```css
:root { --phi: 0.618; }        /* 1/1.618 */
.split-gold {                  /* 竖向黄金分割:大区在左(或右),小区为辅 */
  display: grid;
  grid-template-columns: 61.8% 38.2%;
  height: 100%;
}
.inner-gold {                  /* 大区内再套一次黄金:标题落点 */
  padding-top: 38.2%;
}
```
适用场景:文艺人文、品牌发布、书籍封面。**不要与满版出血混用**——黄金的精致感靠留白撑,出血会吃掉它。

### 3 · 中轴对称(仪式感 / 权威)

```css
.axis {
  display: flex; flex-direction: column; align-items: center;
  padding-top: 22%;            /* 版心比几何中心高 1/10 ≈ 从 50% 提到 ~40% 视觉重心 */
  text-align: center;
}
.axis > * + * { margin-top: 4.5%; }   /* 纵向节奏用同一间距,不要随手给 */
```
**反 AI 味要求**(`guardrails.md` 反味自检第 6 条):默认居中构图当唯一构图是被禁的。用中轴必须**有理由**——对称主体(建筑/人像/产品正面)、发布级仪式感、正式请柬。理由说不出口就换三分。

### 4 · 对角线(动感 / 运动 / 促销)

```css
.diag {
  position: absolute; inset: 0;
  background: linear-gradient(158deg, var(--c-primary) 0%, transparent 62%);
}
.diag-content { transform: rotate(-6deg); transform-origin: left center; }
```
- 角度 **15°–30°** 之间;>35° 阅读困难,<10° 看不出是斜的
- 文字**不要跟着转**超过 6°——促销短词可以,正文绝对不行(长斜体中文是排版灾难)

### 5 · 框中框(聚焦 / 编辑感 / 画中画)

```css
.frame {                       /* 外框留边 + 内框裁图 */
  margin: 6%; padding: 3%;
  border: 2px solid var(--c-ink);
}
.frame .inner { aspect-ratio: 4/3; overflow: hidden; }
.frame .inner img { width: 100%; height: 100%; object-fit: cover; }
```
双层框线间距 = 外框宽 的 **1/8–1/6**;两层框必须**同色同线宽**或**明显不同**(差一点就是失误,CRAP 的 C)。

### 6 · 满版出血(沉浸 / 产品特写)

```css
.bleed { position: absolute; inset: 0; }           /* 图片铺满 */
.bleed::after {                                    /* 压字区必须垫层 */
  content: ""; position: absolute; inset: 0;
  background: linear-gradient(to top, rgba(0,0,0,.62) 0%, rgba(0,0,0,.12) 46%, transparent 72%);
}
```
压字可读性数值见 `color-contrast.md` §4。装饰元素允许贴边出血,**文字和 logo 不许**。

## 四、网格:让"对齐"有东西可对齐

> `guardrails.md:41` 写了「元素全部吸附栏与基线」但没给参数。这里补。

### 4.1 栏数由画布宽决定

| 画布宽(px) | 栏数 | 栏沟 |
|---|---|---|
| ≤ 800 | 4 | 16px |
| 801–1440 | 6 | 24px |
| 1441–2400 | 12 | 32px |
| > 2400(长图) | 12 | 48px |

**栏宽不是画布宽 ÷ 栏数**——要先扣掉安全边距与栏沟:
```
栏宽 = (画布宽 − 2×安全边距 − (栏数−1)×栏沟) ÷ 栏数
```

### 4.2 基线单位由正文字号决定

```
基线单位 = round(正文字号 × 行高 ÷ 4) × 4      /* 取 4 的倍数 */
```
例:正文 28px × 行高 1.75 = 49 → 取 **48px** 为基线单位。
所有纵向间距(`margin` / `padding` / 板块间距)取基线单位的 **0.5 / 1 / 2 / 3** 倍,不外取中间值。

### 4.3 落地

```css
:root{
  --safe: 8%;                  /* 安全边距,被裁切场景取 8%,否则 6% */
  --cols: 6; --gutter: 24px; --baseline: 48px;
}
.poster{
  display: grid;
  grid-template-columns: repeat(var(--cols), 1fr);
  gap: var(--gutter);
  padding: var(--safe);
  align-content: start;
}
.block + .block { margin-top: calc(var(--baseline) * 2); }
```

**完成判据**:画面里没有一个元素"没有归属"——每个元素要么贴左栏线、要么跨整数栏、要么压三分线。抽查 5 个元素,5 个都能说出它吸附在哪条线上。

## 六、正反例

### ✗ 反例 A:元素全在但没骨架

> 主标居中、四张等大卡片 2×2 排布、底部一行小字。

问题:中轴 + 均质卡片阵列,两个焦点(主标 + 卡片墙),且"默认居中"违反反味自检第 6 条。
修:主标移到左上三分区,卡片改为主卡占 2×2、三张副卡 1×1(便当盒)。

### ✗ 反例 B:动线声明与实际不符

> 声明 Z 动线,但 CTA 在左下、二维码在右下。

问题:Z 的终点是右下,CTA 却在中途。
修:CTA 与二维码合并到右下,或改声明为 F 动线并把 CTA 提到顶部通栏。

### ✓ 正例:能说出坐标的构图

> 1080×1440 小红书封面,Z 动线 + 三分骨架:
> 眉题「新手摄影」在 (8%, 8%) 左上三分区 → 主标「6 个避雷点」压 (8%, 22%) 左上三分线 →
> 编号列表从 (8%, 42%) 竖排到 (8%, 82%) → CTA「收藏」在右下 (68%, 88%)。
> 视觉重量:主标 面积 40% + 对比 25% = 焦点;CTA 面积 18% + 对比 15%,弱一档。

## 七、出图前构图自检(4 条,接在 `guardrails.md` §9 之后)

1. **动线能说出坐标**:「从 __ 到 __ 停在 __」,三个位置都指得出来。
2. **焦点唯一**:缩到 15% 看,第一落点唯一,第二落点弱 ≥1 档。
3. **元素有归属**:随机抽 5 个元素,5 个都能说出吸附在哪条栏线/三分线/基线上。
4. **留白有意图**:留白 ≥25%(`guardrails.md` 反味自检第 11 条),且呼吸位在**焦点旁边**,不是四边均匀镶边。

> 打分请走 `design-review-rubric.md`(构图与留白维度占 15%)。
