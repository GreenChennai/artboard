# 霞鹜文楷(LXGW WenKai)

| 属性 | 值 |
|---|---|
| 字体文件 | LXGWWenKai-Regular.ttf(Regular 单字重) |
| 字重/变体 | Regular(可加 CSS font-weight 变胖,但非真字重) |
| 分类 | 文艺人文 · 手写批注 |
| 气质关键词 | 温润、手写、课本、信笺、小清新 |
| 协议/来源 | SIL OFL 1.1 · lxgw/LxgwWenKai |

## 气质描述
基于 Klee One 的开源楷体,像钢笔写出的课文与信。温度高、攻击性为零,
是"人味"最重的一款。

## 适用
- 手账、日记感小红书卡片的正文与批注
- 文艺、教育、绘本类海报
- 引文旁的手写感补注

## 慎用
- 促销大字报、科技 KV(力度与气质都不对)
- 需要粗壮标题的场合(它只有一档)

## 示例句
「把日子过成诗,把诗写进日常 0123456789」
