# artboard 风格制作指南(如何新增风格分册)

> 风格库是 artboard 的弹药库。任何用户/维护者按本指南 30 分钟能登记一个新风格。

## 1. 分册模板

新文件放 `references/styles/<slug>.md`,slug 用英文短横线(如 `magazine-editorial.md`),**按以下章节写全**:

```markdown
# <风格中文名>(<slug>)

> 一句话定位:给谁用、什么场景、什么感觉。

## 画布与安全边距
推荐尺寸预设(xhs/long/kv/banner/square/vertical);安全边距(常规 6%/被裁切场景 8%)。

## 色彩角色表
| 角色 | 值 | 用法 |
|---|---|---|
| 底 bg | #… | … |
| 近黑文字 ink | #… | … |
| 主色 primary | #… | … |
| 强调 accent | #… | 只给 1-2 个元素 |
| 辅助 muted | #… | … |
(≥5 色,可直接改用 style-system.md 八组 tokens)

## 字体栈
| 角色 | 字体(链接字体库目录) | 字重 | 字距 |
|---|---|---|---|
| 主标 | [得意黑](../../fonts/smiley-sans/INTRO.md) | — | 0 |
| 正文 | [思源黑体](../../fonts/source-han-sans/INTRO.md) | 400 | 0.02em |
| 数字 | … | … | … |

## 字号阶(以 1080 宽为基准)
主标 Npx / 副标 Npx / 正文 Npx / 标签 Npx / 页脚 Npx。

## 网格与间距
栏数/边距/组件间距基准(8px 系或 12px 系)。

## 组件语言(3-6 个)
本风格签名组件的写法要点:标题排法 / 标签件 / 卡片 / 装饰件。
(引用 effects.md 配方,注明组合方式)

## 调性禁则(≥5 条"不要")
这个风格一做就俗/翻车的点,逐条列死。

## 参考案例
[案例 HTML](../../assets/cases/<slug>-case.html) · 渲染要点。

## 来源与灵感
提炼/参考了什么,标注仓库与协议(思想提炼需重写;MIT/Apache 可少量引用并注明)。
```

## 2. 制作流程

1. **取材**:想清楚目标场景 → 在 `其他开源项目参考/` 的来源库(baoyu-skills 风格词表、
   html-anything 模板、Art 特效、esther 规则)找气质相近的样本,**只提炼思想**。
2. **定 tokens**:色彩角色表 + 字体栈。字体必须来自 `fonts/` 已有款(缺字体先走 add_font)。
3. **写分册**:按模板填,禁则至少 5 条——禁则越具体,出图越稳。
4. **写案例**:在 `assets/cases/<slug>-case.html` 写一个完整参考实现(固定画布、
   只用库内字体、tokens 全走 `:root`),内容用虚构品牌。
5. **渲染自检**:scaffold 冒烟项目 → 换入案例 → WPI 导出 → Read PNG 检查(走 pipeline Step 5–6)。
6. **登记**:SKILL.md 风格清单表加一行(名称/slug/一句话/推荐尺寸)。

## 3. 案例硬要求

- 单文件 HTML,内联 CSS;`@font-face` 相对路径 `fonts/…`(scaffold 会复制)。
- 无动画(M2 前禁用);无 CDN;无交互。
- 代表性:案例要能当"及格线答卷"——按它改内容就能交付的水平。
