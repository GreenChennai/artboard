# artboard 设计思维分册(生成层:四段翻译 · 主导动作 · 概念生成法 · 反套路)

> **何时读**:需求本身很平("就是一张海报")、用户要"设计感"、想要记忆点、或 brief 读完想不出画面长什么样时——**选骨架之前**(在 `composition.md` 之前读)。
> **单一真相源声明(防多真相源)**:
> - 本册只讲**生成层(Generative Layer)**:从 brief 到概念、概念到视觉装置的思考方法——四段翻译模型、主导动作、概念生成法、卖点映射、反套路、三方向、软提示落盘;
> - 动线/骨架/网格怎么选 → `composition.md`;语气怎么排 → `typographic-expression.md`;纵深怎么做 → `depth-3d.md`;防守清单(别像 AI)→ `guardrails.md §5`;验收打分 → `design-review-rubric.md`;改稿期诊断与三版**呈现** → `revision-protocol.md`;
> - 本册产出的是"想法",**全部要在上述分册落地**,且不豁免铁律 3(层级 ≤3 / 强调 ≤2 / 特效 ≤3 / 字体 ≤3);
> - B/C 模式(复刻/换风格)不启动本册——视觉基准已在参考图里(见 §八例外)。

## 〇、第一原则:先想"说什么",再想"怎么排"

brief 平不是图的错,是没做**翻译**。用户给的是卖点(抽象),画面能放的是装置(具体);
生成层就是把前者翻译成后者。既有三册(`composition.md` / `style-system.md` / `design-review-rubric.md`)
定位分别是"选择""选""验收",本册补的是它们之前缺的那一步:"想"。

**判据(生成层是否工作了)**:把主标遮住,这张图还能被一眼读出"情绪或主张"吗?
能 → 概念在场;只剩"一张排版干净的空图" → 生成层缺席,先回本册,别急着调字号。

**生成 ≠ 加东西**。概念是"一个意思",不是"一堆装饰"——想清楚了才知道删什么留什么,
与 `guardrails.md §2`「密度目标 4/10,最高质量的动作通常是删减」同向:概念让删减有依据。

## 一、四段翻译模型(生成层的骨架)

```
brief(用户要什么) → 概念(一个意思) → 视觉装置(一个看得见的动作) → 版式(composition 落地)
```

| 段 | 回答的问题 | 一句话的形状 | 不合格的样子 |
|---|---|---|---|
| **brief** | 用途 / 受众 / 一句话诉求 / 品牌人格 | 原样转述,不翻译 | —(输入段) |
| **概念** | 这张图在"说"什么 | 一句主张("X,是 / 是一种 Y") | 复读 brief("卖咖啡的海报") |
| **视觉装置(Visual Device)** | 概念变成什么可见动作 | 一个指得出来的画面动作(什么东西在哪、做什么) | 形容词("大气的排版""高级的感觉") |
| **版式** | composition 如何为装置让路 | 动线/骨架/网格/留白各自服务装置哪一点 | 先选骨架再塞概念(§八) |

**例(手冲咖啡招募)**:brief「给手冲咖啡做招募海报」→ 概念「慢,是一种讲究」→
视觉装置「一滴水落下,在画面正中砸出涟漪」(时间被拉长)→ 版式「中轴对称 + 单点特写 +
大留白,文字退到涟漪之外」。

**判据**:四句连读成因果链——"因为 brief 要 __,所以这张图主张 __,所以画面里做 __,所以版式这样让路"。
**连不上 → 卡在哪段回哪段,别硬往下走**。三种最常见断裂:
1. 概念复读 brief(段 2 没干活——"卖咖啡的海报"不是概念,是任务重述);
2. 装置写成形容词(段 3 没落地——"高级"没法画,涟漪才能画);
3. 版式与装置无关(段 4 没服务——装置要留白,版式却塞满了)。

**纪律**:概念不改变信息,只改变"怎么说"——文案仍逐字来自用户,不编数据(`guardrails.md` 铁律 4)。

## 二、主导动作(Dominant Move)

> **定义**:一张图里**唯一那个最大胆、最记得住的设计决断**——"如果这张图能被记住,靠的就是它"。
> **与"焦点"的区别**:焦点是"眼睛先看哪"(**视觉规律**,归 `composition.md §二` 管);
> 主导动作是"作者做了什么冒险"(**设计意图**,归本册管)。一张图可以焦点清晰却没有主导动作
> ——那叫"正确但无记忆点";主导动作做出来后,焦点通常就落在它身上,但不必然。

### 候选库(一图只选一个)

| # | 类型 | 做法 | 落地参照 | 风险(带理由) |
|---|---|---|---|---|
| 1 | **超尺度** | 主标巨大到几乎成为画面,文字即图形 | `typographic-expression.md §五`(字号 = 画布宽 0.4–1.0) | 短词 ≤5 字、手动断行、逐字查笔画粘连 |
| 2 | **出血裁切** | 主体被画布边缘切掉一部分 | `composition.md §三.6` 满版出血 | **仅图形/照片主体**;文字画布出血默认禁(`typographic-expression.md §八` 裁决 4),要同款观感用画布内裁切窗 |
| 3 | **意外对比** | 巨大×极小、极素×极艳同框对撞 | `composition.md §二` 重量对比 | 需要"故意"的信号——不像故意就像失误 |
| 4 | **一处纵深** | 伪3D / 前后遮挡造空间 | `depth-3d.md`(计入特效计数) | 一图一处纵深焦点,不得堆(`depth-3d.md §七`) |
| 5 | **负空间叙事** | 大面积留白本身是主角,留白形状有意味 | 留白 ≥40%,呼吸位在焦点旁 | 留白要有意图;四边均匀镶边不算(D 维 1 分构图) |
| 6 | **打破网格** | 一个元素明显脱离网格(斜置/错位) | `composition.md §四` 网格 | 只破一个;破两个 = 乱,不是破 |
| 7 | **材质意外** | 一处强材质(金属/纸纹/霓虹/压印)对撞其余极素 | `effects.md` 配方 | 一图 ≤1 处;材质吃特效配额(≤3) |
| 8 | **手作痕迹** | 一处真手写/手绘笔迹,其余规整 | `fonts/` 手书款(如 liyu-shoushu) | 只给短句;正文禁手写体(可读性) |

**纪律(写死,不放宽)**:主导动作**一图只一个**;其余一切规整、退让。
判据:缩到 15% 宽看图,用一句话说"这图靠 __ 被记住"——**说出两个,砍掉弱的那个**。
理由:两个大胆互相抢戏,结果双双失忆(与"一图一焦点""强调色 ≤2"同一逻辑)。

**与硬规则的关系**:主导动作**不豁免任何上限**——超尺度吃"字体 ≤3 / 层级 ≤3",
材质/纵深计入"特效 ≤3",出血不许碰安全边距内的文字与 logo(`guardrails.md §1`)。
**与 rubric 的关系**:没有主导动作 → E 维最高 4 分(12 条全过但偏保守,`design-review-rubric.md §一` E);
避开首俗(§五)+ 一处主导动作 → E 维 5 分的充分路径(E 5 = 12 条全过 + 一处"故意打破")。
**与改稿的关系**:用户说「再来点设计感」= 缺主导动作,答案是在候选库选**一个**,不是加特效
(`revision-protocol.md §2` 翻译表既有条目)。

## 三、概念生成法(五种,可操作)

> 用法:同一 brief 用 **2–3 种**法各产一个概念,与 §五 反套路合判,选出**最能落地且最不套路**的一个;
> 落选的两个不扔——它们是 §六 三方向的现成种子。

| 法 | 怎么做(步骤) | 例子 | 失手点(带理由) |
|---|---|---|---|
| **1 类比** | ①写出主体核心属性 → ②找一个该属性极强的熟悉事物 → ③借它的形/机制呈现主体 | "咖啡因 = 电池电量"→ 用电量进度条排醒神时段;"自习室 = 潜水舱"→ 舱窗里一格暖灯 | 类比物只有圈内人懂——行话类比给大众看,解码失败 |
| **2 隐喻** | ①抽象卖点 → ②它给身体/生活的什么感觉 → ③找那个感觉的具体载体 | "效率 → 剪刀";"增长 → 阶梯";"安静 → 一根悬着未落的线" | 隐喻陈词滥调(灯泡 = 创意)——先过 §五 反套路再用 |
| **3 极端化** | ①列主体 3 个属性 → ②挑与诉求最相关的一个 → ③问"推到 10 倍会怎样" | "快 → 快到残影";"多 → 多到溢出画布";"静 → 静到只剩一行字" | 极端化错属性——把"便宜"极端成糊满价格 = 廉价感 |
| **4 对立冲突** | ①找主体的天然对立面 → ②同框并置 → ③让冲突点正好落在卖点上 | "旧 vs 新"(老宋体排新科技);"1 vs 10000"(一块钱 vs 一万块的价值) | 为冲突而冲突——冲突点与卖点无关,只剩怪 |
| **5 约束法** | ①从约束库抽 1 条 → ②在限制内解题 | 约束库:只用一种颜色 / 只用几何形 / 文案 ≤6 字 / 只用一个字号 / 只许用圆。"只用一种颜色"→ 靠纸纹与压印造层次;"文案只有 6 个字"→ 每个字升到主角尺度 | 约束只砍了装饰,信息层级跟着塌——约束是逼创意,不是减信息 |

**判据(概念合格线)**:能接进 §一 的段 3(说得出视觉装置),且过 §五(不撞首俗)。
两条缺一 → 换一个概念,别硬排。

## 四、卖点 → 视觉隐喻映射(10 组)

> 用户给的多是"卖点/功能",要翻译成**看得见的东西**。本表是起点不是终点:
> 每格给"可用隐喻"与"优先避开"(避开项是各卖点的俗套解,撞 §五 首俗或 AI 高发手法)。

| 卖点 | 可用的视觉隐喻 | 优先避开(俗) |
|---|---|---|
| 快 | 残影 / 速度线 / 计时器 / 一刀切开 | 闪电图标 |
| 稳 | 地基 / 锚 / 三脚架 / 一条水平线 | 握手 |
| 高端 | 大留白 / 单点光 / 金线 / 大理石纹 | 满屏金色渐变 |
| 天然 | 植物经络 / 土色 / 手感纸纹 | 绿叶雨林满铺 |
| 智能 | 网络节点 / 光线脉络 / HUD 细线框 | 发光大脑、蓝紫渐变(`guardrails.md §4` 既有禁令) |
| 便宜/划算 | 堆叠 / 量杯 / 醒目大数字 | 爆炸贴 + 倒计时 |
| 专业 | 蓝图 / 标尺 / 网格 / 仪器面板 | 西装握手 |
| 温度/人情 | 手写 / 胶带贴纸 / 暖光 | 爱心雨 |
| 安全/信任 | 锁孔 / 盾形留白 / 一条完整闭环线 | 城堡剪影 |
| 新鲜/现做 | 断裂的脆口 / 活水 / 当日时间戳 | 通用蒸汽符号 |

**纪律(三条,带理由)**:
1. **隐喻一眼可懂,不解谜**——观众没义务解码,3 秒读不出的隐喻是作者自嗨;
2. **隐喻服务信息,不为炫技**(`guardrails.md §5`:装饰必须服务层级或叙事);
3. **一图一个隐喻体系**——同格内才可混用,跨格混搭(蓝图 + 手写 + 残影同图)= 装饰堆砌。

## 五、反套路机制(生成层最有效的一步)

**做法**:动笔前先写一句"**这类需求最俗的做法是什么**",然后**主动避开它**。
先说出俗,才有资格不俗——首俗做法是全行业试错试出来的"最大公约数",撞上它 =
图还没发就被归入"见过的一万张"。

| brief 类型 | 最俗的做法(避开) | 反向找空间 |
|---|---|---|
| 科技发布 | 深蓝紫渐变 + 发光球 + 网格线 | 克制留白 + 一种材质(金属/压印) |
| 促销 | 满屏红黄爆炸贴 + 斜体大字 + 倒计时 | 大字报 + 单色高对比(`composition.md §五` 大字报行) |
| 知识干货 | 均质圆角卡片 2×2 排列 | 编号清单 + 尺度天窗(`typographic-expression.md §二`) |
| 文艺 | 宋体居中 + 水墨 + 印章堆得太满 | 一个器物特写 + 大留白,字退到边缘 |
| 咖啡/食品 | 暖色木桌 + 蒸汽 + 俯拍 | 单点特写 + 正视角度 + 底色换出暖棕系 |
| 招聘 | 大楼仰拍 + 握手 + "加入我们" | 一张真实工位/一次工作瞬间 + 一句实在话 |
| 教育/课程 | 蓝底白字 + 毕业帽 + 书堆 | 手写笔记质感 + 一道被划了重点的原题 |
| 健身/运动 | 黑底 + 荧光绿数字 + 肌肉特写 | 纸感底 + 一个动作定格 + 器械几何线条 |

**挂钩 rubric E 维**(`design-review-rubric.md §一` E):避开首俗 + 一处主导动作(§二)
= E 维 5 分的充分路径;命中首俗做法 = 至多 3 分——"装饰堆砌/默认居中/卡片墙"等自检条目
会连带不过(`guardrails.md` 反味 6/10/12)。

**判据**:初稿与上表并排,命中任意一行中列的**任意一个元素** → 回炉重想,不是"改一改"。
交付汇报写一行**反套路声明**:「避开了 __,改用 __」。

## 六、三方向并行(说不清时的生成兜底)

> 同一 brief 产出 3 个**彼此可区分**的方向。**分工**:本节负责"**想**"三方向(生成期纸面动作,
> 不加导出成本);`revision-protocol.md §5` 三版对比负责改稿期的"**呈现**"三版(何时导出、怎么给用户挑)。
> 呈现形态的完整版(一次 4 稿 + 一张 2×2 联络表 + 选择即转正)在 `multi-draft.md`
> (**备选模式:默认单稿,仅用户要求 / 说指令 / 同意提议时触发**)——本节管"想"方向,
> multi-draft 管"批量呈现与选择",互指、不双轨。

| 方向 | 定位 | 主导动作取法 |
|---|---|---|
| **1 保守正确** | 最稳的解法,不犯错也不出彩——保证"有图可交"的兜底 | 不刻意做主导动作,守全部规则 |
| **2 激进表达** | 主导动作最外放 | 候选库(§二)里最险的格(超尺度/出血) |
| **3 折中巧思** | 用一个小装置点题,险与稳之间 | 候选库里最轻的格(负空间/一处错位) |

**判据(方向成立的唯一标准)**:三方向必须能被**一句话区分**——"这版靠留白 / 这版靠对比 /
这版靠概念";说不出差异的两版是假方向,重想。

**实演(虚构 brief 走通,非咖啡)**:brief「社区旧书置换店开业海报,受众是附近居民,要有人情味」:
- 反套路先声明:避开"书堆 + 宋体居中 + 水墨印章"的文艺首俗(§五);
- 四段(以方向 3 为例):概念「书不退休,只换岗」→ 装置「两只手交递一本书的剪影,四周大留白」→ 版式「对角动线,交递点压三分线交点,文字退到剪影之外」;
- 三方向区分:①保守正确——靠书脊横排的秩序感(三分骨架 + 规整信息层级);②激进表达——靠一个"换"字的巨构(超尺度,笔画间嵌书脊条纹);③折中巧思——靠交递剪影的负空间(手与书之间的空隙是画面主角)。
- 三句话互斥,方向成立。

**默认**:选不出时交**方向 1**(保守正确是兜底);2/3 记入 `design-prompt.txt` 备选——
用户改稿说"平淡/差点意思"时,它们是第一响应(`revision-protocol.md §2`「再来点设计感」条)。
**不默认三稿齐出**:导出几版由 revision-protocol §5 的触发条件决定(用户说不清才呈现多版)。

## 七、软提示接线(人格三词 → design-prompt.txt)

> `style-guide.md §3` 规定配「硬提示(约束+自检)+ 软提示(创意简报)」一对;
> `intake.md` 五问收人格与反参照(Q5.5)。本册把软提示定成**固定四行格式**,写进项目
> `design-prompt.txt`——保存位沿用 `pipeline.md Step 1.5`(提示词本就落在那里,不新增文件):

```
【人格】三个词(如:克制 / 手工 / 温暖)
【参照】一个视觉参照(如:"像 MUJI 的海报" / "像 Aesop 的店面")
【主导动作】一句话(如:"大留白里一枚小印章")
【反参照】用户明确不要的(如:"不要蓝紫渐变";来自 intake Q5.5,优先级最高)
```

**人格三词怎么提(可操作)**:从 brief 找"它像什么人 / 什么器物 / 什么场合",收成三个
**能落到参数的词**(克制、厚重、低哑、响亮、玩心……);**禁用评价词**(高级、大气、好看
——评价词不可执行,落到 CSS 就是空的)。人格三词 → 语气(Power/Quiet/Playful/Editorial)
的映射见 `typographic-expression.md §一`。

**参照怎么给**:一个可指认的真实参照(品牌/刊物/物件),不是风格词堆砌——
"像 MUJI 的海报"比"极简风"信息量大一个数量级:参照自带密度、留白、字体气质的默认值。

**主导动作一句话**:先在 §二 候选库选类型,再写成一句话("超大单字出血" / "一处压印浮雕")。
**改稿时对照它检查"主导动作还在不在"**——定点改稿最容易把记忆点顺手改没了;没了要报给用户。

## 八、与 composition 的顺序纪律(不能反)

```
本册(生成:概念 + 主导动作) → composition.md(骨架:动线/骨架/网格) → 写 HTML
```

**先**生成"主导动作 + 概念",**再**去 composition 选"动线/骨架/网格"**服务于它**;
反过来(先选骨架再想概念)= 骨架变成模板,图会"正确但平庸"。§一 四段模型的末段
必须落到 composition——生成层不架空结构层。

**判据**:回看每一条版式决策(动线/骨架/留白位置),都能回答"这是为概念/主导动作服务的吗"?
答不上来的那条是惯性动作,重想。

**例外**:B/C 模式(复刻/换风格)不启动本册——视觉基准已在参考图里,直接走
`replicate.md` 与风格分册;仅当用户明说"可以改良"时,才进入本册补概念。

## 九、复杂度预算(一图最多花多少力气;防过度设计)

> 概念可以大胆,实现必须有预算。一张图是"设计",不是"炫技合集"。本节把"克制"量化成生成期可数的上限——
> **不放宽铁律 3 与密度 4/10,只是把它们翻译成"想概念时就能数"的口径**(验收仍以 `guardrails.md` / `design-review-rubric.md` 为准)。

| 预算项 | 上限 | 理由 |
|---|---|---|
| 概念数量 | **1 个**(主导动作唯一,§二) | 两个概念 = 没有概念,观众只会记住"乱" |
| 视觉手段(特效/伪3D/纹理合计) | ≤3 种(铁律 3 原文) | 手段互相抢戏,焦点消失 |
| 装饰层次 | ≤2 层(背景介质层 + 点缀层) | 每层装饰都要求观众付一次注意力 |
| 字体 / 强调 / 层级 | 3 / 2 / 3(铁律 3 原文) | — |
| 信息密度 | 4/10(`guardrails.md §2`) | 每个元素都要挣得自己的位置 |
| 讲完时间 | 信息流里 ≤3 秒讲完主信息 | 讲不完 = 设计过度或信息过载,二选一返工 |

**预算用法(生成期三问,答不出就砍)**:
1. 这个手段在主导动作的服务链上吗?不在 → 砍(§八 判据同源);
2. 砍掉它,主信息有损失吗?没有 → 它是装饰,砍;
3. 预算满了还想加?**先还后借**:新加一种手段必须删一种旧的,总账不涨。

**与既有口径的关系**:密度 4/10 管"版面信息密度",本节管"设计手段密度"——两把尺子独立量,都不放宽。
预算没花完不是偷懒,是克制;案例:`concept-case.html` 全图只有"一束光"一个概念,其余全部规整退让。
