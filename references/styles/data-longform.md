# 数据长图(data-longform)

> 一句话定位:行业报告/干货科普的 2400 宽纵向长图,章节化叙事 + 统一图表语言。
> 来源统一见仓库 README「致谢」。

## 画布与安全边距
- 尺寸:long 预设(**2400×auto**,高度随内容,通常 4000–8000px;scale 1,内容稀疏可 2)。
- 安全边距 6%(144px);章节间距 ≥ 200px。

## 色彩角色表
| 角色 | 值 | 用法 |
|---|---|---|
| 底 bg | `#f4f6fa` | 冷灰蓝纸感 |
| 近黑文字 ink | `#101a2e` | 标题正文 |
| 主色 primary | `#1f4e9c` | 图表主系列、章节号 |
| 强调 accent | `#e8b93c` | 图表高亮系列 + 关键数字,**每屏 ≤1 处** |
| 辅助 muted | `#6b7688` | 来源注、轴标签 |

## 字体栈
| 角色 | 字体 | 字重 | 字距 |
|---|---|---|---|
| 章节大标 | [思源黑体](../../fonts/source-han-sans/INTRO.md) | 900 | 0.02em |
| 正文 | [思源黑体](../../fonts/source-han-sans/INTRO.md) | 400 | 0.01em |
| 大数字 | [思源黑体](../../fonts/source-han-sans/INTRO.md) | 800 | 0(用 `font-variant-numeric: tabular-nums`) |

## 字号阶(2400 宽基准 = 1080 基准 × ~1.8)
题图主标 200–260 / 章节标 90 / 小节标 56 / 正文 44–52 / 图表轴注 30 / 来源注 28。

## 网格与间距
24px 间距系;内容列宽 ≤ 2000px 居中;数据板块两栏网格(图表 1200px + 解读 700px)。

## 章节结构(自上而下)
1. **题图**:主标 + 一句导语 + 报告元信息(日期/出品),fx-mesh 浅色变体。
2. **导语卡**:3 行以内说清"这张图讲什么"。
3. **数据板块 × N**(每板块 = 一个论点):
   - 图表(ECharts,统一主题)+ 右侧 2–3 条解读(**解读比图重要**)。
   - 板块编号(章节大数字,muted 色 20% 透明度)。
4. **结论区**:3 条 takeaways,accent 高亮关键词。
5. **页脚**:数据来源、制作方、日期。

## 图表语言(ECharts 统一主题)
- 注册统一 theme:字体思源黑体、轴色 muted、系列色 [primary, accent, #6b9bd2, #b0b8c4]。
- 柱状/条形为主角,折线看趋势,饼图 ≤4 扇区;**禁 3D、禁双 Y 轴堆两张图**。
- 网格线 1px `rgba(16,26,46,.08)`;数据标签只标最大/最小/最新三项。

## 布局原型(板块级)
| 论点形态 | 原型 | 图表 |
|---|---|---|
| 增长/趋势 | 时间线 | 折线/面积 |
| 构成占比 | 构成 | 堆叠柱/环形 |
| 多方对比 | 对垒 | 分组柱 |
| 转化漏斗 | 漏斗 | funnel |
| 要素拆解 | 鱼骨/树 | 手排 HTML(SVG 线 + 节点卡) |
| 单一巨数 | 大数字卡 | 数字 + 同比箭头 |

## 调性禁则
1. **每屏一个论点**:一个数据板块讲一件事,讲完就收。
2. 图表配色超 4 个系列 = 重新分组,不准加色。
3. 禁无来源的数据;来源注字号 ≥28 且不省略。
4. 禁图表标题党——标题写结论(「A 反超 B」),不写指标名(「A 与 B 对比」)。
5. 章节大数字、章节标、图表三者层级必须拉开(字号差 ≥1.5 倍)。
6. 禁在长图里塞二维码超过 1 个(放页脚)。
