# 排版表达分册(语气 · 尺度天窗 · 节奏张力 · 字体即图形 · 编辑母版)

> **何时读**:排版"排对了但太平"、要"排出语气/冲击力"、要做超大标题、要做杂志感长文时。
> **单一真相源声明(防多真相源)**:
> - 本册只讲排版的**表达层**:语气、尺度戏剧性、节奏、张力、字体即图形、编辑母版、版式实验;
> - 断行/孤字/禁则/行距/对齐/数字等**硬规则** → `typography-rules.md`,本册一条不重复;**冲突时硬规则优先**(§八);
> - 字号阶/字距底线/层级地板 → `guardrails.md §3`,本册**不另起字号阶、不新增加权**,一切语气都在既有阶内实现;
> - 标题**字形级**处理(描边/蒙版/错位/模糊)→ `title-fx.md`;本册管**整体语气与尺度**,两册互指不重叠;
> - 断行与竖排的 CSS 实现 → `cjk-typography-css.md`;网格与动线骨架 → `composition.md`。

---

## 〇、第一原则:"排对"是底线,"排出语气"才是设计

`typography-rules.md` 保证"不出错";本册保证"有性格"。

**同一份文案,换一套排版参数,可以读成权威、安静、活泼或编辑感——这就是语气。**
眯眼看十张"排全对"的图,八张是一个表情:参数全在安全区,语气全不在场。"太平"不是排版错误,是排版**没有做主张**。

**前提(不可谈判)**:任何语气都必须**先过硬规则**——禁则、孤字、对比度、不溢出。
行首落了句号的"个性"不是个性,是错字;行高压到 1.2 的"紧凑"不是风格,是违规。表达在硬规则划出的场地内踢球,场地不能改(裁决细则见 §八)。

## 一、语气系统(四种,属性映射)

> **纪律:一张图只用一种语气。** 混语气 = 精神分裂——Power 的大色块里塞 Quiet 的宽字距小字,读者读到的不是丰富,是没想清楚。
> 语气由 brief 的**人格三词**决定(提取方法见 `design-thinking.md §七`);人格三词到语气的映射:响亮/自信/制造 → Power;克制/细腻/器物感 → Quiet;活泼/亲切/玩心 → Playful;理性/专业/叙事 → Editorial。

| 语气 | 场景 | 字号对比(主标:正文) | 字重 | 字距 | 对齐 | 行高 | 附加 |
|---|---|---|---|---|---|---|---|
| **Power 权威** | 发布/公告/大字报 | 天窗 3–6×(§二) | 主标特粗(库内真字重 800–900,禁假粗体),正文常规 | 主标 0 ~ −0.03em(**仅展示级大标题**;正文 0,禁负字距) | 左或中(**主对齐唯一**) | 标题 1.1(guardrails 下限;图形化展示字例外见 §五),正文 1.6–1.8 | 出血大色块(装饰出血,文字不出安全边距)、大数字 |
| **Quiet 安静** | 文艺/奢品/日系 | 中等 1.8–2.5× | 常规/细(选库内真细字重,不用 CSS 压细) | 主标 0.02–0.06em;**≤8 字短标签**可拉宽 0.12–0.3em 做奢侈感 | 左(首选)或中 | 正文 1.75–1.9(取既有区间上半) | 大留白(≥40%)、单色系、发丝线 |
| **Playful 活泼** | 手账/活动/母婴 | 混合:天窗主标 + 小批注 | 多变:同族 2–3 档字重混排(字体仍 ≤3 款) | 正文 0;装饰字随性 | 主对齐唯一;**"破"只允许局部**:贴纸/批注旋转 −3°~3°、个别字 ≤6° | 正文 1.5–1.7(硬下限 1.5 之上取短),标题 1.1–1.3 | 贴纸、手写批注(用库内手写体,禁 CSS 斜体)、错位(位移 ≤ 字高 20%,`title-fx.md §四`) |
| **Editorial 编辑** | 杂志/报告/长图 | 层多而有序 1.5–2.5× | 2–3 档字重梯(如 900/500/400) | 正文 0–0.02em | **左对齐严格**(全图唯一主对齐) | 正文 1.6–1.8 | 网格分栏、首字下沉、边注、页眉页脚(§六) |

**四语气通用硬边界**(逐条对应既有硬规则,不得越):
- 中文永不斜体——"斜体感"用宋体/楷体/手写体替代(`typography-rules.md §二` 既有硬条);
- 同级元素字号/字重/间距完全一致——语气改变的是**级间差**,不是级内乱(`typography-rules.md §二` 既有硬条);
- 层级 ≤3、强调 ≤2、字体 ≤3 款、特效 ≤3 种(`guardrails.md` 铁律 3)——四种语气都不加层。

## 二、尺度对比:地板与天窗

- **地板(既有硬规则,下限)**:相邻层级 ≥1.15–1.25×,主标 vs 正文 ≥1.5×(`typography-rules.md §二`)。地板回答"能不能分清"。
- **天窗(本册新增,表达)**:主标 vs 正文拉到 **3–6×** 造戏剧性。天窗回答"记不记得住"。**越大越敢 → 越有冲击力**,但**中间地带要空**:想要戏剧性却停在 2× 左右,是最尴尬的档位——既不整齐(不成秩序)也不震撼(不成焦点)。

**算例**(1080 宽画布,全部取自 guardrails 既有字号阶,不另起阶):

| 方案 | 主标 | 正文 | 倍数 | 判读 |
|---|---|---|---|---|
| 只守地板 | 48px | 32px | 1.5× | 分得清,但"喊"不起来——多数"太平"的图卡在这 |
| **克制天窗** | 88px(阶下限) | 28px | **3.1×** | 主标开始"喊",正文退成"耳语",冲击力成立 |
| **强天窗** | 160px(阶上限) | 28px | **5.7×** | 发布级张力;副标直接并入主标块或给 56px,**不排 40/48 的中间层** |

**判据**:眯眼(或缩到 15% 宽)看图——主标"喊"、其余"耳语" → 尺度成立;大小"差不多" → 层级没拉开(`composition.md §二` 既有焦点判据)。

**纪律**:
1. **天窗全图只给一个元素**(通常主标),其余全部退到地板附近——两个元素同时"喊" = 没有焦点(铁律 3);
2. 天窗是**既有层级差的极端化**,不是加层——层级仍 ≤3,天窗不违反它;
3. 天窗与超大字体(§五)是两件事:天窗仍在"文字"范畴(88–160px),§五已把文字当图形(400px+)。一张图**二选一**,都上 = 两个焦点。

## 三、节奏与韵律

排版的节奏 = **重复 + 变化**。全重复 = 单调;全变化 = 噪音;节奏 = 在重复的底上放变化。

| 手段 | 做法 | 注意 |
|---|---|---|
| **重复** | 同级元素的间距/字号/字重**完全一致** | "整齐感"的唯一来源;这是 `typography-rules.md §二` 硬条的正面用法,不是可选项 |
| **变化** | 每隔 N 个同级元素变一次(换强调色/加粗/缩进) | N 固定(如每 3 条),随机变 = 噪音;变化仍计入"强调 ≤2" |
| **断点** | 长内容每 **3 行**一个视觉停顿(空行/小标/发丝线) | 长图可读性的关键;`composition.md §一` F 动线既有"每 3 行一个断点" |
| **呼吸** | 组内紧、组间松,**≥2:1** | `typography-rules.md §三` 既有(板块间距 = 组内 2–4 倍);倒过来 = 元素糊成一片 |

**口诀:重复建秩序,变化建节奏,断点建呼吸。**

**判据**:同级元素两两并排看,完全一致才算"重复"成立;任意相邻两板块,组间距量出来 ≥ 组内距 2 倍才算"呼吸"成立。

## 四、张力(拥挤 vs 空旷)

- **张力 = 密度反差**。全图每处都是中等密度 = 没有张力;一处极密 + 旁边极空 = 强张力。
- **做法**:核心信息**密**(紧凑成块:组内距取下限、行宽收窄),周围**空**(让出大留白)——"字块浮在留白里"。
  注意:密块的"密"是**排得紧**(间距收缩),不是行高压扁——行高仍在 1.5–2.0 硬区间内。
- **禁区**:
  - 四边均匀镶边式留白(`guardrails.md` 反味 11 / `composition.md §七`:留白必须有意图,呼吸位在焦点旁);
  - 全图等密度——等密度 = 没有主次,眼睛没有落点。

**判据**:把画面按 3×3 分区,应能指出"最密的一格"和"最空的一格",且最空一格紧邻最密一格;指不出 = 没张力。

## 五、字体即图形(超大字体排版 Oversized Typography)

> `styles-catalog.md` expressive 组「超大字体排版 Oversized Typography(文字即布局,当下头号趋势)」列了方向,本节是它的实现配方。
> 定义:让文字大到**成为画面主体/骨架**(字号占画布宽 40%–100%,或单行占宽 60% 以上),读者先看见"形",再读出"字"。

**可抄配方**(1080 宽基准,其他画布按 `画布宽 × 系数` 等比换算;**用固定 px,不用 vw/vh**——导出语境视口 ≠ 画布,铁律 1 同源理由):

```css
/* 超大主标:字号 = 画布宽 × 0.4–1.0(1080 → 432–1080px);两行以内 */
.oversized{
  font-size: 460px;
  line-height: .95;            /* 图形化展示字专用,窄豁免见 §八 */
  letter-spacing: -.02em;      /* 负字距仅展示级大标题(guardrails 既有);中文逐字看粘连,导出后必看图 */
  font-weight: 900;            /* 库内真字重,禁假粗体 */
}
/* 图形化裁切:溢出部分裁在【画布内的窗口】里,不出画布(硬规则裁决见 §八);
   窗口元素另标 HTML 属性 data-allow-overflow(机检装饰豁免) */
.oversized-crop{ position: absolute; overflow: hidden; }
.oversized-crop > span{ display:block; }
/* 空心大字当图形:描边宽 ≤ 字号 1%(460px → ≤4.6px;过粗笔画自粘连) */
.oversized-outline{ color: transparent; -webkit-text-stroke: 3px var(--c-ink); }
```

```html
<!-- 裁切窗用法:窗口本身是装饰容器,标 data-allow-overflow 声明"故意" -->
<div class="oversized-crop" data-allow-overflow>
  <span class="oversized-outline">秋</span>
</div>
```

**中文注意(逐条带理由)**:
1. **大字只放短词(≤5 字),长句禁**——超大号的"读"已变成"看",长句在 400px+ 字号上既读不了也放不下;
2. **语义断行必须手动给**(`<span class="tl">`,方法同 `typography-rules.md §一` / `cjk-typography-css.md §四`)——浏览器逐字断行,超大字断错一词毁全图;两行按语法边界断,多行末行 ≥3 字;
3. **负字距上限 −0.03em**,且逐字检查笔画是否粘连——中文笔画密,西文的 −0.05em 惯例对中文过量;
4. **对比度复核不豁免**:空心字描边、背景图形字用低对比色时,确认它**不承担信息**(信息在别处完整出现)——装饰读不清是设计,信息读不清是事故。

**配合伪3D**:超大标题 + 挤出(`depth-3d.md §三` B/C 配方)是"文字即画面"的强解;注意特效计数(铁律 3)与"只做标题一处"纪律。

**构图归属**:大字报骨架(主标占版面 30%+ 面积,其余让路)见 `composition.md §五`;瑞士海报/超大字体排版等方向的气质词见 `styles-catalog.md`。

## 六、编辑设计母版(≥6 手法)

> 来源:杂志/期刊的版式语言。骨架前提:先有网格(`composition.md §四`),编辑感是**网格严谨**的副产品;**不与满版出血混用**——编辑的精致靠栏线与留白,出血会吃掉它。

| 手法 | 实现要点 | 为什么成立 |
|---|---|---|
| **跨栏标题** | 标题 `grid-column: 1 / -1`,正文分栏 | 标题横贯全宽 = 天然的阅读入口,栏区从它下面开始 |
| **首字下沉** | `p.lead::first-letter{ float:left; font-size:3em; line-height:.9; margin-right:.08em; font-weight:900; }` | 一图 ≤1 处,只给正文第一个字;下沉字用衬线/楷体更有书卷气 |
| **边注** | 侧栏小型注(`grid-column` 窄栏或右侧 240px 窄列),20–24px,muted 色 | 主文 26–32px、边注 20–24px,级差守地板;边注是"学术/杂志"的最强身份信号 |
| **引文块** | 大号衬线 + 大引号 + 缩进 + 左侧竖线;中文引语**用字体重替代斜体** | 引文是版面的"换气口";引号按风格分派(杂志感用「」,通用用"") |
| **栏线与分隔** | 发丝线 `1px` 低对比色分隔板块/栏目 | 用"线"替代"空白"做区隔,是编辑感与海报感的分水岭 |
| **页眉页脚** | 顶部眉题(品牌/栏目名,宽字距小字)+ 底部页码/落款 | 「期刊感」的直接来源;页码数字用 `tabular-nums`(`numeric-typography.md §一`) |
| **基线网格** | 正文吸附基线单位(公式见 `composition.md §四.2`),纵向间距取基线 0.5/1/2/3 倍 | 跨栏文对齐的隐形骨架;栏间文字"行行相咬"就是它 |

**纪律**:编辑设计 = 网格严谨 + 左对齐严格 + 层多而有序;三者缺一,只剩"字小行多",不叫编辑感。

## 七、版式实验手法(何时用 + 四问纪律)

| 手法 | 实现 | 何时用 | 硬边界 |
|---|---|---|---|
| **竖排** | `writing-mode: vertical-rl`(`cjk-typography-css.md §八`) | 国风/日系/短标题 | 只放短句;竖排 + 固定画布 + 长文 = 极易溢出(既有警告) |
| **旋转** | 局部 `transform: rotate(±2~6deg)` | 活泼/贴纸/动感 | 正文绝不旋转;个别装饰字 ≤6°(`composition.md §三.4` 既有) |
| **错位** | 逐字 `translateY`(`title-fx.md §四`) | 排版要"活" | 单字位移 ≤ 字高 20%,过大松散(既有纪律) |
| **出血裁切** | 文字被裁掉一部分 | Power 语气/主导动作 | **真·画布出血裁字默认禁**(裁决见 §八);用画布内裁切窗(§五)实现同一观感 |
| **挤压拉伸** | `transform: scale(.82,1.18)`(`title-fx.md §五`) | 促销/冲击 | 逐字做,整行统一 scale 横向露缝(既有坑);汉字三不:不拉长压扁(`guardrails.md §3.2`)——scale 是变形,优先选库内窄体 |

**四问纪律(实验前逐问自答,答不出就不做)**:
1. **服务语气吗?** Power 才配出血,Quiet 做实验 = 自毁气质;
2. **只破一处吗?** 破两处 = 没有"破",只有乱(铁律 3 一焦点的推论);
3. **"故意"看得出来吗?** 网格可以打破,但要打破得**故意**——明显错位/出血/裁切,不是不小心(`guardrails.md §5` 既有);看不出来是失误,看得出来才是手法;
4. **过硬规则复核了吗?** 禁则/孤字/对比度/溢出逐条过;机检 `check_overflow.py` 每次重导前必跑(不受自检时机限制)。

## 八、与硬规则的关系(必读)

> 本册**不新增字号阶、不新增加权、不放宽任何硬条**。
> **冲突判定:硬规则 > 本册表达意图**。逐条裁决示例:

| # | 表达意图 | 相抵触的既有规则 | 裁决 |
|---|---|---|---|
| 1 | Quiet 仪式感想整段居中 | `typography-rules.md §四`:长段文字禁居中(居中仅标题/短句) | **从硬规则**:居中只给标题/短句,长段回左对齐 |
| 2 | Playful 想给正文负字距求紧凑 | `guardrails.md §3`:正文禁止负字距 | **从硬规则**:负字距仅展示级大标题,且逐字看粘连;正文用收窄行宽/组内距替代 |
| 3 | 想给细体中文描粗边(空心字变体) | `title-fx.md §一`:中文细体禁粗 stroke | **加 `paint-order: stroke fill` 或改用库内粗字重**,不硬描 |
| 4 | 想让超大字溢出画布被裁(真出血) | `guardrails.md §1`:文字不出安全边距;`design-review-rubric.md` B 维:文字出画布计 0 | **默认禁**;改用**画布内裁切窗**(§五:窗口在画布内,`overflow:hidden` + `data-allow-overflow`),裁掉部分不承担识读 |
| 5 | 图形化展示字行高压到 0.85–1.1 | guardrails 标题行高 1.1–1.3 | **窄豁免(仅此一处,非放宽)**:阅读型标题守 1.1–1.3;**"字体即图形"的展示字**(§五,文字已当图形)允许 0.85–1.1——此时行高语义是"拼装字块"而非"阅读行距";正文行高 1.5–2.0 硬区间与"行距全图一致"硬条**不受影响**(既有先例:`assets/cases/depth3d-case.html` 主标 1.08) |

> 排版表达**不改变** `design-review-rubric.md` 的 B 维判据——表达手法在 B 维的三个高危点(裁字、行高压扁、破断行)已分别被裁决 4、§四、§一 断行纪律挡住;做对表达,B 维不掉分,A/D 维的"有主张"反而加分。

## 九、落地自检(6 条,表达层专用;硬规则自检仍按 `typography-rules.md §六` 全过)

1. 这张图能**用一个语气词**概括吗(Power/Quiet/Playful/Editorial)?说出两个 = 混语气,砍掉一个;
2. 眯眼测试:主标"喊"、其余"耳语"?天窗只给了一个元素?
3. 同级元素两两一致?组间:组内 ≥2:1?长内容每 3 行有断点?
4. 有最密一格与最空一格吗?留白位置在焦点旁?
5. 做了实验手法?四问逐条有答案;"故意"看得出来?
6. 图形化展示字:短词 ≤5 字、手动断行、负字距逐字查过粘连、裁切在画布内窗口里?
