# EB Garamond

| 属性 | 值 |
|---|---|
| 字体文件 | EBGaramond-Italic.ttf, EBGaramond-Regular.ttf |
| 字重/变体 | Regular+Italic |
| 分类 | 英文点缀·古典衬线 |
| 气质关键词 | 古典,衬线,优雅,正文 |
| 协议/来源 | OFL 1.1 · georgd/EB-Garamond |

## 气质描述
文艺复兴老衬线:优雅、书卷、有出处感的英文首选。

## 适用
编辑风海报英文引言、品牌名、serif混排。

## 慎用
科技促销;全大写长句。

## 示例句
「海内存知己,天涯若比邻 0123456789」
