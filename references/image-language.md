# artboard 位图语言分册(图像角色 · 色调分级 · 裁切语法 · 景深 · 主体分离 · 处理链)

> **单一真相源声明(防多真相源)**:
> - 本册管「**怎么想**」:一张图进版面之前,先定**角色**(主体/背景/纹理/氛围/对比对),角色决定色调、裁切、景深、光影的全部处理选择,以及处理链的先后顺序;
> - `imaging.md` 管「**用哪条命令**」:子命令的完整参数、质量档位、场景速查一律以它为准,本册只写"这个角色该走哪条命令",不复制参数表;
> - **数值一律引用、不复制**:画布尺寸 → `scaffold.py SIZES`;平台体积红线 → `material-catalog.md`;印刷 DPI/LPI → `print-production.md`;压字对比度(4.5:1 / 3:1)与遮罩 α → `color-contrast.md`;颗粒/纸张/半调 CSS 配方 → `effects.md`;统一光源与景深四层的具体数值 → `depth-3d.md §一/§五`;找图来源与抠图模型红线 → `materials.md`。
> - 本册与 `imaging.md` 互指不重叠:读完本册知道"这张图当什么、往哪个方向处理",动手时翻 `imaging.md` 查命令。

## 0. 第一原则:先定"这张图是什么角色",再决定怎么处理

**同一张图,角色不同,处理天差地别**:

- 当**背景** → 压暗/降饱和/虚化,永远退让(它存在的意义是让文字和主体立得住);
- 当**主体** → 最锐、最高对比、抠干净,永远最前(它是动线的终点,画面为它让位);
- 当**纹理** → 去色/降对比/低透明,永远垫底(它是"材质",不是"内容");
- 当**氛围** → 局部露出/只取色调,永远服务于叙事(它是"情绪",不是"信息")。

**判断**:每张图进项目前,先在心里说一句"这张是____"。说不出来 → 这张图多余,删掉(多一张没角色的图,就多一处抢注意力的噪音,违反"一图一个焦点")。

角色**在整张图里只能有一个主体**;背景/纹理/氛围可以有多张,但都必须退让。两张图都按"主体"处理 = 两个焦点 = 重做。

## 一、图像角色定位表

| 角色 | 处理方向 | 工具(命令用法见 `imaging.md`) | 版式位置 |
|---|---|---|---|
| **主体**(Subject) | 抠图 + 软投影 + 保持最锐最高对比 | `cutout.py --shadow`、`card --shadow`(卡片化时) | 焦点区、动线终点;独占最大视觉权重 |
| **背景**(Background) | 压暗/降饱和/虚化,文字压上来前先垫层 | `tone`(--saturation/--temp)、`blur-bg`、`pad` | 满版/出血;对比度责任见 `color-contrast.md` |
| **纹理**(Texture) | 去色/降对比/低透明 + 平铺或铺满 | `tone --saturation 0`、`convert` | 垫底、装饰层;`pointer-events:none` + 最上层(见 §三纪律) |
| **氛围**(Mood) | 局部裁切/只取色调,不承担信息 | `crop --pct`/`fit` 取局部、`tone` 拉齐色温 | 次要区、负空间;小面积出现 |
| **对比对**(Contrast Pair) | 同主体前一后/两规格并列,除对比外零处理 | `derive`、`slice` | 分屏/并列/改造前后面 |

三条角色纪律:

1. **主体永不让渡锐度**:任何降饱和/模糊/滤镜都不得加在主体上(含 CSS `filter`)——主体一糊,画面失去"看哪里";
2. **背景必须退让到位**:背景的对比度、饱和度、锐度三样都要低于主体;背景抢戏的图,换一张或再压一档;
3. **角色决定命令方向**:同一张 `fit` 裁切,当背景裁取"氛围段",当主体裁取"完整物"——先定角色再定 `--gravity`,不要拿命令倒推角色。

## 二、色调分级(让多图不打架)

多图同屏,**统一色调是最低要求**(来源不同的照片各有色温,直接并排 = 廉价拼贴感)。五档手法,从轻到重:

| 手法 | 做法 | 何时用 |
|---|---|---|
| **统一色调**(最低要求) | 所有照片加同一组 `tone` 参数(如 `--temp 0.12 --saturation 0.9`),一次定死、多图复用 | 多图同屏的任何场景 |
| **双色调 duotone** | 灰度后向双色映射:`tone --duotone '#色1,#色2'`(位图)或 `fx-duotone`(CSS 配方见 `effects.md`) | 强调品牌色、强风格统一 |
| **分离调色 split-tone** | 高光偏暖、暗部偏冷(或相反),配方见下方 CSS | 电影感、质感升级 |
| **单色 colorize** | duotone 的特例:两色取**同一色相**的深浅两端(如深褐 → 米白),全图只留一种颜色的明度层次 | 编辑感、高级感、奢品质感 |
| **去色 grayscale** | `tone --saturation 0`,让彩色元素(品牌色块/价格标签)独占色彩 | 与彩色元素对撞、编辑风 |

```css
/* 分离调色 split-tone(⚠️ mix-blend 在 Kiln 矢量道会色偏/丢失,仅位图交付用;
   矢量交付改为 imageops 预渲染进位图再贴) */
.split-tone img{ filter: contrast(1.05) saturate(1.05); }
.split-tone::after{ content:""; position:absolute; inset:0; mix-blend-mode:soft-light;
  background: linear-gradient(180deg, #ffb37a, #2b4a7a); }  /* 上暖下冷:高光暖、暗部冷 */
```

三条分级纪律:

1. **先统一、再风格化**:统一色调没做之前,不允许上 duotone/split-tone——底层色温不齐,风格化只会放大混乱;
2. **一套参数管全图**:同一张图里的所有照片共用同一组 tone 参数(记进项目 `design-prompt.txt`),逐张手调 = 必然打架;
3. **去色是牺牲不是偷懒**:grayscale 后画面信息靠明度层次撑,主体与背景的明度差要拉开,否则糊成一片灰;
4. **`tone` 会拍平透明通道**(入口强制转 RGB):抠图产出的透明件**不做 tone**——需要色调的透明主体,在链上对裁切后的底图先 tone 再抠图,或在交付端用 CSS `filter` 补色调。

## 三、质感与颗粒

位图的"数字平底"感(过度锐化、纯色平滑)靠质感层压住。配方只列"何时用",CSS 全文以 `effects.md` 为唯一真相源:

| 手法 | 既有配方 | 效果 |
|---|---|---|
| 胶片颗粒 | `fx-noise`(低透明度叠加,数值见配方) | 压住数字平底,统一多图"拍摄介质" |
| 纸张肌理 | `fx-paper` + `fx-noise` 叠加 | 手账、文艺、纸质品类 |
| 半调网点 | `fx-halftone`;位图侧量化路线的适用边界见 `imaging.md` §6(扁平色才划算,渐变图禁) | 波普、印刷感 |
| 扫描线/故障 | 重复线性渐变(`repeating-linear-gradient`) | 科技、赛博、Y2K |

**纪律**(带理由):

1. 纹理层一律 `pointer-events:none` + 最上层——它盖在所有内容上做"介质",不许吃交互、不许只盖一半;
2. **一图只一种纹理**——颗粒 + 纸纹 + 半调同时上 = 三种介质打架,画面立刻脏;
3. 纹理计入特效数(铁律 3"特效 ≤3 种"把纹理算在内)。

## 四、裁切语法(构图裁切 + 禁裁字)

裁切是"用画布边缘做构图"。五种语法,按语气从稳到险:

| 裁切方式 | 做法 | 效果/语气 |
|---|---|---|
| **三分裁** | 主体压在三分线/交点上(`fit` + `--gravity`,或 `smartcrop` 主体感知) | 稳妥,默认选择 |
| **切主体** | 画布边缘故意切掉主体一部分(`crop --pct` 定向切) | 张力、冲击;"主导动作"候选 |
| **负空间裁** | 主体缩置一角,大面留白(`pad` 补边或版式留白) | 高级感、Quiet 语气 |
| **特写裁** | 只留局部细节放大(`crop --box` 取局部) | 冲击、抽象、质感放大 |
| **对望裁** | 人物视线/动势朝留白侧裁(`fit --gravity` 朝向控制) | 引导动线,视线把读者带回版面 |

**四条红线(硬,违反 = 重做)**:

1. **含文字图禁止裁字**——字被切一半 = 废图,不是构图(`imaging.md`、`responsive-reflow.md` 既有硬红线;理由:半截字读不出信息,还暴露"机器裁的");
2. **人物不裁断关节**(手肘/膝盖/腕),不裁头顶——关节切断读作"伤残",头顶贴边读作"憋闷",都要留呼吸;
3. **产品图不裁掉品牌标识**——logo/型号是品牌资产,裁掉等于替用户毁素材;
4. **裁切后主体仍完整可辨**——"切主体"是故意张力,必须看得出是**故意的**(切得果断、切在动势上);切得含糊 = 事故,不是语法。

## 五、景深四层(数值真相源:`depth-3d.md §五`)

位图参与画面纵深时,按四层分工;**每层只做自己的事**,越权即假:

| 层 | 角色语言 | 处理 |
|---|---|---|
| **前景**(可选) | 制造"镜头很近"的遮挡感 | 轻 blur + 降饱和,小面积 |
| **主体** | 焦点层,全图唯一 | **最锐、最高对比,永不 blur** |
| **背景** | 退让层 | 预虚化:`blur-bg` 铺底,或直接换虚化图 |
| **空气层**(可选) | 层与层之间的"空气透视" | 半透明白/暖雾薄纱,拉开层间距 |

四层的 blur 量级与 α 数值以 `depth-3d.md §五` 为唯一真相源,此处不复制。

**禁用项(带理由)**:

1. **禁主体 blur**——焦点层一糊,画面没有"看哪里",景深结构直接塌;
2. **禁全图统一 blur**——全糊不叫景深,叫没对上焦;景深 = 层与层之间的锐度**差**;
3. **产品白底图禁 `blur-bg`**——毁掉干净白底(`imaging.md` 既有),白底产品图该用 `pad --bg '#ffffff'` 补边。

## 六、主体分离:抠图后的光影一致性

抠图不是终点,**"贴回去"才见功力**——抠得再干净,光影不对就是贴纸感。三条:

1. **投影方向 = 全图统一光源方向**(`depth-3d.md §一`,定一次全图遵守);抠图件用 `cutout.py --shadow` 生成软投影,方向、软硬并入全图光源体系,不许抠图件自带"照片原阴影"残留(原影方向与新光源打架,一眼假);
2. **投影软硬随"离地高度"**:贴地的元素投影**短而硬**(接触阴影),悬空的元素投影**长而软**(距离阴影)——软硬是高度的物理暗示,全图同软硬 = 所有东西都飘着;
3. **环境光匹配**:主体色温与背景不一致时,给主体加轻微环境色/边缘光(背景偏暖,主体边缘蹭一点暖)——没有环境光反射的主体像"抠出来贴上去的",这正是要消除的贴纸感。

## 七、处理链固定顺序模型(不许乱序)

```
① 方向矫正 → ② 几何(裁/补/缩) → ③ 抠图(如需要) → ④ 色调统一 → ⑤ 合成垫层/压字 → ⑥ 压缩收口
 exif-fix      fit/pad/crop        cutout.py         tone/duotone      scrim/contrast-check    compress
```

**为什么是这个顺序**(每步依赖上一步的产物,乱序 = 返工):

1. **方向最先**:手机图带 EXIF Orientation,不先旋正,后面一切几何坐标全错(`imaging.md` 铁律 1);
2. **几何在抠图前**:先裁到目标比例再抠,算力只花在留下的画面上;先抠再裁 = 抠一整张废掉大半;
3. **色调在合成前**:先把多图色调拉齐,再上版叠层——先叠层后调色,垫层/文字会被一起染色;
4. **压字对比度在压缩前验收**:`contrast-check` 过线后才许 `compress`——压缩(尤其有损格式)会移动色彩,验收必须针对最终像素;数值口径见 `color-contrast.md`;
5. **压缩永远最后**:前面每一步(裁切重采样、抠图羽化、色调重映射)都可能放大体积或重写像素,提前压缩 = 白压。

色调/滤镜/图层环节的**可重放配方**用 `scripts/pixel.py`(references/pixel-pipeline.md);
一条链到底用 `pipeline` 子命令(`imaging.md` §3);中间步骤的产物保留,改稿时从最近的有效步骤重放,不从头再来。

## 八、位图语言自检(6 条)

1. 每张图**角色**说得出吗?(主体/背景/纹理/氛围/对比对;说不出的图删掉)
2. 多图**色调**统一了吗?(最低要求:同组 tone 参数;更高:duotone/split-tone)
3. **裁切**没裁字、没裁断关节、没裁品牌标识、主体完整可辨?(§四四红线)
4. **景深**成立吗?主体最锐、背景虚化、锐度差存在?(§五;主体/全图禁 blur)
5. 抠图件**投影**方向与全图光源一致?软硬随高度?环境光匹配了?(§六三条)
6. **处理链**顺序对吗?压字对比度在压缩前过验收了吗?(§七;机检 `contrast-check` 输出为准)
