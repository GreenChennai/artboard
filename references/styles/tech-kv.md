# 科技发布 KV(tech-kv)

> 一句话定位:产品发布会/版本更新主视觉,深底、克制、高级,"少即是多"的代言人。
> 光效原理研究自 Art 视觉特效组件(无 LICENSE,原理参考后自写)。

## 画布与安全边距
- 尺寸:kv 预设(1920×1080,scale 2);衍生 vertical(1080×1920)社媒竖版。
- 安全边距 8%;光效与网格线可满幅出血。

## 色彩角色表
| 角色 | 值 | 用法 |
|---|---|---|
| 底 bg | `#0e0b1e`(近黑紫夜) | 唯一底色,禁纯黑 #000 |
| 文字 ink | `#f2eeff` | 主标题(白非纯白) |
| 主色 primary | `#7c5cff` | 光效、渐变、网格线 |
| 强调 accent | `#2ee6a8` | **全图只给一个元素**:版本号/一颗星/一行高亮 |
| 辅助 muted | `#8f89a8` | 副文、日期、logo 条 |

## 字号阶(1920 宽基准)
主标 150–190 / 副标 52 / 参数 36 / 标签 26 / 页脚 22。

## 网格与间距
12px 间距系;中轴对称为主;特性区三等分栏,间距 48px。

## 布局原型
| 场景 | 原型 | 结构 |
|---|---|---|
| 发布主 KV | sparse | 顶部小字日期 → 中央产品名(占 40% 高)→ 底部特性一行 |
| 版本更新 | balanced | 左侧大版本号 + 右侧 3 条特性卡(fx-glass) |
| 倒计时 | sparse 变体 | 中央巨大数字,四周极简,accent 色秒针点 |

## 组件语言
1. **光幕背景**(fx-mesh 深色变体 + fx-grid):主光在标题后方,亮度向边缘衰减。
2. **玻璃特性卡**(fx-glass):3 条特性,图标 28px + 标题 + 一句话。
3. **版本号胶囊**(fx-glass 窄条):「v3.0」用 accent 色,全图唯一焦点。
4. **光晕焦点**(fx-halation):给产品名或 logo,不叠加使用。
5. **星云底纹**(fx-plasma,opacity ≤0.5):只在角落,不与网格线抢。

## 调性禁则
1. **发光元素 ≤1 处**(fx-neon/fx-halation 二选一);霓虹到处开 = 网吧。
2. 禁纯黑 `#000` 底、纯白 `#fff` 字(用紫夜底 + `#f2eeff`)。
3. 特性卡 ≤3 张,每张一句话——KV 不是说明书。
4. 禁照片直贴(除非已统一调成深色 duotone)。
5. 渐变只允许 primary 单色系深浅,禁彩虹渐变横幅。
6. 留白 ≥ 40%:深底图的呼吸感就是高级感本身。
