## 一、权威阈值(含"大字"定义)

> `guardrails.md:56` 只写「大字 3:1」没说多大算大字——本节的 pt/px 界定即"大字"的定义。

WCAG 2.2 SC 1.4.3 原文界定:

| 文字类别 | 定义 | 最低对比度(AA) |
|---|---|---|
| **常规文字** | 小于 18pt,或小于 14pt 粗体 | **4.5 : 1** |
| **大字** | **≥18pt(24px)常规**,或 **≥14pt(18.66px)粗体** | **3 : 1** |
| 图形/界面组件 | 图标、边框、图表线 | **3 : 1** |
| 装饰性/禁用文字 | 纯装饰、已禁用态 | 无要求 |

换算基准:1pt = 1.333px @96dpi(浏览器 CSS 标准)。

**artboard 落地口径**(画布宽 1080 基准,其它宽度等比):

| 元素 | 字号 | 属于 | 阈值 |
|---|---|---|---|
| 主标 88–160px | ≥24px | 大字 | 3:1(但**主标建议仍按 4.5:1 做**,它是画面门面) |
| 副标 40–56px | ≥24px | 大字 | 3:1 |
| 正文 26–32px | <24px 的才算常规 | 常规 | **4.5:1** |
| 标签 20–24px | 边界 | 常规 | **4.5:1**(取严) |
| 页脚 18–20px | <24px | 常规 | **4.5:1** |
| 二维码 | — | 图形 | 3:1,且码宽 ≥ 版面宽 8%(铁律 9) |

> ⚠️ 1080 基准下**只有主标和副标够"大字"**。正文/标签/页脚一律按 4.5:1 做——这比"目测差不多"严得多,也是最常见的对比度事故区。
> 印刷品类:`formats/card.md` 的 7pt 底线、`formats/rollup.md` 按视距给的字号阶,都**不豁免**对比度,只是字号下限不同。

## 二、相对亮度与对比比(可手算)

### 2.1 公式

**Step 1 · 通道线性化**(c = R/G/B 归一化到 0–1):
```
c_lin = c / 12.92                      若 c ≤ 0.03928
c_lin = ((c + 0.055) / 1.055) ^ 2.4    否则
```

**Step 2 · 相对亮度**:
```
L = 0.2126 × R_lin + 0.7152 × G_lin + 0.0722 × B_lin
```

**Step 3 · 对比比**(L1 = 较亮者,L2 = 较暗者):
```
ratio = (L1 + 0.05) / (L2 + 0.05)
```

### 2.2 手算示例(暖纸 tokens,`style-system.md:46`)

底色 `#faf7f2` 上的 ink `#1a1712`:

```
#faf7f2 → R_lin .9560  G_lin .9302  B_lin .8880  → L = .9326
#1a1712 → R_lin .0103  G_lin .0086  B_lin .0061  → L = .0088
ratio = (.9326 + .05) / (.0088 + .05) = 16.7 : 1   ✅ 远超 4.5:1
```

### 2.3 常用中性色对白/黑底的对比比(速查)

| 灰阶 | 对白 `#fff` | 对黑 `#000` | 结论 |
|---|---|---|---|
| `#111` | 18.9 : 1 | — | 白底正文最佳起点(`guardrails.md:56` 要求禁纯黑,从 `#111` 起步) |
| `#333` | 12.6 : 1 | — | 安全 |
| `#595959` | 7.0 : 1 | — | AAA 级(7:1)边界 |
| `#767676` | **4.54 : 1** | — | **AA 正文最低线**,再浅就不合规 |
| `#949494` | **3.03 : 1** | — | **AA 大字最低线**,只能给 ≥24px |
| `#faf7f2` | — | 20.3 : 1 | 深底正文最佳起点(禁纯白,从暖白起步) |

## 三、OKLCH 速判法(免算公式)

手算三次幂太慢。用 **OKLCH 明度差 ΔL** 速判——OKLCH 的 L 是感知均匀明度(0–1),差值可直接对应对比度:

| 目标对比比 | 所需 ΔL(OKLCH) | 记忆锚点 |
|---|---|---|
| 3 : 1(大字/图形) | **≥ 0.33** | 白底 L=1 → 文字 L ≤ 0.67 |
| 4.5 : 1(正文) | **≥ 0.45** | 白底 L=1 → 文字 L ≤ 0.55 |
| 7 : 1(AAA) | **≥ 0.54** | 白底 L=1 → 文字 L ≤ 0.46 |

**用法**:定色时直接在 OKLCH 里调 L:
```css
:root{
  --c-bg:  oklch(97.5% 0.012 85);    /* 暖纸底 L=97.5% */
  --c-ink: oklch(22%   0.02  70);    /* ΔL = 75.5% → 远超 4.5:1 ✅ */
  --c-muted: oklch(58% 0.02  70);    /* ΔL = 39.5% → 只够大字(≥24px)⚠️ */
}
```

**精度说明**:ΔL 法则对**中性色精确**(上表即由中性色反推);对高饱和色为近似——WCAG 的亮度权重偏绿(0.7152),同为 OKLCH L=60% 的**纯黄**与**纯蓝**,对比比可差 1.5 倍以上。因此:
- 中性/低饱和(C ≤ 0.05)→ 直接用 ΔL 判
- 高饱和(C > 0.15)→ ΔL 判过但**余量不足 0.1** 时,用 §2 公式核一次
- 边界值(ratio 在 4.3–4.7 之间)→ 一律用公式核算

## 四、文字压图:遮罩数值

> `xhs-cover.md:103` 写「压图必须暗化/渐变层兜底,对比度 ≥4.5:1,不许靠滤镜碰运气」,但没给做法。这里给。

### 4.1 三种垫层,按图片复杂度选

**A · 全幅单向渐变**(最常用,照片构图杂乱时)
```css
.scrim{
  position:absolute; inset:0;
  background: linear-gradient(
    to top,
    rgba(12,10,8,.72) 0%,      /* 底部最重:文字区 */
    rgba(12,10,8,.38) 34%,
    rgba(12,10,8,.06) 62%,
    transparent 82%
  );
}
```
- 方向:文字在**下**用 `to top`,在**上**用 `to bottom`,在**左/右**用 `to right/left`
- 覆盖比例:渐变**实体段**(α ≥ .30)至少覆盖文字区外扩 8% 的高度
- 底部 α 上限 **.75**——再重图片就废了,不如换图

**B · 局部色块**(文字成块、构图干净时)
```css
.scrim-block{
  position:absolute; left:0; bottom:0; width:62%; height:38%;
  background: rgba(12,10,8,.62);
  backdrop-filter: blur(2px);      /* 可选,2–4px;>6px 会糊 */
}
```
- α **.55–.70**;低于 .50 在浅色照片上守不住 4.5:1
- 色块颜色取**ink 同色系**,不要用图片主色的补色(会脏)

**C · 双层**(压字最保险的组合:软渐变 + 文字自身描边)
```css
.title-on-photo{
  text-shadow: 0 1px 3px rgba(0,0,0,.45);   /* 只做收边,不做发光 */
}
```
- 描边/投影只作**收边**,α ≤ .50、blur ≤ 4px;靠它顶替垫层 = 文字发灰

### 4.2 验收(必做,不许目测)

1. 取**文字区内最亮的一小块**(通常 20×20px)作为 L2 —— 不是取图片平均色
2. 按 §2 算 ratio;不足则**加重垫层**,不要改文字颜色(改了会破坏 tokens 一致性)
3. 边界情况:垫层已到 α .75 仍不达标 → **换图或移动文字位置**,不要继续加

### 4.3 常见错误

| 错误 | 后果 | 正解 |
|---|---|---|
| 用 `filter: brightness(.6)` 压整图 | 整幅发灰,主体也没了 | 用垫层,只压文字区 |
| 垫层用 `mix-blend-mode: multiply` | 转矢量必色偏(`vector-export.md` 五条禁令之一) | 用 alpha 叠加 |
| 白字压浅色天空 | 对比度常常只有 1.5:1 | 换深色垫层或把文字挪到暗区 |
| 只压一次不验收 | 交付后才发现看不清 | 按 §4.2 取最亮小块核算 |

## 五、色盲友好

约 **8% 男性 / 0.5% 女性**有色觉障碍,红绿色盲占绝大多数。海报是大众媒介,主信息不能只靠颜色区分。

### 5.1 三型与影响

| 类型 | 占比 | 混淆 |
|---|---|---|
| 绿色盲 Deuteranopia | ~6% 男 | 红↔绿、粉↔灰 |
| 红色盲 Protanopia | ~1% 男 | 红↔暗、红↔棕 |
| 蓝色盲 Tritanopia | <0.01% | 蓝↔绿、黄↔粉 |

### 5.2 三条硬规则

1. **颜色不是唯一编码**:状态/分类必须同时带**文字标签**或**形状/图标**。对比图「涨/跌」只靠红绿 → 加 ▲/▼。
2. **系列色拉开明度**:数据系列(图表、图例)相邻色的 OKLCH **L 差 ≥ 0.12**,这样去色后仍能分辨。
3. **避开红绿主对比**:促销类的「原价删除线红 / 现价绿」换成「红 + 删除线 + 字号差」三重编码。

### 5.3 色盲安全系列色(4 色,直接抄)

```css
/* Okabe-Ito 改良版:8 型色觉下均可分辨 */
--series-1: oklch(58% 0.17  40);   /* 朱红 */
--series-2: oklch(72% 0.15  85);   /* 橙黄 */
--series-3: oklch(62% 0.13 220);   /* 天蓝 */
--series-4: oklch(48% 0.10 300);   /* 紫   */
```
相邻 L 差 ≥ 0.10,任意两色去色后 L 仍不重合。系列 >4 时**重新分组,不加色**(`data-longform.md:57` 同规)。

### 5.4 快速自检

把图**去色**(灰度)后看:
- 主信息与背景仍分得开?
- 各分类仍分得开?
分不开 = 只靠颜色编码了,必须补形状或文字。

## 六、与既有 tokens 的关系

`style-system.md:44-53` 的 8 组起步 tokens 已通过对比度检验(ink 与 bg 的 ΔL 均 > 0.70,远超 4.5:1)。使用时注意:

| 注意点 | 说明 |
|---|---|
| 强调色不是正文色 | `accent` 通常饱和度高、L 偏高,**不要**拿来排正文;先按 §三 核 ΔL |
| 深底反转 | 紫夜/黑金两组是深底,阈值方向不变(ratio 与深浅无关,只看 L1/L2 之比) |
| 60/30/10 与对比度无关 | 那是面积分配,不是可读性。小面积强调色同样要过 3:1(图形)或 4.5:1(文字) |
| 强调 ≤2 处 | `guardrails.md` 铁律 3。本册不放松它——加对比度不等于可以增加强调处 |

## 七、色彩自检(接在 `guardrails.md` §9 之后)

1. 正文对比比 ≥4.5:1?按 §2 算过,不是目测?
2. 大字(≥24px 常规 / ≥18.66px 粗体)≥3:1?
3. 压图文字:取文字区**最亮小块**核算过?垫层 α ≤ .75?
4. 强调色 ≤2 处?
5. 去色后主信息仍可辨?
6. 图标/图表线/二维码 ≥3:1?

> 打分走 `design-review-rubric.md`(色彩与对比维度占 20%)。
> 印刷任务的色彩另有 CMYK 约束(TAC ≤300%、单色黑 K100、禁 RGB 极值),见 `print-cmyk.md` —— 两者**同时**满足,`print-cmyk.md` 优先级更高(印刷不可返工)。

## 八、视距 → 字号换算(通用附录)

> 本册管"看不清"的两种根源:对比度不够(§一–§五)与**字太小**(本节)。各品类的成品字号阶以 `formats/<品类>.md` 为准(它们是按品类观看方式校准过的);本节给**通用物理换算**,用于:新品类没有现成分册、或用户问"X 米远能看清吗"。与既有口径的关系:名片 7pt 底线(`formats/card.md`)、易拉宝 1–2m 字号往大做(`formats/rollup.md`)都能由本节公式推出——本节是推导来源,不是第二套字号阶。

**两条经验公式**(字面高度 H,视距 D,同一单位):
- **最低可辨**:H ≥ D ÷ 250(能认出是什么字;只够信息条/落款用)
- **舒适阅读**:H ≥ D ÷ 100(移动中、一瞥、中老年受众;海报正文一律这档)

换算成画布:**画布px = 字面高 mm × (画布宽 px ÷ 介质宽 mm)**。

| 场景 | 视距 D | 最低可辨 | 舒适阅读 | 折算与既有口径对照 |
|---|---|---|---|---|
| 名片 / 卡片 | 0.3 m | 1.2 mm(≈3.4pt) | 3 mm(≈8.5pt) | 7pt 底线(`formats/card.md`)落在两档之间,靠加粗兜住;1063px 宽画布 ≈ 11.8px/mm |
| 手机竖图(xhs 等) | 0.25–0.35 m | ≈1.2 mm | ≈3 mm | 1080 宽画布 ≈ 5.7px/mm → 舒适档 ≈ 17px,正文 ≥24px(`guardrails.md §3`)即舒适档 ×1.4 安全系数 |
| A4 海报 | 0.5–1 m | 2–4 mm | 5–10 mm | 1240px 宽画布(scale 1)≈ 5.9px/mm → 正文舒适档 ≥30px |
| 易拉宝 | 1–2 m | 4–8 mm | 10–20 mm | 2362px 宽画布 ≈ 2.95px/mm → 舒适档 ≈ 30–60px;`formats/rollup.md` 实际定 90–120px——行走观看是"瞥"不是"读",分册值 = 公式 ×2 安全系数 |

**三条使用纪律**:
1. **品类分册优先**:有 `formats/<品类>.md` 字号阶的用品类值(已按观看方式校准),本表只在无分册时兜底;
2. **主标语不用最低档**:最低可辨只给信息条/落款/法规小字,主标一律舒适档起;
3. **远距 / 老年受众再乘 1.5**:车站、户外、社区公告类场景,安全系数往上加,不是往下省。
